# 写作主动词汇

> 目标：把这批 chunk 从"认识"变成"会用"。来源：[[IELTS/Writing/作文批改 Task 2 - 死刑]] · [[IELTS/Writing/作文批改 Task 2 - 运动]] · [[IELTS/Writing/作文批改 Task 1 - 教育入学]] · [[IELTS/Writing/作文批改 Task 1 - 世界人口占比]] · [[IELTS/Writing/作文批改 Task 2 - 工作满意度与稳定]] · [[IELTS/Writing/作文批改 Task 1 - 食用昆虫]] · [[IELTS/Writing/作文批改 Task 1 - 英国燃料产量]] · [[IELTS/Writing/作文批改 Task 2 - 大学生住家还是离家]] · [[IELTS/Writing/作文批改 Task 1 - 澳大利亚出口]] · [[IELTS/Writing/作文批改 Task 2 - 离家找工作]]。
> 掌握程度用 ⬜（未掌握）/ 🟡（眼熟）/ ✅（能主动用）标注。

## 死刑题 · 核心 14 个 chunk

- [ ] `violate human rights` — 侵犯人权
- [ ] `wrongful conviction` — 误判（定罪错误）
- [ ] `irreversible` — 不可逆的（`an execution is irreversible`）
- [ ] `feel remorse` — 感到悔恨
- [ ] `act as a deterrent` — 起到威慑作用
- [ ] `potential offenders` — 潜在的犯罪者
- [ ] `lose faith in the justice system` — 对司法体系失去信心
- [ ] `take the law into one's own hands` — 动用私刑/自行执法
- [ ] `social stability` — 社会稳定
- [ ] `a breeding ground for organised crime` — 有组织犯罪的滋生土壤
- [ ] `strictly limit the use of ...` — 严格限制……的使用
- [ ] `ensure that ...` — 确保……
- [ ] `impose a death sentence` — 判处死刑
- [ ] `legal safeguards` — 法律保障

## 运动题 · 身心强度

- [ ] `physically demanding sports` — 对身体要求高的运动
- [ ] `highly / well trained` — 训练充分（对比 hardly trained）
- [ ] `mental resilience` — 心理韧性
- [ ] `remain calm under pressure` — 压力下保持冷静
- [ ] `perform to the best of one's ability` — 发挥最佳水平
- [ ] `realise one's full potential` — 发挥全部潜力
- [ ] `a decisive factor` — 决定性因素
- [ ] `provide the foundation for ...` — 为……奠定基础
- [ ] `compete against other athletes` — 与其他选手竞争
- [ ] `at the highest level of competition` — 在最高水平的比赛中
- [ ] `compensate for a lack of ...` — 弥补……的不足
- [ ] `consistent success` — 持续的成功

## 图表作文 · 高频 chunk

- [ ] `the figure for ...` — ……的数字（避免反复写 the number of...）
- [ ] `compared with ...` — 与……相比
- [ ] `respectively` — 分别地
- [ ] `whereas / while` — 而（一边降一边升时比 but 自然）
- [ ] `at the primary / secondary / tertiary level` — 在小学/中学/大学阶段
- [ ] `rose / fell from ... to ...` — 从……上升到/下降到……
- [ ] `exceeded / remained below the target` — 超过/未达到目标
- [ ] `outnumber` — 数量上超过（girls outnumbered boys）
- [ ] `recorded` — 记录到（developing countries recorded 83...）

## 图表作文 · 人口占比/预测

- [ ] `account for X% of ...` — 占……的 X%
- [ ] `the figure fell / rose to ...` — 数字降到/升到……
- [ ] `show a similar / opposite trend` — 呈现相似/相反的趋势
- [ ] `be projected / predicted / expected to ...` — 预计会……（2050 预测时替代 will）
- [ ] `remain stable / remain unchanged` — 保持稳定/不变
- [ ] `overtake / surpass` — 超过（India is projected to overtake China）
- [ ] `the largest share` — 最大份额
- [ ] `had the highest percentage` — 占比最高

## 食用昆虫题 · 地图+柱状图（Task 1）

- [ ] `the countries shown` — 图中所示的国家
- [ ] `record the highest / lowest figure` — 记录到最高/最低值（Mexico records the highest willingness rate, at 71%）
- [ ] `follow at X%` — 以 X% 紧随其后
- [ ] `the corresponding figure(s)` — 相应的数字
- [ ] `range from X to Y` — 范围从 X 到 Y（报两组价格范围最高效）
- [ ] `at $X per kilogram` — 每公斤 X 美元（替代反复的 which costs）
- [ ] `more than three times the price of ...` — 是……价格的三倍多
- [ ] `willing respondents outnumber unwilling ones` — 愿意者多于不愿意者
- [ ] `insect-based products` — 昆虫制品（-based 合成形容词）
- [ ] `conventional foods` — 常规食品（替代 common foods）

## 燃料产量题 · 线图（Task 1）

- [ ] `stand at approximately X` — 处于约 X 的水平（production stood at approximately 90 units）
- [ ] `compared with around X for ...` — 与……的约 X 相比
- [ ] `rise sharply` — 急剧上升
- [ ] `rise steadily` — 稳步上升（≠ stably；stable=水平不变，steadily=变化持续）
- [ ] `fall dramatically` — 大幅下降
- [ ] `fall to a low of X` — 降至低点 X（不用 valley / bottom）
- [ ] `reach a peak of X` — 达到峰值 X
- [ ] `recover to` — 回升到
- [ ] `fluctuate` — 波动
- [ ] `remain broadly stable` — 大致保持稳定
- [ ] `the dominant fuel` — 占主导地位的燃料

## 澳大利亚出口题 · 线图（Task 1）

- [ ] `Australia's largest export market` — 最大的出口市场（不是 first export country）
- [ ] `the figure / share for ...` — ……的数字 / 份额（percentage 的安全替身）
- [ ] `fluctuate before declining` — 先波动后下降（不是一路 fell）
- [ ] `overtake A to become ...` — 超过 A 成为……（用 by + 年份，不猜交叉点具体年份）
- [ ] `declined steadily, reaching X% by YYYY` — 稳步下降并带出终点
- [ ] `rose, although much more gradually than ...` — 也上升但慢得多
- [ ] `before falling slightly to X%` — 随后小幅回落（别漏尾部变化）

## 工作题 · 满意度 vs 稳定（核心 7 个）

- [ ] `job satisfaction / job security` — 工作满意度 / 工作稳定（泛指不加 the）
- [ ] `financial stability` — 财务稳定（= 中文里的"生活稳定"）
- [ ] `meet one's basic needs` — 满足基本需求
- [ ] `a reasonable standard of living` — 尚可的生活水平
- [ ] `personal fulfilment` — 自我实现感
- [ ] `a sense of achievement` — 成就感
- [ ] `mental well-being` — 心理健康

## 住家 vs 离家上大学题（Task 2）

- [ ] `outweigh the disadvantages` — 利大于弊（题目自带的最好用词）
- [ ] `adapt to a new / unfamiliar environment` — 适应新环境
- [ ] `focus on one's studies` — 专注于学业（academy 是"学院"）
- [ ] `household chores` — 日常杂务（staff 是"工作人员"）
- [ ] `There is no need to ...` — 没有必要……
- [ ] `live independently` — 独立生活
- [ ] `encourage sb to do sth` — 鼓励某人做某事（替代 push them to）
- [ ] `interact with their peers` — 与同龄人交流相处
- [ ] `form close friendships` — 建立亲密友谊
- [ ] `these relationships may remain valuable` — 人际关系毕业后依然有价值

## 离家找工作题（Task 2）

- [ ] `many more job opportunities` — 多得多的工作机会（可数用 many more）
- [ ] `adjust to a new environment / job` — 适应新环境/工作
- [ ] `in the early stages of one's career` — 职业生涯初期
- [ ] `build a successful career` — 成就一番事业
- [ ] `step outside one's comfort zone` — 走出舒适圈
- [ ] `people from different backgrounds` — 来自不同背景的人
- [ ] `stay in touch with` — 保持联系（get in touch = 联系上）
- [ ] `have a negative effect on` — 对……有负面影响
- [ ] `support / effort` 不可数 — need support；time and effort

## 同义词/升级表达

| 初级 | 升级 |
|---|---|
| punishment | penalty / sanction |
| killer / criminal | offender / culprit |
| warn criminals | act as a deterrent to potential offenders |
| give comfort to family | provide a sense of justice or closure for victims' families |
