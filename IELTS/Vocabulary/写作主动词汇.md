# 写作主动词汇

> 目标：把这批 chunk 从"认识"变成"会用"。来源：[[IELTS/Writing/作文批改 Task 2 - 死刑]] · [[IELTS/Writing/作文批改 Task 2 - 运动]] · [[IELTS/Writing/作文批改 Task 1 - 教育入学]] · [[IELTS/Writing/作文批改 Task 1 - 世界人口占比]]。
> 掌握程度用 ⬜（未掌握）/ 🟡（眼熟）/ ✅（能主动用）标注。

## 死刑题 · 核心 14 个 chunk

- [ ] `violate human rights` — 侵犯人权
- [ ] `wrongful conviction` — 误判（定罪错误）
- [ ] `irreversible` — 不可逆的（`an execution is irreversible`）
- [ ] `feel remorse` — 感到悔恨
- [ ] `act as a deterrent` — 起到威慑作用
- [ ] `potential offenders` — 潜在的犯罪者
- [ ] `lose faith in the justice system` — 对司法体系失去信心
- [ ] `take the law into one's own hands` — 动用私刑/自行执法
- [ ] `social stability` — 社会稳定
- [ ] `a breeding ground for organised crime` — 有组织犯罪的滋生土壤
- [ ] `strictly limit the use of ...` — 严格限制……的使用
- [ ] `ensure that ...` — 确保……
- [ ] `impose a death sentence` — 判处死刑
- [ ] `legal safeguards` — 法律保障

## 运动题 · 身心强度

- [ ] `physically demanding sports` — 对身体要求高的运动
- [ ] `highly / well trained` — 训练充分（对比 hardly trained）
- [ ] `mental resilience` — 心理韧性
- [ ] `remain calm under pressure` — 压力下保持冷静
- [ ] `perform to the best of one's ability` — 发挥最佳水平
- [ ] `realise one's full potential` — 发挥全部潜力
- [ ] `a decisive factor` — 决定性因素
- [ ] `provide the foundation for ...` — 为……奠定基础
- [ ] `compete against other athletes` — 与其他选手竞争
- [ ] `at the highest level of competition` — 在最高水平的比赛中
- [ ] `compensate for a lack of ...` — 弥补……的不足
- [ ] `consistent success` — 持续的成功

## 图表作文 · 高频 chunk

- [ ] `the figure for ...` — ……的数字（避免反复写 the number of...）
- [ ] `compared with ...` — 与……相比
- [ ] `respectively` — 分别地
- [ ] `whereas / while` — 而（一边降一边升时比 but 自然）
- [ ] `at the primary / secondary / tertiary level` — 在小学/中学/大学阶段
- [ ] `rose / fell from ... to ...` — 从……上升到/下降到……
- [ ] `exceeded / remained below the target` — 超过/未达到目标
- [ ] `outnumber` — 数量上超过（girls outnumbered boys）
- [ ] `recorded` — 记录到（developing countries recorded 83...）

## 图表作文 · 人口占比/预测

- [ ] `account for X% of ...` — 占……的 X%
- [ ] `the figure fell / rose to ...` — 数字降到/升到……
- [ ] `show a similar / opposite trend` — 呈现相似/相反的趋势
- [ ] `be projected / predicted / expected to ...` — 预计会……（2050 预测时替代 will）
- [ ] `remain stable / remain unchanged` — 保持稳定/不变
- [ ] `overtake / surpass` — 超过（India is projected to overtake China）
- [ ] `the largest share` — 最大份额
- [ ] `had the highest percentage` — 占比最高

## 同义词/升级表达

| 初级 | 升级 |
|---|---|
| punishment | penalty / sanction |
| killer / criminal | offender / culprit |
| warn criminals | act as a deterrent to potential offenders |
| give comfort to family | provide a sense of justice or closure for victims' families |
