# Task 1 写法 — 结构、改写与分组

> 来源：[[作文批改 Task 1 - 食用昆虫]] 批改后的两个通用问题：
> ① 能不能直接用题干第一句当开头？② 为什么 Task 1 写完像"有头没尾"？

## Task 1 是 report，不是 essay

| | Task 1 | Task 2 |
|---|---|---|
| 本质 | 报告 | 议论文 |
| 结构 | **先总结，再证明** | 先论证，最后总结 |
| 结尾 | 不需要 conclusion | 必须 conclusion |

官方说明：Academic Task 1 **不需要单独的 conclusion，但必须有清晰的 overview**。

固定四段：

1. **Introduction** — 图里有什么（一句话，改写题干）
2. **Overview** — 最重要的总体发现（两句，不密集列数字；**单位说明不是 main feature**，不写进 Overview，正文直接用 `140 energy units` 即可）
3. **Body 1** — 第一张图的细节，用数据支持 Overview
4. **Body 2** — 第二张图的细节，用一个最有比较价值的数据句自然收束

Overview 已经提前把"结论"告诉读者，后面只是展示证据；数据写完报告自然结束。觉得"有头没尾"不是漏写了一段，而是把它当成了议论文。**不要**再加 `In conclusion` 去重复 Overview。

两个操作要点：

- **永远把 Overview 放在第二段**：就算最后时间不够，最重要的总体特征也已经交代了
- **最后一句落点要稳**：不要停在孤立数据上，选一个有比较价值的收束（如：最贵昆虫食品是 beef 价格的三倍多），就自然有"结尾感"

## 题干改写：借骨架，不整句照搬

官方建议用自己的语言改写题干，**整句照抄的部分可能不计入最低字数**。但改句子骨架就够了，不需要每个名词都换生僻同义词。

可以保留：国家名、年份、单位、`insect-based products`、`the percentage of...` 这类专有/功能表达。

例（本题题干 → 安全改写）：

> 题干：The map shows the global willingness to eat insect-based products, and the chart shows the current prices of certain foods available on the market.
>
> 改写：The map shows the proportions of people willing to consume insect-based products in selected countries, while the bar chart compares the current prices of several conventional and insect-based foods.

只做了四个稳的变化：

- `global willingness` → `the proportions of people willing...`
- `eat` → `consume`
- 两个 `shows` → `shows..., while ... compares`
- `certain foods` → `several conventional and insect-based foods`

反面教训：为改写而改写会引入新错误——`The map and charts here shows`（chart 数量错 + 主谓一致错 + here 多余）。**轻度、可控的改写 > 大幅改写。**

固定开头句式（功能语言，不算模板痕迹）：

- `The bar chart compares...`
- `The maps illustrate the changes in...`
- `The table provides information about...`
- `The diagram shows how...`
- `The map shows..., while the chart compares...`

## 时态跟着图表走

- 无历史年份、数据是 current → **一般现在时**（Mexico records... / Beef costs...）
- 有历史年份 → **过去时**（increased / rose / fell）
- 未来预测 → `be projected / predicted / expected to`

## 数据分组：不逐个报数

题目要求 **selecting and reporting the main features**，不是把每个数字报一遍。逐国列数机械、费词、压 CC 分，还容易超字数（目标 **180–210 词**）。

一句覆盖一组：

> In all the remaining countries, willingness is below 40%, ranging from 39% in South Africa to only 21% in Japan.

考前草稿只列骨架（最高 / 次高 / 范围 / 最低），正文分组覆盖其余。

线图额外注意（见 [[作文批改 Task 1 - 英国燃料产量]]）：

- 不要沿时间轴从左往右"讲故事"——多线来回切换读者跟丢，句子越长时态越乱
- 按**趋势相似程度**分组：三线图 Body 1 只写 petroleum（90 → 140 → 100 → 140），Body 2 写 coal + natural gas
- 交叉点值得写（natural gas 在 1990s 超过 coal）

## 多图题思路

- 两张图不相关很正常：**一张图总结一个规律，两个主体段分别描述**
- Overview 各写一句
- **不必强行找两张图之间的因果联系**

> Task 1 没有"想不出观点"的问题，只有"没有找好分组"的问题。
