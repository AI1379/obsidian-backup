> 核心问题定位：不是缺论点，而是 **中文概念 → 英文表达** 这一层没建立好。

## 反复出现的语法/结构错误

- 主谓一致：`Some people believes` → `believe`；`the numbers...is` → `figures...were`
- 单复数：`human rights` / `concerns` 常复数；`In this circumstances` → `In these circumstances`
- `prevent A **from** doing B`（不是 `prevent A does B`）
- `ensure that ...` 是"确保"的标准表达
- 法律语境用 `state` 比 `government` 更自然
- 不可数名词：`corn` → `corn is stored`（不是 are）
- 双写 r：`transfer` → `transferred`
- `its` = 它的 / `it's` = it is（`is destination` → `its destination`）
- 抽象概念不加 the：`physical strength` / `mental strength` / `job security` / `job satisfaction`（不是 the ...）
- 泛指不加 the：`among athletes`（不是 among the athletes）
- `-ed` vs `-ing`：unsatisfied（人感到不满意）/ unsatisfying（事令人不满意）→ an unsatisfied employee / an unsatisfying job
- 有现成形容词就用：a secure job / a satisfying job，不要全部抽象成 high security / high satisfaction
- Task 2 结论用 `In conclusion`；`Overall` 更像 Task 1 的 overview
- 结论语气不能比正文弱：正文明确表态后，结尾不要 `may be more important`
- 绝对副词（definitely）能省则省 → `can be beneficial to...`
- 图表数据用过去时：increased / rose / fell（不是 increases）
- 数据描述用 `figure` 替代反复的 `the number of girls per 100 boys`
- 混合时态：历史节点用 past simple，未来预测用 `is projected/predicted/expected to`（不用 `will`）
- 主谓一致：`The bar charts illustrates` → `The bar chart illustrates`
- comma splice：两个完整句不能只用逗号硬接（`...in 2002, the percentage...` → 拆两句）

## 可复用的论证展开模板

- **Point → Explanation → Consequence**（反方论点不要只列不展开）
- 抽象化表达比具体叙述更稳：`Wrongful executions are irreversible.` 优于 `an innocent person cannot be brought back to life`
- 把语气写"分析性"，避免情绪化表述
