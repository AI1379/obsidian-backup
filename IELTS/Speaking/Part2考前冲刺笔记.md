## 一、题库背景（30 秒版）

- 口语题库**不是官方公开的固定题库**，而是考生考场回忆汇总出的"题池"。
- 换题周期：**1–4 月 / 5–8 月 / 9–12 月**，每年 **1、5、9 月**换题（旧题保留一部分 + 新题加入）。

- **题库 ≠ 原题必押中**：Part 1 问法会变；Part 2 措辞可能微调；Part 3 最灵活，死背原答案风险大。

**备考策略**（GPT 原建议）：
- **Part 1**：看题库练到能自然说 20–30 秒，不用逐题写答案。
- **Part 2**：重点准备，但不背几十篇独立答案，而是准备 **8–12 个万能故事素材**，一个素材覆盖多道题。

### 素材 2 ｜AI Agent 开发（技术题主打）

> [!important] 注意
> ~~FPGA 电路板调试~~ 是朋友的经历（他借了账号问的），**不能当自己的故事讲**，已整体移给人物 A。自己的技术题主打 AI Agent / 算法 / 计算数学。

**可覆盖**：🟢 遇到的技术难题 ｜🟢 使用电子设备时遇到的问题 ｜🟢 做困难事情并成功 ｜🟡 运用想象力解决问题 ｜🟡 聪明解决问题的人 ｜🟡 想拥有或改进的技术设备 ｜🟡 一个应用或程序

**参考答案**

> One technological problem I once faced was when I was developing an AI agent for programming tasks.
>
> The basic idea was to let the AI read a software project, understand the user's request, and then modify the code automatically. At first, I thought the difficult part would be choosing a good language model. However, I soon realised that the bigger problem was how to make the agent use tools correctly and keep track of what it had already done.
>
> For example, sometimes the agent would search the same file repeatedly, or make a change without checking whether the program still worked. In other cases, it would misunderstand the structure of the project and edit the wrong part of the code.
>
> To solve this, I changed the workflow. I asked the agent to make a plan before editing anything, keep its steps relatively small, and run tests after important changes. I also tried to separate different tasks, such as searching, reasoning and actually modifying files.
>
> After several experiments, the system became much more reliable. It still wasn't perfect, but the experience taught me something important: building an AI agent is not simply about using the most powerful model. The way you organise the whole process can be just as important as the model itself.

**变体：Describe a difficult task you completed** —— 主体不变，只换开头与因果链：

> A difficult task I once completed was building a simple AI agent that could help with programming.
>
> What made it difficult was that I wasn't simply writing a normal program with a fixed sequence of steps. The AI had to make decisions by itself, such as which files to read, what information was relevant and what changes it should make.
>
> At the beginning, the results were quite unstable. Sometimes the agent repeated the same operation several times, and sometimes it modified the wrong file. I initially thought that using a stronger AI model would solve the problem, but I gradually realised that the design of the workflow was equally important.
>
> So I divided the task into smaller stages. The agent first had to understand the problem and make a plan. Then it could inspect the necessary files, make a limited number of changes, and finally test whether its solution worked.
>
> It took me quite a lot of experimentation, but eventually the system became much more reliable. I found the project challenging but also very interesting, because it combined programming, problem-solving and AI.

> [!tip] 金句（值得背）
> - **I wasn't simply writing a normal program with a fixed sequence of steps.**
> - **The AI had to make decisions by itself.**
> （让考官瞬间理解你在做什么）

**重点表达**：AI agent for programming tasks ｜ read a software project ｜ modify the code automatically ｜ use tools correctly ｜ keep track of what it had already done ｜ the structure of the project ｜ edit the wrong part of the code ｜ make a plan before editing anything ｜ run tests after important changes ｜ the whole workflow

> [!warning] 别掉进的坑
> 考场**完全不需要**说 MCP、tool calling、context window、sub-agent、OpenAI-compatible provider 这类词。知道得越深，越容易忍不住解释，把 Part 2 变成技术报告。

### 素材 3 ｜优化算法 / 梯度下降（计算数学故事）

**可覆盖**：difficult subject ｜ something difficult you learned ｜ an interesting course ｜ a useful skill ｜ something you learned that surprised you ｜ a difficult problem

**参考答案**

> One difficult topic I learned was optimisation algorithms used in machine learning.
>
> When I first studied neural networks, I knew that algorithms such as gradient descent and Adam were used to train them, but my understanding was quite superficial. I could use the formulas, but I didn't really understand why different optimisation methods behaved differently.
>
> So I decided to study the mathematics behind them more carefully. I compared ordinary gradient descent with methods such as momentum and Adam, and I wrote some small programs to visualise how they moved towards the minimum of a function.
>
> The visualisation helped me a lot. Instead of just looking at equations, I could actually see why momentum sometimes allowed an algorithm to move faster, or why a poor choice of parameters could make the optimisation unstable.
>
> It took some time because I had to connect mathematical ideas with programming and machine learning. But once I understood it, I found it extremely satisfying. It also made me realise that computational mathematics is interesting precisely because abstract mathematics can produce very practical algorithms.

**术语安全说法**

| 概念 | 考场说法 |
| --- | --- |
| 梯度下降 | gradient descent, which is an algorithm for finding a better solution step by step（不要解释偏导数） |
| 最小值 | the minimum of a function（忘了就说 the best point） |
| 优化算法 | optimisation algorithm |
| 收敛 | 尽量不说 convergence，说 **move towards the solution** |

### 素材 5 ｜三人数学小组项目：主动缩小范围

**亮点**：表现判断力，而不只是"分工合作最后成功"的模板。

**可覆盖**：🟢 一次小组合作 ｜🟢 改变计划 ｜🟢 改变观点 ｜🟢 做困难事情并成功 ｜🟡 给别人建议 ｜🟡 擅长规划的人 ｜🟡 聪明解决问题的人 ｜🟡 鼓励别人的经历

**一分钟笔记**

```
3 students
maths / physics / number theory
original idea too ambitious
too many forced connections
suggested simplifying
clearer presentation
```

**参考答案**

> One time I worked in a group was for a university mathematics project. There were three of us, and we had quite different academic interests. I focused more on computation, one teammate studied physics, and another was particularly interested in number theory.
>
> At first, our plan was far too ambitious. We tried to connect conformal maps, string theory, number theory and neural networks in a single presentation. It sounded impressive, but the connections were not always clear, and the audience would probably have found it difficult to follow.
>
> I suggested removing the neural-network section because it felt slightly forced. Instead, we decided to begin with a concrete mathematical example and then introduce the deeper theory. We divided the remaining work according to our strengths and met several times to combine the slides.
>
> In the end, the presentation became much clearer. This experience taught me that successful teamwork does not mean including every idea. Sometimes the most intelligent decision is to simplify the project.

> [!tip] 万能结尾句
> **Sometimes the most intelligent decision is to simplify the project.**（可放到"建议、决定、合作、困难"类题的结尾）

### 素材 11 ｜体育比赛：完全不了解也能救

> [!important] 策略
> 不要临时背足球规则或运动员名字——IELTS 不是体育知识竞赛。
> 最稳的方法：**承认自己不是体育迷 + 选奥运会这种人人都知道的比赛 + 描述观看体验而不是技术细节。**

**首选素材：奥运乒乓球（电视直播）**

巨大优势：**根本不需要知道谁赢了。** 因为描述的是：为什么看 → 看到什么 → 什么觉得有意思 → 为什么现在理解体育迷了。

**参考答案**

> To be honest, I don't follow sports very closely, so I don't watch matches on a regular basis. However, one sporting event I remember watching was an Olympic table tennis match on television.
>
> I watched it mainly because the Olympics is a major international event and people around me were talking about the competition.
>
> I don't know much about professional table tennis tactics, but the match was still surprisingly exciting. The game was extremely fast, and sometimes a single point involved many quick exchanges. What impressed me most was how concentrated the players were. Even when the score was very close, they had to remain calm because one small mistake could completely change the result.
>
> I also enjoyed the atmosphere. Even though I was watching it on a screen rather than inside the stadium, I could hear the audience reacting to important points, which made the match much more exciting.
>
> I probably wouldn't become a serious sports fan because of one match, but the experience helped me understand why people enjoy watching competitive sports. When the result is uncertain until the final few points, it can be genuinely stressful and exciting at the same time.

| **Level 1** 我知道一点 | 能说出具体项目 | 说奥运会、乒乓球、羽毛球这类规则直观的；不解释 tactics / rankings / tournament structure / athlete statistics |
| **Level 2** 几乎不看体育 | 真没素材 | 开头承认 **I'm not really a sports fan, so this isn't something I do very often.**（完全不会扣分）+ **But the closest example I can think of is...** → 学校运动会、奥运直播、朋友拉你一起看的比赛。IELTS 测英语，不测兴趣是否合题 |
| **Level 3** 题目要求"现场看过" | *a sporting event you attended* | 电视直播不贴题，最稳素材是 **a school sports day**——哪怕你只是坐在旁边看 |

**School sports day 一分钟笔记**

```
school sports day
running events
went with classmates
not interested at first
cheered for classmates
atmosphere surprisingly good
```

**开场句**（合法且好讲）：

> I'm not particularly interested in professional sports, so the sporting event that comes to mind is actually a sports day at my school.

## 四、人物题：A/B 体系（不用准备十个人）

> **A = 一个我很熟、能讲具体故事的人；B = 一个我不熟、但一次 encounter 本身就有故事的人。** 这是最稳的组合。

### 人物 A ｜FPGA 朋友

**负责**：聪明的人 ★★★★★ ｜ 做困难事情成功的人 ★★★★★ ｜ 擅长解决问题的人 ★★★★★ ｜ 不同兴趣的朋友 ★★★★★ ｜ 一起学习/讨论的人

**人设**（别只说 "My friend knows a lot about FPGA"，太扁平）：

> 他是一个很喜欢自己动手解决工程问题、遇到问题会一路追根究底的人。

**核心表达**

- 他主要做硬件 → **He is mainly interested in electronics and hardware design.**
- FPGA → **FPGA, which is a type of programmable chip**（第一次出现解释一次：*He does quite a lot of work with FPGAs, which are basically programmable chips used to build specialised digital systems.* 之后直接说 FPGA）
- 画板 → **design a circuit board**
- 调试硬件 → **debug hardware**
- 从原理图到能用的板子 → **turn a design on paper into a working device**（零技术门槛，特别好）

**版本 1：做困难的事情并成功的人**

> One person I know who managed to do something quite difficult is a close friend of mine who is really interested in electronics.
>
> He often works on FPGA projects. An FPGA is basically a programmable chip that can be used to build specialised digital systems. Some time ago, he decided to design his own circuit board around one of these chips.
>
> What made the project difficult was that there were many things that could go wrong. He had to design the hardware, choose suitable components, assemble the board and then debug it. Even a very small mistake could stop the whole system from working.
>
> I remember that when he first tested the board, it didn't work as expected. Instead of giving up or immediately starting again, he checked the problem step by step. He measured different signals, changed parts of the design and gradually eliminated possible causes.
>
> Eventually, he managed to get the system working. What impressed me wasn't simply the final result. It was his patience. I'm much more interested in algorithms and software myself, so watching him solve a physical engineering problem was quite different from the kind of work I usually do.
>
> I think that's why I remember the experience so clearly. It showed me that difficult problems often require patience more than one brilliant idea.

> [!tip] 金句
> **Difficult problems often require patience more than one brilliant idea.**

**版本 2：一个聪明的人**

> A person I consider particularly intelligent is a close friend of mine who is very good at hardware design.
>
> What makes me think he is intelligent is not that he knows every answer immediately. It's that he is very systematic when he doesn't know the answer.
>
> When something goes wrong, he doesn't just try random solutions. He breaks the problem into smaller parts and checks them one by one.

> [!tip] 技巧
> 不要把 smart 定义成"考试成绩很好"——**聪明 = 系统性地对待不知道的问题**。

**加分细节（专业差异让答案变真实）**

> I'm more interested in algorithms and computational mathematics, while he's much more into electronics and hardware.
> So we sometimes look at the same technical problem from completely different perspectives.
> I tend to think about software or algorithms first, while he usually thinks about what is happening at the hardware level.

> [!warning] 提醒
> "快乐的人"**不要强套**——除非他本人确实外向乐观，否则别突然 "He is also the happiest person I know."。快乐的人、擅长语言的人、医疗工作者、种植物的人、儿时朋友 → 另找真实人物。

### 人物 B ｜Andrei Okounkov（菲尔兹奖得主）

> [!warning] 名字拼写
> **Andrei Okounkov**（不是 Okunkov）。2006 年 Fields Medal，获奖理由：连接 probability、representation theory 和 algebraic geometry；现任 Columbia University 数学教授。

**负责**：只见过一次、想进一步了解的人 ★★★★★ ｜ 著名/成功的人 ★★★★☆ ｜ 敬佩的人（与 A 二选一）

> [!important] 不了解他不是缺陷，是故事逻辑
> 我只在讲座上见过他 → 当时没完全听懂 → 后来知道他是 Fields Medalist → 发现他的研究跨很多数学领域 → 所以反而想进一步了解他。
> 这比硬装"我研究他论文很多年"自然得多。

**主线**：where I met him → what I knew → what happened at the lecture → why he impressed me → why I want to know more

**参考答案**

> A person I have met only once but would really like to know more about is **Andrei Okounkov**, a mathematician who won the Fields Medal in 2006.
>
> I saw him at an academic lecture some time ago. To be honest, before attending the lecture, I knew his name, but I didn't know much about his research. I only knew that he was a very well-known mathematician.
>
> During the lecture, he talked about some fairly advanced mathematical ideas. I couldn't understand every technical detail, because some of the topics were beyond what I had studied at university. However, what impressed me was the way he connected ideas from different areas of mathematics. Instead of treating each subject as something completely separate, he showed that apparently unrelated problems can sometimes be studied using similar mathematical ideas.
>
> After the lecture, I learned that his research connects areas such as probability, algebra and geometry, and that he received the Fields Medal for this kind of work.
>
> I would like to know more about him, especially how he approaches a completely new mathematical problem and how he finds connections between different fields. Since I'm interested in mathematics and computation myself, I think his way of thinking is probably more interesting to me than the award itself.

> [!tip] 金句（务必保留）
> **His way of thinking is probably more interesting to me than the award itself.**
> 听起来不像背诵 "Fields Medal is a prestigious prize blah blah"。

**"不懂装不懂"话术**（考官不是数学专业，别解释 representation theory / algebraic geometry / enumerative geometry / random partitions）：

- 含糊带过 → **some advanced topics in mathematics** / **several different branches of mathematics**
- 真要说表示论 → **representation theory, which is an area of abstract mathematics**（到此为止）
- 没完全听懂 → **I couldn't follow every technical detail.** / **Some parts of the lecture were beyond my current level of mathematics.**
  - ❌ 不要说 *I couldn't understand what he was talking about*（听起来像全场没听懂）

**常用表达**：a Fields Medalist ｜ a well-known mathematician ｜ an academic lecture ｜ advanced mathematics ｜ different branches of mathematics ｜ connect apparently unrelated ideas ｜ approach a mathematical problem ｜ his way of thinking ｜ beyond my current level ｜ I couldn't follow every technical detail ｜ what impressed me most was...

Fields Medal 一句话解释即可：**The Fields Medal is one of the most prestigious awards in mathematics.**
（不要说 "the Nobel Prize of mathematics"——自己就是数学方向，可以说得更准确。）

若考官追问 *Why do you want to know more about him?*：

> **Because I want to know how a mathematician at that level actually thinks when facing a problem he has never seen before.**

**"做困难事情并成功的人"**：Okounkov 可用但**不是首选**——你难以描述他具体遇到什么困难、怎么克服。这题首选人物 A。

## 六、概念急救：中文 → 可说英语

> [!important] 核心规则
> **不知道专业术语时，解释功能，不要找术语。**
> IELTS 评分标准不是"你知不知道 regularisation"，而是"你能不能用英语把自己的意思连续、准确地表达出来"——口语特别奖励这种解释能力。

### 技术概念

| 中文概念 | 忘词时的说法 |
| --- | --- |
| 上下文窗口 | There is a limit to how much information the AI can consider at one time. |
| 幻觉 | Sometimes the AI produces information that sounds reasonable but is actually incorrect. |
| 工具调用 | The AI needs to decide when and how to use external tools. |
| 多 Agent | I let several AI agents handle different parts of the task. |
| 强化学习 | a method that allows a system to learn from rewards and feedback |
| 过拟合 | The model performs very well on the data it has seen, but poorly on new data. |
| 正则化 | methods used to prevent the model from becoming too dependent on the training data |
| 泛化能力 | how well the model performs on new data |
| 数值稳定性 | whether small numerical errors can seriously affect the final result |
| 迭代 | repeat the process several times and gradually improve the result |
| 调参 | adjust the parameters and compare the results |

### 文化作品概念

尤其容易出现"知道中文意思、英文突然卡住"的情况：

| 中文概念 | 考场说法 |
| --- | --- |
| 世界观 | the fictional world created by the game / the setting of the story（不用纠结 worldbuilding） |
| 剧情 | the story（想准确点：the storyline） |
| 角色塑造 | the way the characters are written（比 characterisation 更口语） |
| 美术风格 | the visual style |
| 配乐 | the soundtrack / background music |
| 沉浸感 | It makes me feel like I'm actually inside that world.（别为了 immersion 卡十秒） |
| 文化元素 | elements from traditional Chinese culture |
| 开放世界 | an open-world game |
| 抽卡 | 没必要就**不要主动提**；真需要时说 a system where players can obtain new characters randomly |

## 七、Part 2 一分钟草稿法

官方规则：**1 分钟准备、连续说 1–2 分钟**，可做笔记。目标不是逐条机械回答提示点，而是形成连贯故事，尽量接近完整的两分钟。

**只写六格，不写完整句子**（写完整句子的结果：照着说得很顺，纸用完立刻停住）：

```
Who / What
Background
Problem
Action
Result
Feeling / lesson
```

例（技术难题）：

```
my AI agent
tool use / tracking failed
repeated searches, wrong edits
plan → small steps → tests
much more reliable
process matters as much as model
```

**固定连接句**

| 位置 | 句子 |
| --- | --- |
| 开场 | The first example that comes to mind is… |
| 背景 | To give you some background,… |
| 引出困难 | The main difficulty was that… |
| 补充例子 | To give you a specific example,… |
| 回顾 | Looking back, I think… |
| 结尾 | So overall, it was a challenging but valuable experience. |

## 八、考前练习清单

1. **专业转向**：分别以"决定、改变计划、改变观点、长期理想"四种开头各说一遍。
2. **AI Agent**：说两遍，第二遍删掉所有不必要的技术术语。
3. **数学小组项目**：说两遍，确保有"原计划→发现问题→简化→结果"的完整因果链。
4. **课程、杭州、钢琴**：各说一遍。
5. **文化素材**（Frozen、原神）各说一遍；体育题练一次 Level 2 开场和 school sports day 开场。
6. **选定两个人物**（A 朋友 / B Okounkov），各备一件具体小事。
7. **随机抽题**模考：一分钟写六个关键词，连续说至少 90 秒。

**三条考场原则**：

> [!note] 牢记
> 1. **简单句不断，比复杂句反复重启好得多。**
> 2. **具体小事，比空泛大道理更容易说满两分钟。**
> 3. **忘掉一个词就换说法，不要停在那里搜词。**
