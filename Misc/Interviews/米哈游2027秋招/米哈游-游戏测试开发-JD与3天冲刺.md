# 米哈游「游戏研发-游戏测试开发」JD 拆解与 3 天冲刺

> 岗位来源：米哈游招聘官网 2027 届秋招，岗位 ID 8949，上海，全职
> 你 11/1（周日）19:00-21:00 的在线笔试是「2027届秋招-米哈游程序通卷-F卷」，以下按这个岗位准备。

## 一、官方 JD 原文（8949）

### 岗位职责
1. 负责开发测试工具，参与游戏质量相关工具和平台的前后端开发；
2. 负责专项测试平台的前后端开发，涉及兼容性、自动化、服务器性能、客户端性能、安全等平台；
3. 负责研究新型测试技术，帮助项目提升整体质量。

### 任职要求
1. 具备扎实的计算机基础，熟悉至少一门编程语言（C/C++、C#、Python、Go 等不限），**深入理解数据结构、算法、操作系统和网络**等知识；
2. 具备扎实的 web 研发基础知识，**熟悉 HTTP 协议、MySQL** 等 Web 相关技术；
3. 熟悉**系统设计与算法**；
4. 具备优秀的逻辑思维能力和强烈的求知欲，能够快速学习新的知识。

### 加分项
1. 了解产品级的平台服务研发经验，了解代码托管、大数据处理；
2. 了解主流 iOS/Android 自动化、性能相关，了解 Unity、Unreal 等业界引擎；
3. 有 AIGC、AI 自动化、代码大模型提效、AI Agent 等 AI 应用相关实践经验者优先。

3) 测试基础 + Web/MySQL（专业面）
4) 计算机组成原理（选择题补分，性价比低于前两项但必须背高频）

## 四、3 天冲刺计划（10/29 晚 → 11/1 考试）

> 目标不是学完，而是「选择题少丢分 + 编程题能写出一道」。每天保证 4-5 小时有效学习。

### 10/29（周四晚）
- 19:30-21:30 计算机网络：TCP/UDP、三次握手四次挥手、HTTP/HTTPS、状态码、DNS/ARP、输入 URL 过程（先背结论，再做 30 道牛客选择）
- 21:30-23:00 操作系统：进程/线程、调度、死锁、内存分页/页面置换、Linux 常用命令
- 23:00-23:40 编程：LeetCode 热题 1 道（数组/哈希），用 ACM 模式手写输入输出

### 10/30（周五）
- 上午/下午抽 2.5h 计算机组成：补码/浮点、CPU 性能公式、流水线、Cache 映射与地址划分、中断/DMA
- 1.5h 操作系统错题 + PV/死锁/虚拟内存
- 1.5h 编程：2 道（字符串 + 二叉树/DP）
- 晚上 0.5h 复盘错题

### 10/31（周六）
- 2h 测试基础：黑盒/白盒、等价类/边界值/判定表、覆盖率、缺陷生命周期、测试用例设计
- 1.5h Web/MySQL：HTTP 方法/状态码、Cookie/Session/Token、SQL 联表/索引/事务
- 1h 全真选择题模拟（计网+OS+计组各 20 题），记录错题
- 1.5h 编程：2 道（链表/栈队列/二分）
- 晚上只看错题本，不再开新难点

### 11/1（周日）
- 上午：看错题本 + 三科公式/结论速查（2h 内）
- 14:00 后不再做难题，检查设备：Chrome、摄像头、第二机位、草稿纸
- 18:45 打开考试链接核对信息；19:00 开考

## 五、资料清单（按性价比排序）

### 选择题/八股
1. **牛客网**：计算机基础专项练习、测试开发专项、公司真题（优先刷「计算机网络」「操作系统」「计算机组成原理」）
2. **小林 coding**：`xiaolincoding.com` — 图解网络、图解系统，适合 2-3 天速成
3. **JavaGuide**：`javaguide.cn` — 计算机基础、HTTP、MySQL 面试题
4. **CS-Notes**：`github.com/CyC2018/CS-Notes` — 精简八股
5. **王道考研**：计算机网络/操作系统/计算机组成原理 复习指导（只看每章「知识点总结 + 选择题」）

### 教材/系统学习（考前不啃，考后补）
- 《计算机网络：自顶向下方法》
- 《操作系统概念》（恐龙书）
- 《深入理解计算机系统》CSAPP（重点第 3、6、9 章）
- 《计算机组成原理》唐朔飞
- 《现代操作系统》

### 编程
- LeetCode 热题 100 / 剑指 Offer
- 牛客「ACM 模式」输入输出练习（米哈游/牛客笔试都是 ACM 模式）
- 重点题型：数组、字符串、哈希、双指针、栈/队列、链表、二叉树、二分、排序、DFS/BFS、简单 DP、模拟

### 测试基础
- 黑盒：等价类划分、边界值、判定表、因果图、场景法、错误推测
- 白盒：语句覆盖、判定覆盖、条件覆盖、路径覆盖
- 测试流程：需求评审 → 测试计划 → 用例设计 → 执行 → 缺陷跟踪 → 回归 → 测试报告
- 性能：QPS/TPS、响应时间、并发数、吞吐量、资源利用率
- 自动化：接口自动化（Postman/Pytest+Requests）、UI 自动化（Selenium/Appium）、CI/CD
