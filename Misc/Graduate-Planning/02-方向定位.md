# 02 - 方向定位

## AI 行业的三条路径

| 路径 | 核心工作 | 是否需要 PhD |
|------|---------|------------|
| AI 算法研究 | 提出新模型、训练方法、理论与实验分析 | 通常很有价值 |
| AI Systems / Infra | 训练框架、推理引擎、Agent runtime、编译器、分布式系统 | 不一定，但顶尖研发岗常有帮助 |
| AI 应用与产品 | RAG、Agent 产品、垂直应用、工程落地 | 通常不需要 |

## 自我认知修正

- Agent 对我来说更像"玩玩"，不是研究主线
- 做了这么多严格数学训练后去做传统软件工程不是好选择
- 希望数学训练能真正发挥作用

## 可能最适合的方向

结合代码/系统实现兴趣 + 数学背景，很可能适合：

- LLM Agent 与工具使用
- AI Systems
- 模型推理与训练基础设施
- 多模态 Agent
- Embodied / interactive agents
- 长期记忆、环境建模、planning
- AI for scientific computing
- 模型与真实软件/硬件系统的结合

更具体地，应该收敛到两个方向簇：

### 模型与学习方法
- generative models
- statistical learning
- optimization for ML
- uncertainty
- representation learning
- deep learning theory
- foundation models for structured data

### Scientific ML / AI4S
- neural operators
- inverse problems
- PDE-constrained learning
- dynamical systems
- computational biology
- materials or molecular modeling
- scientific foundation models
- uncertainty quantification

## 寻找导师的关键

不要只搜索标题里写着"Large Language Model"的老师。很多真正适合的组可能挂在：计算机系统、软件工程、数据库、NLP、多模态、机器人、人机交互、科学计算、优化与机器学习。

## 需要通过研究确认的问题

> 提新算法、做实验、证明理论、造系统，还是把模型放进复杂环境里解决问题？

## 重新定位

> **接受过严格数学与计算训练，希望研究现代学习模型的原理、方法，以及它们在科学问题中的应用。**

这个定位：
- 既适合 NUS Statistics and Data Science
- 也适合香港的统计/计算机项目
- 适合国内的统计学习与 AI4S 直博
- 适合美国的 Statistics、Applied Math、CS 和 Computational Science PhD
- 比"我要做 LLM"更有辨识度，也更不容易随着具体技术风口过时

## 两种试探性项目

### 项目 A：模型或统计学习方向

例如：生成模型训练动力学、diffusion/flow matching 的数值或统计问题、表征学习与泛化、uncertainty calibration、高维数据 foundation model、优化方法对模型行为的影响。

测试你是否喜欢：阅读 ML 论文、设计实验、推导与建模、在噪声很大的结果中提炼规律。

### 项目 B：AI4S 或 Scientific ML

例如：神经算子求 PDE、逆问题、物理约束生成模型、材料或分子建模、时间序列和动力系统、数学自动推理、科学数据中的不确定性量化。

测试你是否喜欢：深入理解一个科学对象、把数学结构放进模型、与领域知识结合、接受评价周期更长但问题更扎实。

Agent 项目可以继续存在，但定位成：软件作品、工程能力证明、独立完成复杂项目的证据、申请材料中的补充特色。**不要让它成为唯一科研标签。**
