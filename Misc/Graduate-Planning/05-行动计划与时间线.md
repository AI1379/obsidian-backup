# 05 - 行动计划与时间线

## 时间线

### 现在 → 开学（暑假剩余）

1. 筛出校内 12-15 位候选老师
2. 精读其中 5-8 位近期工作
3. 联系 4-6 位，至少和 2-3 位面谈
4. 最终进入一个组，获得明确任务
5. 整理已有代码项目，挑一个最能体现数学/模型能力的做成正式仓库

入门任务可以是：复现一篇论文 / 实现 baseline / 阅读一组文章并作报告 / 验证某个模型现象 / 小规模理论推导。不要等老师直接给一个"能发 NeurIPS 的题目"。

### 大三上（到寒假前）— 完成第一次研究闭环

- 一份较完整的文献综述
- 可复现代码
- 一套实验或推导
- 一次组内报告
- 一个关于"下一步为什么这样做"的判断

标准不是是否投稿，而是：**导师是否已经能就你的研究能力写出一封具体的推荐信。**

同时开始准备英语。不要拖到大三暑假。

### 大三寒假 → 大三下 — 第二段科研或暑研通道

- 国内直博夏令营
- NUS/香港导师联系
- 海外或港新暑研（NUS SSI、HKUST 暑研等）
- 第一段项目延续或投稿
- 第二位推荐人

注意：HKUST 暑研可直接转 PhD offer（案例：同批三十余人约十人留下读 PhD）。

### 大四申请季

同时申请：国内直博 + NUS + 香港 + 美国 + 其他全奖 PhD。拿到具体导师和 funding offer 后再比较。

## 导师联系名单结构

第一轮不超过 **12-15 位**。

| 类别 | 人数 | 说明 |
|------|------|------|
| A 类：浙大 | 5-6 位 | 两周内面谈 2-3 位，覆盖统计学习/生成模型/AI4S |
| B 类：上海与西湖 | 3-4 位 | 周末线下/学期远程/寒假访问 |
| C 类：清北 | 3-4 位 | 只选研究匹配最强的 |

## 邮件模板

### 校内导师

可以说希望先聊一聊方向，不急于确定具体课题。

### 外校/清北导师（需更具体）

> 老师您好，我是浙江大学数学科学学院信息与计算科学专业即将升大三的学生。我的课程背景主要包括……，平时有较多 Python/PyTorch 与软件项目经验，但尚未接受系统科研训练。
>
> 我近期阅读了您关于 \_\_\_ 的工作。我对其中 \_\_\_ 的处理比较感兴趣，尤其是它与 \_\_\_ 之间的关系。我目前尝试复现/推导了 \_\_\_，对 \_\_\_ 还有一些疑问。
>
> 我希望往模型方法/AI4S 方向接受长期研究训练，不以短期挂名或快速投稿为目标。想询问您或组内老师是否有适合本科生参与的阅读、复现或小型研究问题。我可以在学期内稳定线上投入，并在寒暑假赴北京集中交流。

### 注意事项

- 不夸大自己
- 不强调"我想去清华北大"
- 不直接索要论文
- 不说"求老师给一个课题"
- 证明愿意长期做
- 证明因研究问题联系而非学校名气

## 判断回复质量

### 很好的信号

安排线上交流 / 给具体材料 / 介绍博士生或博后指导 / 提出有边界的小问题 / 约定下次汇报 / 询问每周投入时间

### 一般但可尝试

让先读文章 / 参加组会 / 让博士生先聊 → 主动把下一步落到日期上："我计划两周内完成阅读和初步复现，届时给您发一份简短报告，可以吗？"

### 不值得等待

"欢迎关注工作" / "自行阅读论文" / "等暑研再申请" → 可保留关系但不替代已启动的校内项目。

## 两周后决策标准

不是谁学校最强，而是谁能给你：
- 具体问题
- 固定指导人
- 稳定沟通
- 至少半年的连续空间

## 是否考虑本科就业

### 结论：值得作为备选，但现在不建议作为主赌注。

### 三条就业路径

| 路径 | 特点 | 与你的匹配度 |
|------|------|-----------|
| 基础模型研究岗 | 最贴近兴趣但最难，需高质量科研经历 | 冲刺 |
| 大模型算法工程岗 | 本科现实得多，但多数是模型实验+数据工程+业务调参 | 可能错位 |
| 大模型应用/传统软件工程 | 最容易进但与长期兴趣最可能错位 | 不推荐 |

### 实习的价值

- 比校内更快排除错误幻想：模型研究到底有多少数学？日常工作到底有多少清洗数据？
- 提高 PhD 申请质量：复现改进方法 / 设计评测 / 参与论文 / 获得推荐

### 实习优先级

1. **研究型实习**（foundation model / generative modeling / diffusion / AI4S）
2. **研究工程交叉岗**（训练框架 / 推理优化 / 评测基础设施）
3. **高质量算法应用岗**（能接触训练，有实验方法）
4. **纯 Agent 和 API 应用**（较低优先）

### 双轨履历

| 内容 | PhD 价值 | 就业价值 |
|------|---------|---------|
| 正式导师科研 | 很高 | 中高 |
| 模型论文复现改进 | 很高 | 很高 |
| PyTorch 训练经验 | 高 | 很高 |
| 数学统计课程 | 很高 | 中等 |
| LeetCode / 基础 CS | 低 | 高 |
| 开源模型项目 | 中高 | 很高 |
| 公司研究实习 | 高 | 很高 |
| 普通应用实习 | 较低 | 中高 |

### 最终建议

精力分配：**60% 找导师启动研究 + 25% 补基础整理项目 + 15% 关注实习。**

到大三结束用一个问题决定：
> 在同样辛苦的情况下，我更愿意承受"研究长期没有结果"，还是更愿意承受"工作被业务目标和工程细节支配"？

前者 → PhD；后者 → 就业；喜欢公司模型研究但本科岗位层级有限 → 先 PhD 再进研究团队。
