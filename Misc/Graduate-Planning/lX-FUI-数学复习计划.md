## 一、考纲 vs 你的课程背景：差距分析

### 考纲结构（两大板块）

**1. ALGEBRA（代数）**

| 考纲条目 | 你的课程基础 | 差距 | 优先级 |
|----------|------------|------|--------|
| 1.1 集合论 | ✅ 基础常识 | 无 | 🟢 |
| 1.2 数与代数结构（群/环/域、等价关系、Z/nZ、多项式根与系数） | ✅ 抽象代数（群/环/域/Galois/中国剩余定理） | 少量：复指数在几何中的应用 | 🟢 |
| 1.3 有限维向量空间（基底、维数、行列式、矩阵、线性映射、秩） | ⚠️ 只在 R^k/C^k 中学过 | **抽象向量空间形式主义**（考纲星号警告！） | 🔴 |
| 1.4 自同态约化（特征值/特征向量、特征多项式、Cayley-Hamilton、对角化） | ⚠️ 数值代数接触过计算层面 | 理论层面需加强 | 🟡 |
| 1.5 欧氏空间（内积、Cauchy-Schwarz、正交投影、正交群、正交矩阵、实对称矩阵对角化） | ⚠️ 数值代数接触过 | 需补欧氏几何的抽象处理 | 🟡 |

**2. ANALYSIS AND DIFFERENTIAL GEOMETRY（分析与微分几何）**

| 考纲条目 | 你的课程基础 | 差距 | 优先级 |
|----------|------------|------|--------|
| 2.1 有限维赋范空间的拓扑（开集/闭集/紧集/范数等价） | ✅ 点集拓扑 + 实变函数 | 几乎无缝衔接 | 🟢 |
| 2.2 单变量实/复函数（导数、Taylor公式、函数项级数收敛） | ✅ 复变函数 + 数学分析 | 函数项级数一致收敛需复习 | 🟡 |
| 2.3 有界区间上的积分（微积分基本定理、分部积分、含参积分） | ✅ 数学分析 | 含参积分求导需复习 | 🟢 |
| 2.4 数值级数与幂级数（收敛判别、幂级数收敛半径、Taylor 展开） | ✅ 复变函数 | 需复习展开技巧 | 🟡 |
| 2.5 微分方程（一阶/二阶线性方程、常系数线性方程组、常数变易法） | ✅ ODE 课程 | 几乎全覆盖 | 🟢 |
| 2.6 多元函数（偏导数、链式法则、Schwarz定理、反函数定理、临界点、曲线/曲面切线） | ⚠️ 可能部分接触 | **反函数定理、微分几何部分**需补 | 🔴 |

### 差距总结

**三个红色区域（必须补）：**
1. 🔴 **抽象向量空间**（1.3）— 考纲星号警告，中国学生典型短板
2. 🔴 **多元微积分 + 微分几何**（2.6）— 反函数定理、临界点、曲线弧长/曲率、曲面切平面
3. 🟡 **自同态约化 + 欧氏空间的抽象处理**（1.4-1.5）— 你在数值代数层面学过，但口试需要理论证明能力

**你的优势区域：**
- 拓扑（2.1）— 你的点集拓扑基础超出了考纲要求
- ODE（2.5）— 你的 ODE 课程基本覆盖考纲全部内容
- 代数结构（1.2）— 抽代基础扎实
- 积分理论（2.3）— 实变函数给了你超出要求的深度

## 二、复习阶段规划

### 阶段 0：摸底测试（8月5日 - 8月8日，3天）

**目标：** 确认实际水平，校准后续计划

- [ ] 找一套 l'X FUI 或法国 prépa 往年口试题做摸底
- [ ] 找一套全国大学生数学竞赛往年题（数学类）做摸底
- [ ] 记录每个考纲条目的真实掌握程度（1-5分自评）

### 阶段 1：补短板（8月9日 - 9月10日，约4.5周）

> 这是最关键的阶段。同时兼顾 FUI 考纲和数学竞赛的重叠区域。

**Week 1-2（8/9 - 8/22）：抽象线性代数 + 矩阵理论**

| 日 | 主题 | 具体内容 | 参考资源 |
|----|------|---------|----------|
| 8/9-10 | 抽象向量空间 | 线性空间公理、线性无关/生成集/基底/维数、子空间 | Obsidian 笔记 [[线性空间]] [[线性变换]] |
| 8/11-12 | 线性映射与矩阵 | 线性映射的矩阵表示、基变换、像与核、秩-零度定理 | 同上 + 数值代数笔记 |
| 8/13-14 | 行列式理论 | 抽象行列式（多重线性/反对称）、余子式展开、行列式与可逆性 | 复习数值代数对应章节 |
| 8/15-16 | 自同态约化 | 特征值/特征向量、特征多项式、Cayley-Hamilton、对角化判据 | 做 10 道对角化证明题 |
| 8/17-18 | 欧氏空间 | 内积空间、Gram-Schmidt、正交投影、最小二乘法 | — |
| 8/19-20 | 正交矩阵与对称矩阵 | 正交群 O(E)、实对称矩阵的正交对角化、二次型 | — |
| 8/21-22 | 阶段总结 | 综合练习 + 做一套线性代数综合题 | — |

**Week 3（8/23 - 8/29）：多元微积分 + 微分几何**

| 日 | 主题 | 具体内容 |
|----|------|---------|
| 8/23-24 | 多元函数微分学 | 偏导数、全微分、链式法则、Schwarz 定理 |
| 8/25 | 反函数定理 + 隐函数定理 | 证明思路 + 经典应用 |
| 8/26 | 临界点与极值 | 局部/全局极值、Lagrange 乘数法、Hessian 判别 |
| 8/27 | 平面曲线 | 参数曲线、切向量、弧长、曲率 |
| 8/28 | 曲面 | R³ 中曲面、切平面、法向量 |
| 8/29 | 阶段总结 | 综合练习 |

**Week 4-5（8/30 - 9/10）：分析深化 + 函数项级数**

| 日 | 主题 |
|----|------|
| 8/30-31 | 函数项级数：一致收敛、Weierstrass 判别法、极限与积分/求导交换 |

| 9/5-6 | 数值级数综合复习：正项级数/交错级数/绝对收敛/条件收敛全套判别法 |

### 阶段 2：强化训练（9月11日 - 10月10日，约4.5周）

> 10月10日是 FUI 资格结果公布日。在此之前应该把所有考纲内容过一遍。
> 这一阶段同时是数学竞赛的黄金准备期。

**Week 6-7（9/11 - 9/24）：分模块刷题**

每天 2-3 小时，每个模块做 15-20 道中等难度题：

- [ ] 代数模块：线性代数证明题（对角化、不变子空间、正交矩阵性质）
- [ ] 分析模块：级数收敛判别、Taylor 展开、含参积分
- [ ] 微分方程模块：各种类型的 ODE 求解
- [ ] 微分几何模块：曲线/曲面计算题
- [ ] 每周末做一套综合卷（3小时模拟）

**Week 8-9（9/25 - 10/10）：真题实战**

- [ ] 刷法国 prépa oral 题（mathématiques concours X/ENS）
- [ ] 刷全国大学生数学竞赛往年题（数学专业组）
- [ ] 重点训练口试风格的题目：给出一个题目，口头推导 + 板书
- [ ] 训练英语/法语数学术语表达

### 阶段 3：口试模拟（10月11日 - 11月1日，约3周）

> 假设资格通过，进入口试准备。

- [ ] 每两天做一次完整的 55 分钟口试模拟
  - 准备阶段（如有）：阅读题目，整理思路
  - 口述推导：像给一个同学讲题一样，把思路说出来
  - 面试官追问：准备应对 follow-up questions
- [ ] 用英语练习数学表达（如果选英语口试）
- [ ] 准备第二部分（动机/科学好奇心/通识）的谈话要点
- [ ] 复习自己成绩单上每门课的核心内容

### 阶段 4：冲刺（11月2日 - 口试日）

- [ ] 轻量复习，保持手感
- [ ] 回顾错题本
- [ ] 调整心态，保证睡眠

## 三、推荐参考资源

| 用途 | 推荐教材 | 说明 |
|------|---------|------|
| 线性代数（抽象） | Lang《Linear Algebra》或 Friedberg《Linear Algebra》 | Friedberg 偏计算+证明平衡，Lang 更抽象 |

| 多元微积分 | Zorich《数学分析》第二卷相关章节 | — |

### 数学竞赛 vs FUI 考纲的重叠与差异

| 板块 | 数学竞赛 | FUI | 重叠度 |
|------|---------|-----|--------|
| 数学分析 | ✅ 核心考察 | ✅ 考纲 2.2-2.4 | 高 |
| 线性代数 | ✅ 核心考察 | ✅ 考纲 1.3-1.5 | 高（但 FUI 更重抽象理论） |
| 实分析/测度论 | ✅ 竞赛会考 | ❌ 不在 FUI 考纲 | 低 |
| 抽象代数 | ✅ 竞赛会考 | ✅ 考纲 1.2（但 FUI 只到基础群环域） | 中 |
| 微分方程 | ⚠️ 偶尔考 | ✅ 考纲 2.5 | 中 |
| 微分几何 | ❌ 几乎不考 | ✅ 考纲 2.6 | 低 |
| 解析数论 | ⚠️ 偶尔考 | ❌ 不在 FUI 考纲 | 低 |
| 组合/概率 | ✅ 竞赛会考 | ❌ 不在 FUI 考纲 | 低 |

> 策略：以 FUI 考纲为主线，数学竞赛作为副产品自然覆盖大部分内容。竞赛独有的板块（组合、概率、解析数论）在 FUI 口试后再突击。

## 五、口试策略提醒

1. **Major 选数学**（最强项，系数8）
2. **Minor 选 CS**（天然优势，系数5）
3. 口试不是笔试——**思路的清晰表达**比计算的完美更重要
4. 法国人重视"mathematical maturity"——展示理解深度而非计算速度
5. 如果选英语口试，提前练习用英语讲解数学推导
6. 第二部分（动机/通识）不要忽视——这也是评分的一部分
