# 2026 年浙江大学学生社团年审注册与星级调整 · 材料清单

> 通知：https://zjutw.zju.edu.cn/2026/1022/c32290a3217938/page.psp （需浙大内网查看）
> 办理平台：tzzd.zju.edu.cn（统一身份认证登录 → 我的门户 → 办事流程 → 新建流程 → 社团管理）
> 提交与指导老师审核时间：**2026-10-22 至 2026-11-18 24:00**
> 逾期后果：暂停 2027 年社团评奖评优、基金申请

## 0. 先确认三件事

- [ ] 我们社团是否在《附件11：2026年浙江大学暂不参与星级调整社团名单》里？
  - 在名单里：只做「年审注册」，不参加星级调整（保留一星级）
  - 不在名单里：年审注册 + 星级调整两个流程都要做
- [ ] 我是不是社团主要负责人？（主要负责人 = 系统里登记的第一负责人；很多栏必须本人账号/本人签字）
- [ ] 社团指导老师、指导单位（学院/部门）分别是谁？签字盖章要提前约时间

## 1. 一句话结论

**必须本人做的**：登录并提交两个流程、填负责人本人信息、成绩证明、资格认定证书、最终上传和《社团资格证书》上交/补办。
**可以别人帮忙的**：活动/荣誉/财务/新媒体表单的收集整理、成员信息表、章程初稿、星级材料初稿、排版转 PDF、打印扫描跑腿。
**必须找别人签字/盖章的**：指导教师、指导部门、负责人所在院系辅导员/导师、院系党组织、指导教师所在单位党组织，以及成绩专用章。

## 2. 必须本人（社团主要负责人）亲自办

> 这些涉及本人账号、本人身份、本人证书，不能代签/代办。

- [ ] **登录 tzzd.zju.edu.cn**（本人统一身份认证），新建并最终提交：
  - [ ] 【学生社团年审注册流程】
  - [ ] 【社团星级调整申请流程】（若不在附件11）
- [ ] 填写/确认《社团登记表》中「主要负责人姓名、学院专业、联系方式、邮箱」等本人信息
- [ ] 填写《浙江大学学生社团负责人资格认证信息表》（附件4）本人部分：姓名、社团名称、拟任职务、籍贯、性别、政治面貌、思想表现、成绩排名、学院、年级、专业、联系方式、邮箱、照片
- [ ] **主要负责人成绩证明**（含排名：名次/总人数，需盖成绩专用章）——本人去学院教务/成绩证明窗口办理
- [ ] **主要负责人资格认定证书**——本人提供；如遗失，本人携带学生证或校园卡到尧坤楼 308 室补办
- [ ] 最终检查所有 PDF 的格式/清晰度，并在系统提交
- [ ] 《社团资格证书》上交：年审结果公布后按后续通知，**主要负责人携带学生证/校园卡到尧坤楼 308 室**办理（补办/注册盖章）

- [ ] 按模板起草/更新《浙江大学学生社团章程》（附件3）：填社团名称、指导单位、宗旨、活动内容与形式等
- [ ] 起草《2026年浙江大学学生社团星级调整申请表》（附件8）初稿

## 4. 必须找别人签字/盖章的清单

> 通知里的记号：
> - **签字（盖章）** = 相关责任部门/负责人签字 **或** 盖章（二选一）
> - **签字（及盖章）** = 签字 **和** 盖章都要有
> - 不得冒充、顶替、伪造签字；查实可注销社团

### 4.1 《浙江大学学生社团登记表》（附件2）
- [ ] **指导教师意见**：指导教师 **签字（盖章）**（签字或盖章二选一）
- [ ] **指导部门意见**：指导部门负责人 **签字（及盖章）**（签字 + 部门章，两者都要）
- [ ] 学生社团建设管理评议委员会意见：**不用自己跑**，材料上传后统一处理

### 4.2 《浙江大学学生社团负责人资格认证信息表》（附件4）
- [ ] **社团指导教师及部门意见**：**签字（及盖章）**（指导教师签字 + 部门章）
- [ ] **负责人所在院系辅导员或研究所导师意见**：**签字（盖章）**（签字或盖章二选一）
- [ ] **负责人所在院系党组织意见**：**签字（及盖章）**（签字 + 党组织章）
- [ ] 学校社团建设管理评议委员会意见：上传后统一处理

### 4.3 《浙江大学学生社团指导教师工作情况证明》（附件5）
- [ ] 指导教师本人填写姓名、所在单位、是否指导其他社团、职务、是否主要指导教师、岗位类型、政治面貌、手机、邮箱、照片
- [ ] **所在单位党组织意见**：**签字（及盖章）**（签字 + 党组织章）
- [ ] 学校社团建设管理评议委员会意见：上传后统一填写，不用自己跑

### 4.4 《2026年浙江大学学生社团星级调整申请表》（附件8）
- [ ] **指导教师意见**：**签名（或盖章）**（二选一）
- [ ] **指导部门意见**：**签名及盖章**（签名 + 部门章，两者都要）
- [ ] 学生社团建设管理评议委员会意见：上传后统一处理
- [ ] 负责人填写调整意向：升星 / 保星 / 跳星（仅一星社团可申请跳星）

### 4.5 成绩证明
- [ ] **成绩专用章**：教务处/学院教务部门盖章（含排名：名次/总人数）

### 4.6 章程及其他材料
- [ ] 通知要求“年审注册流程中所有相关文件需进行盖章处理”；章程如指导单位有盖章要求，按指导单位意见办理
- [ ] 所有材料需用最新模板、字体统一，上传前转 PDF

## 8. 特别提醒（容易踩坑）

- [ ] 所有文件必须用**最新模板**，字体统一，上传前转 **PDF**，避免系统乱码
- [ ] 签字栏不能代签、冒充、伪造；查实会注销社团
- [ ] 负责人资格：综合排名专业前 50% 以内 **或** 平均绩点 ≥ 3.5；必修课不及格且未重修/补考未通过者不得担任
- [ ] 同一人不得同时担任多个社团的主要负责人
- [ ] 1 名教师原则上最多担任 2 家社团的主要指导教师；思政类/志愿公益类主要指导教师原则上应为中共党员
- [ ] 若社团拟注销：走【学生社团注销申请流程】+ 附件6，时间另行通知
- [ ] 《社团资格证书》补办：主要负责人带学生证/校园卡到尧坤楼 308 室，时间等后续通知
