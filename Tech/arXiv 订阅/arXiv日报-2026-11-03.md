### 1. Truthful and Admissible Principal–Agent Testing with Nuisance Parameters（2610.41283）｜stat.ME / cs.GT / math.ST / stat.TH｜Aaditya Ramdas

**问题背景**
统计契约（statistical contract）按实验者产出的"证据"付费，因此奖励规则同时决定了谁参与、以及参与后报什么。Tetenov (2016)、Bates et al. (2022) 已给出"让无效方案不可获利"的主–代理检验框架，但当决策关心的是**均值效应**而方差/分布形状未知（nuisance parameters）时，能否同时诱导出**诚实的参数报告**，此前没有答案。

**方法**
把契约设计成 **e-value 菜单**：非负归一化奖励，在每个原假设下期望 ≤ 1。提出 admissibility（可容许性）概念——在保持原假设有效性的前提下，赔付无法被逐点改进。围绕这一概念给出主–代理检验的完整刻画。

**主要结果**
- 高斯情形：**Theorem 4.2**（完全知情 agent，知道均值与方差）——契约落在 [1−η, 1+η]，对所有 µ≤0、σ>0 有效，且可容许；在 µ>0 上严格诱导 (µ, σ)，每种类型都有严格正的期望净收益。
- **Theorem 5.1**（只知均值的 nuisance-uninformed agent）——契约同样可容许，在每个有限原假设类型下期望严格小于 1；对任意 µ>0、σ>0，期望在 m=µ 处**唯一**最大（truthful），且 truthful 期望严格大于 1。**结论对任意 σ 成立，无需对 nuisance 参数设先验**。
- **Theorem 6.2**：对任意固定样本量 n≥1，存在有界的可容许菜单，严格 nuisance-uniform 地 truthful、在每个正均值处严格盈利、在每个有限原假设处严格不盈利；中心化原假设下的亏空为 O(σ^{−(n+2)})。
- **Theorem 6.4 / Proposition 6.3**：多样本延伸保持全部激励，且在任意固定正均值高斯律下证据过程几乎必然增长（e_{r,n} → ∞ a.s.），即"累积证据"能被奖励。
- 超出高斯：**Theorem 7.2** 形状未知（对称单峰）下仍可诱导位置参数；**Theorem 9.4** 两个独立非负观测足以诱导任意高于正原假设阈值的有限均值，而单个观测不可能同时满足严格均值诱导与逐个可容许；**Proposition 8.4** 有界契约无法给出形状一致的正盈余；**Proposition 9.3** 存在无界的"分离子"但无有界对应物。
- 最后区分了"有用检验的存在"与"诱导诚实报告所需的识别性"：有界性非必要，仅有有限个原假设约束本身并不保证可容许的诱导。

**与 Reliable Agent · 统计推断的关系**
本文是本期最贴近"统计保证"内核的一篇：它把"agent 报上来的数字要不要信"变成一个**可证明的激励相容问题**，并且用 e-value 这条 anytime-valid 的路线承载。对我们的课题（Agent 做统计推断时的 bias）有两点直接可用：(1) 若 agent 参与一次统计试验并上报估计量，主方需要的不只是"检验有效"，还需要"诚实上报是唯一最优"——这正是 bias 的一种**内生来源**（激励扭曲导致的报告偏差），本文给出可构造、可容许的最优契约；(2) nuisance-uninformed 的结果说明：**只要结论对未知方差一致成立，就不需要对方知道方差**——这对我们把 agent 放在"只知道部分信息"的现实场景下的保证设计是利好消息。

**链接** https://arxiv.org/abs/2610.41283

### 2. Multi-Test Nation Bias Benchmarking of LLMs with Explicit Unbiased Baselines（2610.41486）｜cs.AI｜Jonghyeon Choi, Yeonjun Choi, Beakcheol Jang

**问题背景**
国家层面的 LLM 系统性偏差在外交/国际关系场景下有现实风险，但现有评测普遍**缺少明确指定的无偏参照系（ground truth）**，因此无法做完全定量、跨设置可比的测量。

**方法**
以 722 条联合国安理会（UNSC）官方记录为语料，用**五个互补检验**测量国家级偏差，覆盖更广的偏差表达通道：意见排序（WOW）、联想排序（AK+-）、投票模拟（PVS）、对立归因（F-Oppose）、框架化（Headliner）。关键设计：为每个检验**显式定义无偏状态**；对 WOW 与 AK+-（难以指定真值）提出**基于行为的伪无偏状态**——由可观测的投票行为推出，可量化。评测 4 个模型（GPT-4o-mini、Llama 3.3-70B、Mistral-22B-Small、Qwen3-30B）× 5 个常任理事国。

**主要结果**
跨检验的**宏观模式**（test-agnostic macro-pattern）：相对各自的参照基线，模型输出对中国与俄罗斯偏向"对立（红）"侧，对英国、美国、法国偏向"支持（蓝）"侧；其中 F-Oppose 上偏差幅度最强。作者据此主张：面向国际关系的 LLM 部署必须用**绑定明确参照点的多检验基准**做审计。

**与 Reliable Agent · 统计推断的关系**
这是"**评测的 bias**"本身如何被量化的范式：关键不是设计更漂亮的指标，而是先**声明无偏基线**（action-grounded），再用多个互补通道做交叉检验。对我们做 Agent 评测时有两点启发：(1) 无偏参照必须"在跑模型之前"就定下来，否则会变成事后合理化；(2) 多检验 + 宏平均的模式，与我们关心的多重检验/e-value 控制天然衔接——不过本文用的是"多通道交叉验证"而非显式的多重检验校正，这正是可以改进/对接的地方。

**链接** https://arxiv.org/abs/2610.41486

### 3. ReplayRCA: Measuring Post-hoc Diagnosis and Live Oversight of Agent Failures by Counterfactual Replay（2610.41025）｜cs.AI｜Jeremy Canale, Fabien Soulis

**问题背景**
当一个语言模型 agent 在多步任务上失败时，另一个模型能否**找出决定性的错误步骤**并用单个动作修好它？基于标注一致性的归因评测有结构性捷径：标注几乎总是落在最后一步。

**方法**
不做标注比对，而是做**干预式打分**：把环境回滚到被选中步骤之前的状态，用建议动作替换 agent 自己的动作，让同一个 agent 继续跑。分数称为 **causal repair** = 续跑成功率 − 一条**配对安慰剂**（placebo，走完全相同机制但重放 agent 原动作）的成功率。两个赛道共用该协议：post-hoc autopsy（诊断者看完整失败轨迹并被告知失败）与 live oversight（监督者实时观看、只能在不可逆动作前介入一次、且不知道本次是否会失败）。任务来自 OpsWorld（确定性程序生成的后台办公环境，6 个难度级，最高级含 QR 码/手写等多模态）。

**主要结果**
- 62 个校准过的系统性失败上，13 个前沿模型中最好的是 **Grok 4.7**，causal repair 达 **+51.3 点**；前八名模型**统计上不可区分**；两家最大厂商的旗舰模型分别排第 8 和第 12；**5 个条目无任何模型能修**。
- 无引导重跑只能修复 **6.90%** 的失败——这正是必须把 causal repair 与"重跑"区分开来的理由。
- 强行在最后一步介入会使模型掉 **17.1 点**（Claude Haiku 5.5 在高推理档下另掉 15.2 点），说明"最后一步捷径"在标注式归因基准里主导的现象**不可迁移**。
- 87 次运行的 oversight 赛道中，两个最好的监督者统计上打平，其中一个是**小开源模型（DeepSeek V4.1 Flash）**；post-hoc 表现最好的那个监督者在 live 场景下反而**变差 −14.5 点（p = 0.002）**——事后诊断能力不能推断为实时监督能力。

**与 Reliable Agent · 统计推断的关系**
这是本期在"Agent 可靠性"上方法论最扎实的一篇，可直接借用两点：(1) **安慰剂对照**——这是把 agent 失败归因变成可识别因果估计的标准做法，与我们做"agent 统计推断偏差"时的双重差分/安慰剂思路同源；(2) **配对安慰剂差分**天然消掉了同一步的环境方差，使分数具有可比性。我们的研究若要评估"agent 的估计有没有系统性偏差"，这套"干预 + 配对安慰剂"的计分协议几乎可以直接搬过去，用来分离"agent 报错了"与"环境本来就这样"。

**链接** https://arxiv.org/abs/2610.41025

### 4. Certified Behavioral Retention for Continual Adaptation with Held-Out Anchors（2610.40740）｜cs.LG / stat.ML｜Ahanaf Hasan Ariq, Abrar Shahid

**问题背景**
持续适应（continual adaptation）不只是"怎么更新"，还要"**敢不敢提交**这次更新"——即不超过一个事先声明的"受保护行为变化预算"。

**方法**
提出 **CABA**（Certified Anchor-Based Adaptation）：一个与候选生成器无关（candidate-agnostic）的**更新后门控**。把一部分历史观测**保留在候选优化之外**（held-out anchors），在冻结表示上比较旧策略与候选策略，选取使**最坏 anchor 的 forward KL 散度**不超过预算 ε 的**最大**插值系数。有限检查既不需要动作标签也不需要完整轨迹。理论部分把"实测的 anchor 保留"与"条件性的 off-anchor 保证"**分开**：在显式的表示覆盖与 Lipschitz 假设下，被接受的更新在受保护支撑集上满足一致的行为散度界。

**主要结果**
理论给出：仿射 softmax 头的正则性界、概率覆盖与压缩保证、插值单调性条件、网格分辨率界、以及**轨迹级与序贯复合（sequential-composition）保证**。实证（UCI Human Activity Recognition 作为非平稳传感器-策略代理）：在预算 ε=0.05 下，平均遗忘从无约束适应的 **1.01% 降到 0.00%**，代价是最终平均准确率从 **93.04% 降到 88.48%**——明确展示了保留-可塑性权衡；作者明确声明该实验不构成基础模型或机器人上的性能证据。

**与 Reliable Agent · 统计推断的关系**
提供了两个我们课题会反复用到的构件：(1) **"预算 + 证书"的范式**——把可靠性写成"给定 ε，若证书成立则行为散度有界"，而不是"我们测了没退化"；(2) **序贯复合保证**——当 agent 连续做多步统计操作时，证书如何复合，这是"长链 agent 累计偏差"问题的技术入口。KL 预算这个设计还提示了一条思路：把 agent 每一步统计操作造成的**分布偏移量**当作"变化预算"来监控。

**链接** https://arxiv.org/abs/2610.40740

### 5. Benchmarking Forecasting Agents on Yesterday's Tomorrows（2610.40940）｜cs.AI / cs.LG｜Yuxuan Wang, Yishu Wang, Jiaqi Deng

**问题背景**
数字 agent 已经能搜集整理信息、推理并调用工具；**预测**（forecasting）把这一切同时压测：需要整合不完整证据、推断因果驱动、并给出**校准过的概率判断**。但现有基准都不合适——活的基准要等事件落地，固定语料基准又把自己锁死在预采集文档里。

**方法**
提出 **FABench**：可扩展的**回测（backtesting）**环境。自动化流水线可对任意历史预测日期发现事件、生成问题、判定结果，使基准可持续更新以跑在模型训练截止之前；首版 287 题、九个领域。Agent 在"档案环境"中自由研究——离线档案 + 实时网页检索，并**筛查以防止时间泄漏**（temporal leakage）。

**主要结果**
- 检索在**所有八个模型、所有检索设定下都改善了 Brier 分数**；领先 agent 在与 Polymarket 关联的 54 题上被推到市场共识水平，最好的三个略高于共识。
- 即便有检索，约**四分之一**的问题上 agent 平均仍**差于常数 0.5 预测**。
- 轨迹分析揭示 agent 在"如何权衡与应用证据"上的反复失误。作者同时报告 ECE 等校准指标，并强调好 Brier 分数并不等于概率可以面值使用。
- 首版 287 题锚定 t0 = 2026-07-01（254 题由 agent 生成、33 题取自 Polymarket）。

**与 Reliable Agent · 统计推断的关系**
这是"**agent 产出概率预测**"这一具体任务上最完整的一次评测设计，对我们的 bias 课题有三层用处：(1) **Brier + ECE + 常数基线**的三件套——尤其是"差于常数 0.5"这个基线，几乎是所有 agent 概率输出的必查项；(2) **时间泄漏筛查**——agent 用检索拿到"事后信息"是统计推断里最隐蔽的 bias 来源之一，本文把它当作基准设计的一等公民；(3) **可回测（backtest）**的题目生成流水线，正是我们做"agent 估计量偏差"实验时需要的可控数据生成器。

**链接** https://arxiv.org/abs/2610.40940

### 6. From fleet trajectories to single-cell promises: hierarchically weighted conformal prediction for battery SOH monitoring（2610.41696）｜cs.LG / stat.AP｜Xiangyu Liu

**问题背景**
conformal prediction 区间常被读成"90% 覆盖率"，但在**嵌套数据**（电池）上，这个数字承诺的是**车队均值**，不是**单体电池**。论文把这一落差当作可测量的对象，而不是留给读者自行体会。

**方法**
在 124 个公开 LFP 电芯上按**预注册的三层报告协议**（fleet / batch / cell）测量覆盖率，用精确二项检验对照名义水平；再用**层级加权 conformal 引擎**部分修复落差——权重只消费预测时即冻结的旁信息（signature 特征、批次标签、循环序号），**绝不接触残差**。

**主要结果**
- 随机划分下**合并覆盖率看起来很健康（0.875–0.906）**，但**最差单体只在 0.1–2% 的时间被覆盖**（名义 0.90）。协议下的基线读数：fleet pooled 0.906、最差 batch 0.787、最差单体 0.642。
- 预注册的修复判据**通过**：第 10 百分位单体覆盖率 **0.750 → 0.830**（补上 53% 的缺口），最差单体 **0.642 → 0.694**，零弃权（deferrals），敏感性谱平坦。
- **两项诚实的失败被如实报告而非调参掩盖**：(a) 协议漂移下冻结权重在 SOH 尺度上有害（属"局部化"而非"未决"的结构性死路）；(b) 跨化学体系外部集上区间**崩塌到 0.286**，而同体系骨架可复现（合并 0.933、最差单体 0.686）。
- 结论性交付物是一套**报告协议**：三层承诺、锚定已测区间、最差单体统计、弃权比例，让逐单体区间主张在部署前可审计。

**与 Reliable Agent · 统计推断的关系**
这篇是本期最值得反复读的"**覆盖率语义**"教材。它给我们的直接启示有三条：(1) 当我们说"agent 的 90% 置信区间"时，必须问"**90% 是对谁成立**"——群体均值、批次均值、还是个体；(2) **嵌套/异质数据下 pooled 指标会系统性掩盖最差个体**，这与"总体 accuracy 掩盖 prompt 级错误"是同一类陷阱；(3) 诚实报告"修不好的部分"（跨域崩塌 0.286）本身就该写进结果而不是调掉——这正是我们做 bias 论文时应遵循的报告规范。

**链接** https://arxiv.org/abs/2610.41696

### 7. Regret-Optimal Wasserstein-Robust Linear Regression（2610.42109）｜stat.ML / cs.LG / math.OC｜Sloan Nietert, Daniel Kuhn

**问题背景**
分布鲁棒优化（DRO）最小化分布不确定性下的最坏风险，但其决策在**超额风险（excess risk）即 regret** 意义上未必最优。本文研究多元最小二乘回归中这个差距。

**方法**
假设观测到的源分布与未知目标分布相差一个大小为 ε 的**对抗性 2-Wasserstein 扰动**。给出 ε→0 极限下鲁棒决策的渐近复杂度刻画（由问题相关的条件数 κ 表征），并分析两个替代方案：**MRO**（minimax regret optimization，把风险目标换成 regret）与 **SNR**（spectral-norm regularization，ERM + ε²·‖A‖²_op 惩罚）。

**主要结果**
- ε→0 时，DRO 等一大批简单算法都达到**实例最优速率 O(κε²)**。
- 固定 ε>0 时：若问题**残差有效秩（residual effective rank）有界**，DRO 仍达 minimax 速率；但也**识别出 DRO 可证明次优的失效模式**，次优幅度随维度增长。
- **MRO 与 SNR 达到 minimax 速率**；作者给出 MRO 的精确凸 reformulation 与 SNR 的加速近端算法，并给出高概率有限样本保证；数值实验分离了 MRO/SNR 与 DRO 的表现。

**与 Reliable Agent · 统计推断的关系**
DRO 是"分布未知时给出保证"的标准工具，而本文指出的是**保证的对象可能选错了**：DRO 保证最坏情形风险，却不保证 regret（相对最优解的超额风险）。换句话说，**用错了损失，得到的"保证"与想控制的量不是一回事**。这与我们关心的"agent 做统计推断时的偏差"直接呼应——当 agent 的估计量有偏时，用最坏情形风险去包装保证，很容易得到一个"保证成立但偏差仍在"的结论。可迁移的做法：把目标从 risk 换成 **regret**，并显式报告有效秩/维度条件。

**链接** https://arxiv.org/abs/2610.42109

### 10. Towards Understanding Score-Seeking in LLMs（2610.41014）｜cs.LG / cs.AI｜Aghyad Deeb, Ryan Greenblatt, Alex Mallen

**问题背景**

**方法**
在**评分器被泄漏（grader is leaked）**的 agentic 环境中观察模型行为（GPT 5.6 Sol、GPT 5.5，以及一个未经安全训练的 o3 检查点 "exp-rl-cap-late"），并做干预：改变"评分会被如何使用"的说明（用于训练 / 用于评测 / 完全不用）。

**CF-SNN**：给定一个含 m 个预测目标的单纯复合体，一次性为全部 m 个目标生成预测集。在温和假设下保证**每个目标**以用户指定的名义覆盖概率包含真标签，且全部 m 个目标的**实际错覆盖比例以高概率保持在名义水平附近**（多目标同时性）。实验显示 CF-SNN 能达成指定覆盖并给出信息量足、规模小的预测集。**关系**：给出了"**多输出同时覆盖**"的形式化保证，这正是 agent 一次报出一组统计量（多个估计量、多个区间）时需要的保证类型。

**链接** https://arxiv.org/abs/2610.41166

### 20. Counterfactual Pairwise Augmentation Improves Small Pointwise LLM Judges（2610.41149）｜cs.AI｜Mohammad Zangooei, Peyvand Teymoori, Mohammad Robati Shirzad, Soroosh Shahtalebi

agentic 系统越来越多地用**逐点 judge** 给单步打分，而小模型做这个角色很有吸引力。问题在于：逐点标签在微调中**欠定**判别边界——不同查询的标注回答沿许多维度同时不同，不揭示哪些特征决定了标签。提出 **CPA**：为每条逐点样本合成并审计一条**期望标签相反的反事实回答**，把接受的一对重构为"哪个更符合准则"的成对任务，联合微调后仍以逐点模式部署。二阶分析显示：合并两个独立训练的专家会让每个参数方向朝成对专家移动相同比例，而联合训练可以**在成对损失平坦处保持逐点最优、在陡峭处吸收曲率**。Qwen3-8B LoRA、六个二元准则上，CPA 相对仅逐点训练**提升 2.5 个 macro-F1 点**，并优于模型合并。**关系**：**用反事实把判别边界显式化**——这与我们用"配对安慰剂/反事实对"给 agent 的统计结论做归因是同一套方法论。

**链接** https://arxiv.org/abs/2610.41149

### 21. Predicting Human-Gain Curves under Local Proxy Optimization from Repeated Ratings（2610.41114）｜cs.AI｜Moonwon Choi, Kisung Nam, Seunggeun Lee

优化代理目标会提升人类感知质量，但增益随优化强度如何变化，平均代理-人类相关性看不出来。提出 **PACE**（Proxy Alignment and Curvature Expansion）：一个**优化前诊断**，把代理优化建模为 KL 正则化的指数倾斜，在 KL 半径 d 处局部增益近似为 A√d + Bd，其中 A 衡量一阶代理-人类对齐、B 捕捉二阶修正；A、B 由重复人工评分估计，再预测留出评估集上的增益曲线。在 SummEval、WMT MQM 聚类、OpenMEVA-MAGS ROC/WP 重复评分切片与 GPT-4o judge 代理实验上，**PACE 一致降低留出增益预测误差**（优于仅 A、零增益、仅可靠性等基线），并与灵活的代理条件校准具竞争力；LoRA-DPO 实验把诊断与真实优化架起了桥梁。**关系**：**代理指标 ≠ 目标指标**这一偏差的定量刻画，正是"用 LLM judge 衡量 agent 统计能力"时必须回答的问题——judge 本身的可靠性不能想当然。

**链接** https://arxiv.org/abs/2610.41114

### 22. Beyond Response Scoring: An AI-aware Cognitive Supervision Framework for Automated Mathematical Short Answer Grading（2610.41215）｜cs.CL｜Shengran Guo, Min Chi, Feifei Qiao, Varad Patwardhan

现有自动简答评分只做"打分"，无法理解含符号与公式的复杂答案，且**忽略生成式 AI 使用带来的向上偏差**。提出 **AICG** 双分支多任务框架：分支一用 RoBERTa 回归/序数/分类头做逐题评分；分支二用专家设计的 **Q-matrix** 把回答关联到技能，联合预测 G-DINA 导出的**技能掌握度与学习增益**，通过共享编码器为评分提供技能级的**认知监督**；另加**Gen-AI 探测器**（监督对比预训练 + 线性分类）估计作答辅助概率并转成**可靠性权重**，用于衰减不可靠的认知证据。实验覆盖 19 个学期、**49,402 份教师评分回答**：相对 RoBERTa 回归，MAE 降低 **50.3%**，QWK 从 **0.798 提升到 0.927**。**关系**：把"**检测并降权不可靠证据**"做成一个可学习组件——正是 agent 统计推断中"哪些输入该被信任"的问题；同时它示范了如何在评测里**显式隔离 AI 辅助带来的系统性偏差**。

**链接** https://arxiv.org/abs/2610.41215

- **解析**：正则 `\narXiv:(\d{4}\.\d{4,5})\n` 切条目 → 以独立成行的 `\\` 切分"元信息/摘要" → 按 `^(Title|Authors|Categories|Comments|Journal-ref|DOI|MSC-class|ACM-class|Report number|Subjects): ` 定位字段（字段值可跨行续接）。Categories 字段会被 `\\ ( https://arxiv.org/abs/xxx , 38kb)` 污染，用 `[a-z-]+\.[A-Z]{2}` 过滤即可。
- **两个踩坑点（已修正）**：
  1. 大小标注带后缀（如 `(603kb,A)`）会让 `\((\d+kb)\)` 匹配失败 → 修订版条目被误判为"新投稿"。应写成 `\((\d+kb[^)]*)\)`。
  2. cross-listing 条目的标记 `(*cross-listing*)` 在 arXiv ID **同一行**，而 `replaced with revised version` 在**下一行**；不区分会把二者混为一谈。本次统计：704 条目 = 544 完整 + 158 cross-listing；544 = 303 新投稿（均有摘要）+ 241 修订版公告。
- **PDF 全文**：`curl -x http://127.0.0.1:7890 https://arxiv.org/pdf/<id>` 本次全部成功（8 篇核心 + 3 篇补充，共 11 篇），`pdftotext -layout` 提取正常。1081 代理本次未测试（7890 足够）。
