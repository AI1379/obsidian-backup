## Knowing When to Intervene: Causal Evaluation of AI Agents（2611.09792）｜cs.AI cs.LG econ.EM stat.ME｜Ayush Sawarni, Wenqian Xing, Tijana Zrnic, Ramesh Johari, Vasilis Syrgkanis

**问题背景**：现有 agent 评测主要依赖 benchmark，但静态基准无法回答部署时「这次干预值不值得做」——人工复核当前输出、用更贵的模型监督、或 agentic 监督。干预的价值本质上是一个因果问题：干预对最终结果的因果效应有多大。且问题具有动态性：干预的影响取决于当前上下文与环境，以及 agent 后续的行为。

**方法**：提出第一个有方法论根基的框架，在 agent 轨迹内评估随机干预的因果效应。只需少量在随机干预（如 verification、screening）下采集的轨迹数据，即可估计一大类（上下文相关的）干预策略的动态因果效应。估计出的结构参数还可用于构造「安全排行榜」，捕捉各类 agent 动作的风险，供实务者排定审计优先级。

**主要结果**：在 tau-bench Retail、ToolSandbox 与 ImpossibleBench 上，干预效应在不同 agent 动作与状态之间差异极大——一刀切地审计某类动作没有意义，必须条件化到具体状态。

**与 Reliable Agent · 统计推断的关系**：这就是「agent 评测要用因果推断」的样板，与你的课题同构：评估「介入 / 引导」对 agent 统计推断结果的影响，本质是动态处理效应估计。它同时示范了因果量如何直接变成可排序的审计优先级，而不是停留在一个显著性检验上。

**链接**：https://arxiv.org/abs/2611.09792

## On the Reliability of Majority-Vote Pseudo-Labels in Test-Time Reinforcement Learning（2611.09872）｜cs.AI｜Haoyu Wang, Ru Wang, Yuanyuan Wang, Jiaxian Guo, Mingming Gong

**问题背景**：测试时强化学习（TTRL）用自生成伪标签在无标注目标域上适配预训练模型，而这些伪标签的可靠性一直缺乏系统理解。

**方法**：针对 online DPO 下的多数票监督做误差分析，把它分解为 **population-majority bias**（群体多数偏置）与 **prompt-dependent finite-rollout variation**（依赖提示的有限 rollout 波动）。作者明确指出：群体多数偏置在没有外部监督时通常**不可识别**（unidentifiable），因此转而缓解有限 rollout 波动的下游影响——提出 Prompt-Conditional Distributionally Robust DPO（PC-Dr.DPO），按观测到的投票可靠性做提示条件化的分布鲁棒重加权，使采样敏感的提示贡献更保守的更新；并引入缓存机制减少在线适配中的自监督遗忘。

**主要结果**：在 6 个数学与知识密集推理基准、5 个模型骨干上，PC-Dr.DPO 在 30 组设定中的 24 组达到或超过最强 TTRL 基线。

**与 Reliable Agent · 统计推断的关系**：这是「偏差分解 + 可识别性边界」的教科书式处理，也是你课题最直接可借用的范式：把 agent 的误差拆成「可识别部分」与「无外部监督不可识别部分」，并且只对前者做统计修正、绝不假装能修好后者。自生成伪标签 / 多数票就是 agent 的伪标签，其偏置项与不可识别性边界必须写进结论，而不是用更强的正则化掩盖过去。

**链接**：https://arxiv.org/abs/2611.09872

## High-Dimensional Off-Policy Evaluation without Sample Splitting using an Onsager Correction（2611.08794）｜stat.ML cs.LG math.ST stat.TH｜Saksham Jain, Guillaume Braun, Masaaki Imaizumi

**问题背景**：off-policy evaluation（OPE）的奖励模型通常用留出数据选择。当样本量与上下文维度同阶增长时，「全样本拟合的模型」与「固定比例子样本拟合的模型」之间的测试风险差**未必**趋于零。留出评估能一致估计小样本模型的风险，但候选奖励模型的相对排序在全数据重拟合后可能改变，因此留出选择可能是次优的。

**方法**：提出 Onsager 修正的、目标策略加权的准则，仅用训练观测即可估计全数据奖励模型在目标策略下的样本外风险，从而支持沿全数据梯度下降轨迹做 early stopping 而**无需样本分割**。在固定深度与隐层宽度的神经网络、高斯上下文、single-index 奖励、上下文依赖的 multi-index 目标策略、已知上下文无关的 logging 等假设下，证明该准则在固定有限个梯度下降迭代点上的一致性，以及所选奖励模型的近 oracle 保证。同一修正还导出**双重稳健估计量**：即使奖励模型的预测误差不消失，也能一致估计真实策略价值。

**主要结果**：实验显示在固定样本-维度比下维度增大时风险估计误差下降；相对留出基线，奖励模型选择有所改进；该修正还降低了「用同一份数据既拟合又选择奖励模型」所得双重稳健价值估计的 RMSE。

**与 Reliable Agent · 统计推断的关系**：这是「用同一批数据做选择与评估」这一 agent 评测常见自欺的统计版本，并给出了 Onsager 修正与无样本分割双重稳健估计两条出路。特别值得注意的是「重拟合导致排序翻转」——agent 反复迭代改进 prompt / 策略时正踩这个坑：看起来最优的那个，未必在最终全量重训后最优。

**链接**：https://arxiv.org/abs/2611.08794

## Copies Are Not Confirmations: How News Duplication Fools LLM Judges and Continual Learners（2611.09203）｜cs.LG cs.CL｜Abdelkader Metales, Miriam Grabenheinrich, Aicha Metales

**问题背景**：许多关于某主张的新闻报道其实是同一来源的副本（通讯社稿、同一媒体集团内部转发、联合供稿、新闻稿）。LLM 裁判与持续学习器会不会把副本当成独立的确认？

**方法**：在 20 万篇英文 CC-News 文章上用 MinHash 检测器链接近重复（去掉样板文字后精度 0.97），链接到 92% 的编辑转载及其原文，但不链接 phi4 / Llama 3.2 / Gemini 2.5 Flash 的 LLM 改写。随后做干预实验：给裁判看同一主张的三份**相同转载**而非一份，并附上「这些报道来自同一来源」的说明；在模拟的持续学习流中，每条被检测到的复制链只给一份报告。另外设计了一个「实体缺失」检验：某报告中的具名实体有多少在更早的相似报告中缺失。

**主要结果**：Llama 3.2 3B 与 phi4 14B 接受的谎言比例从 **0.06 升至 0.71**、从 **0.21 升至 0.90**，且无视「同一来源」的说明；Gemini 2.5 Flash 单份就信，Gemini 2.5 Pro 会遵循来源说明与表格。在持续学习流中，每链只给一份报告使被接受的复制谎言减少 **0.10–0.24**（4 个裁判），代价是接受真话下降不超过 4.2 个百分点。实体缺失检验以 **AUC 0.98–0.99** 区分 LLM 改写与 100 篇独立报道（误报 1 篇）；在改写网络的漏检模式下，把被接受的改写副本谎言从 **0.67 降到 0.20**（改写者编造细节时为 0.40）。作者结论：数报道或数链条本身不是可靠防御；来源信息是否起作用取决于裁判本身；共谋来源仍是未解难题。

**与 Reliable Agent · 统计推断的关系**：这是「伪重复 → 虚假确证」这一偏差最干净的实证，对应统计上的伪重复（把非独立样本当独立样本）。在 agent 场景里，多个 LLM judge 的投票、多个 agent 的报告、同一份检索到的证据被反复引用，都可能是同一信息源的副本——投票数并不等于独立信息量。文中还给出了可操作的防御（按复制链去重），这对「用多个 judge 投票做统计推断」是必须先做的一步。

**链接**：https://arxiv.org/abs/2611.09203

## Minimax designs and estimators for causal inference under network interference（2611.08560）｜math.ST stat.ME stat.TH｜Vishesh Karwa, Edoardo M. Airoldi

**问题背景**：网络干扰（一个单元的处理会影响到他人）之下的因果推断，线性因果 estimand 的最优设计与估计尚无统一的极小极大理论。

**方法**：建立**基于设计的极小极大理论**，对三类问题分别研究极小极大风险：固定设计下优化估计量；在受限类内同时优化估计量与设计；同时在所有设计上优化；对全部估计量与对设计无偏估计量分别研究。允许任意正确设定的 exposure mapping（包括恒等映射）。核心是把干扰下的因果推断表示为扩展有限总体（$\sum_i d_i$ 个潜在结果）上的**约束抽样设计**，用加权采样超图刻画：顶点是潜在结果，超边是可行处理分配下可联合抽样的最大潜在结果集合，权重由随机化设计诱导。三个问题的极小极大风险分别只依赖于设计诱导的加权超图、受限类内可达的加权超图集合、以及无权超图。Bayes 下界通过比较在「联合缺失潜在结果集合」上不同的势结果表得到：对全部估计量的下界由联合缺失概率决定，对无偏估计量的下界由相应比值（odds）决定。

**主要结果**：以无干扰下的平均处理效应、部分干扰下的饱和设计、邻域干扰下的 total / direct / contagion 效应、二分剂量-反应对比等情形说明该理论；若干设定下上下界匹配。

**与 Reliable Agent · 统计推断的关系**：把「干扰」与「设计」纳入同一个极小极大框架——这正是多智能体系统里「一个 agent 的行为影响其他 agent 的 outcome」的统计版本。对你的课题极有启发：若把 agent 交互图当作 interference 网络，「该不该给这个 agent 追加一次复核 / 干预」就是网络干扰下的设计问题；而 joint-missingness 决定下界也提示，日志中系统性缺失的部分会直接吃掉可识别性。

**链接**：https://arxiv.org/abs/2611.08560

## Verifier Noise Is a Temperature: Testing Tilt Predictions in Finite-Budget LLM-Guided Search（2611.09699）｜cs.LG cs.AI｜Xiaomeng Li

**问题背景**：LLM 引导的搜索循环不断提出候选、打分、保留更优者（如 prompt 优化器里的 minibatch acceptance gate）。这种「keep-if-better」迭代本身有可分析的平稳分布，但真正的问题在于：能不能用它**预测**有限预算下搜索究竟能提升多少？

**方法**：当两个候选每次都被重新打分、分数差为 logistic 且变异算子可逆时，keep-if-better 构成可逆马尔可夫链，其平稳律是按 $\exp(\beta f)$ 倾斜的变异平衡分布；对任意连续对称噪声差，小步长扩散极限有同样的倾斜律，$\beta = 4F'(0)$；minibatch gate 下 $\beta$ 随 minibatch 大小的平方根增长。缓存 incumbent 的分数则会让被记录的分数被抬高。作者把「倾斜预测」当作对 LLM 引导程序搜索的定量预测，**预测值在搜索开始前就用校准数据提交**，随后做注册检验（registered test）。

**主要结果**：150 步后的水平在 7 个设定中的 6 个随 minibatch 大小上升，但**预测值失败**：bin packing 上，当 proposer 改写 parent 时搜索只达到预测增益的 **62–88%**，当它写全新启发式时达到 **109–119%**；达成比例随未选中变异的 parent-child 质量相关性下降。两个新设定的注册检验确认了方向，但修正后未确认数值一致。另有注册检验发现从好程序出发的运行在 300 步内持续掉质量，且从搜索已选出的起点掉得更厉害（勉强通过注册规则）；不同起点的运行尚未收敛到同一水平，因此「倾斜是否刻画 LLM 编辑的平稳律」仍然开放。在冻结任务模型分数的 prompt 优化注册检验中再次失败：搜索超过倾斜预测，bin packing 的关系未能迁移。

**与 Reliable Agent · 统计推断的关系**：罕见的「预注册 + 预测失败」的诚实统计实践，正是课题里需要的范式——把 agent 搜索当作随机过程，先写下可证伪的定量预测（这里是一个带温度参数的倾斜律），再检验。它同时示范了现实的落差：理论只给出方向、不给出数值，agent 搜索的增益无法仅从打分噪声模型推出，必须实测。这对「理论界 vs 实际表现」之间偏差的度量方式很有警示价值。

**链接**：https://arxiv.org/abs/2611.09699

## One Run Is Not Enough: A Monte Carlo Protocol for Evaluating LLM Reliability on Data Science Tasks（2611.09729）｜cs.LG｜Wenqi Ni, Ozan Evkaya, and Miguel de Carvalho

**摘要要点**：提出 DS-QA 基准（100 道英国大学课程的数据科学与统计题，覆盖 16 个数据集、3 个难度等级）与三层评估框架——通用响应属性（运行时长、冗长度、文本相似度）、粗粒度指标（准确率、代码可执行性与完整性）、任务特定指标。用 **100 次重复运行的蒙特卡洛协议**评测 OpenAI 模型：在数据可视化与监督学习任务、尤其中等与困难难度下响应变异很大，说明必须在评估回答质量之外同时评估一致性；并给出冗长度关系：词冗长度比 +0.1 对应 token 冗长度比约 +0.013。

**与 Reliable Agent · 统计推断的关系**：直接针对「LLM 做统计 / 数据科任务」的可靠性——单次运行结果不可信，重复运行 + 蒙特卡洛协议才给出可信的均值与离散度，这正是评估 agent 统计能力应有的评测范式（与 2611.09872 的「多数票偏置」互补：这里度量的是跨运行一致性而非标签偏置）。

**链接**：https://arxiv.org/abs/2611.09729

## Definitions, Label Names, or Demonstrations? Auditing What Governs LLM Annotation（2611.09457）｜cs.AI｜Viraj Mishra, Shubham Gupta, Dhruv Gupta, Yuehong Cassandra Tai, and Qunhua Li

**摘要要点**：高准确率并不等于模型真正遵循研究者给出的类别定义——预测可能只反映标签名或示例的先验关联。提出**反事实审计**：在输出标签之间重新分配定义，从而区分「遵循所给定义」与「保持数据集原有映射」。在三个政治文本数据集上，模型很少遵循被重分配的定义；标准微调强化了原有映射，却不必然提升对定义的遵循。再研究检索增强标注：检索最近的训练样本（不分类别）通常优于分类别检索，即便使用的示例更少；在两个收益显著的任务上，直接 kNN 分类恢复了 **74–93%** 的改进，说明邻域标签提供了大部分预测信号。重标注固定示例可以改变预测，而把示例与重分配的定义对齐则显著提升对新映射的遵循。

**与 Reliable Agent · 统计推断的关系**：LLM-as-judge 的经典偏差来源清单——定义、标签名、示例、检索、训练数据必须联合对齐并验证。对「用 LLM 做标注 / 评判、再据此做统计推断」的流程，这是必须先做的审计：否则下游所有推断测的是仪器（模型对标签名的先验），而不是目标（研究者定义的构念）。

**链接**：https://arxiv.org/abs/2611.09457

## Reweighting for Transfer Classification: Exact Risk Conversion and Minimax Adaptation（2611.08876）｜math.ST cs.LG stat.ML stat.TH｜Aoran Chen, Yang Feng

**摘要要点**：研究「源」如何同时让训练混合更容易学、却让其准确率对目标更无价值。对二分类，针对每一对分布律与每个正目标权重，推导**仅由混合 excess 蕴含的最锐目标 excess hinge-risk 界**（在 clip 预测器上取一致），该精确转换曲线由密度加权的局部投票决定；加权 SVM 的两样本 oracle inequality 提供混合 excess，且高斯核下组合为显式形式。在倾斜边界类上，建立全过程的极小极大分类率 $[n + s_+^2/(m^{-1}+\tau^2)]^{-1}$，把**源采样不确定性 $m^{-1}$** 与**关系不确定性 $\tau^2$** 分离。目标检验的高斯-SVM 选择器在固定维度下可对未知 $s_+$、$\tau$ 自适应到对数因子，并对任意独立源保持目标-only 率到同一因子。在另一「光滑对抗」类上，若目标样本不超过源样本的一半，则限定在原标签上拟合的非负权高斯 SVM 族内，极小极大风险比无限制的极小极大风险**指数级更大**——即使允许任意数据依赖的加权与调参。

**与 Reliable Agent · 统计推断的关系**：这是「重加权 / 迁移」下的偏差-方差分解教科书：源数据既影响学习难度，也影响结论有效性，两者必须分开度量，否则「用更多合成/他人数据改进效果」可能只是在降低自己的方差、同时悄悄放大了不可约的关系不确定性。对应到 agent：用合成数据、他人标注或检索得到的资料去估一个量时，「源不确定性」与「关系不确定性」的分离是结论可信的前提。

**链接**：https://arxiv.org/abs/2611.08876

## The Cost of Coverage: Conformalising Native Forecast Uncertainty for GB Wind Power（2611.09815）｜cs.LG stat.AP｜Carl Somers

**摘要要点**：对风电预测的不确定性带做 conformal 校准，比较 6 个预测器（从 ARIMA 到表格基础模型）在英国两个风电场的运行条件下的表现。校准几乎不付 Winkler Score 惩罚就修复了经验**边际覆盖**，但这种成功掩盖了**高风速下的欠覆盖**；按预测风速工况分层校准后，边际覆盖变成工况级覆盖，高风速下日前越界电量相对合并校准减少 **40% 以上**，同时整体收窄了区间。

**与 Reliable Agent · 统计推断的关系**：「边际覆盖达标 ≠ 各条件 / 子群达标」是 conformal 用于 agent 风险控制时最常见的坑——安全关键的分层（高风险状态、少数子群）往往恰好是欠覆盖的地方。做 agent 的风险控制时，必须像这篇一样报告**条件覆盖**而不是只报平均覆盖率。

**链接**：https://arxiv.org/abs/2611.09815

## BEiTScore++: Reference-free Image Captioning Evaluation with BEiT-3 and Conformalized Quantile Regression（2611.09505）｜cs.CV cs.AI cs.CL cs.LG｜Gonçalo Gomes, Bruno Martins, Chrysoula Zerva

**摘要要点**：提出 BEiTScore 的不确定性感知扩展，在给出图像描述对齐分数的同时给出 **conformal 校准的置信区间**；做法是建模人类评判上的预测分布，一次前向即可同时完成打分与原则化不确定性量化。在多个带人工标注评分的基准上，它保持 BEiTScore 的排序相关性，且区间宽度比 MC dropout 更紧密地跟随预测误差；估计出的不确定性在图像退化与域外艺术图像上会增大。

**与 Reliable Agent · 统计推断的关系**：把「评测指标」本身变成带覆盖保证的量——这正是评测 agent / LLM 时最缺的一环（如今所有基准分数都是点估计）。用 conformal 化分位回归给指标配区间，思路可直接搬到「给 LLM 评测分数配置信区间」，与 2611.09815 一起构成当日校准方向的一对。

## Action-Centered Causal Bandits for Budget-Constrained Promotion Targeting（2611.08990）｜cs.LG｜Yifan Lin, Kaixu Yang, Di Mo

**摘要要点**：把「在全局预算下为每个用户挑选成本高昂的干预以最大化增量效果」形式化为带异质处理效应、预算受限的上下文 bandit。虽然动作无关的结果基线在做处理比较时会抵消，但建模非线性基线会抬高统计复杂度；提出 DR-CATE-CBwK，直接学习**处理对比量**，其在线更新在基线模型误设下仍然有效且**不需要逆倾向加权**；组合离线双重稳健学习器预热处理效应估计、在线动作中心估计器做序贯对比学习、原始-对偶控制器与「可负担动作」规则逐路径强制有效成本预算。线性 CATE 的平稳 i.i.d. 情形下证明高概率遗憾界 $\widetilde{O}(Kd\sqrt{T})$（$K$ 个定价动作、$d$ 维上下文、$T$ 步）。另证：动作中心估计矩在任意可预测基线估计下保持**无偏**，而指定的分臂奖励回归在动作依赖记录与共享基线误设下可呈现**渐近对比偏差**。半合成就业市场基准上，实践版 Thompson 变体取得最低遗憾，较最强奖励基线约降 20%。

**与 Reliable Agent · 统计推断的关系**：把「基线误设如何制造对比偏差」讲得很干净——当 agent 要估计的是增量效果而非绝对分数时，直接学对比量比学奖励更稳健。对「agent 做统计推断的 bias」课题，它给出可操作的做法：估计量尽量写成动作中心矩，以避免共享基线误设导致的系统性对比偏差。

**链接**：https://arxiv.org/abs/2611.08990
