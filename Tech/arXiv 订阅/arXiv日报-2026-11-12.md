## MediPFN: Amortized In-Context Nuisance Learning and Inference for Causal Mediation Analysis（2611.13219）｜stat.ML cs.LG stat.ME｜Shi Bo, Jiaming Hu　★本期新增

- **问题背景**：因果中介分析要把处理效应分解为经中介的间接路径与经其他过程的直接路径。表格基础模型（PFN）用上下文学习做分类与回归，正好提供中介分析所需的条件均值与倾向性得分估计；但**由这些估计构造置信区间，必须处理「拟合并组合若干 nuisance 函数」所引入的不确定性**。
- **方法**：MediPFN，一个摊销化的推断框架：把预训练表格基础模型适配为 nuisance 预测器，再用**交叉拟合的 influence-function 估计量**把多个 nuisance 预测组合起来；另设一个 head，从"已知间接效应的模拟表"中学习该估计量**标准化误差的分位数**；随后经监督微调、对称化与独立校准得到置信区间；在标准假设下给出覆盖界。
- **主要结果**：覆盖率比若干对比方法更接近名义水平；不确定性量化的计算成本大幅下降——匹配比较中比 bootstrap **快 59.1 倍**。
- **与 Reliable Agent · 统计推断的关系**：这是"用预训练基础模型替代手工拟合来做统计推断"的范式样板，正好是用户课题的方法论基线：**模型的 nuisance 预测自带偏差**，MediPFN 的应对是「交叉拟合 + 分位数 head 学习标准化误差 + 独立校准」三件套。其"更接近名义覆盖"而非"精确覆盖"的措辞也值得照抄——不要过度声明。可直接把这条 CI 构造流水线移植到"agent 估计量"上。

## Prediction-Powered LLM Ranking with Adaptively Collected Human Feedback（2611.13186）｜cs.LG stat.ME｜Gabriel Sargent, Will Wei Sun, Zhengwu Zhang, Yufeng Liu　（11-11 已列）

- **问题背景**：用人工评测给 LLM 排名对下游决策至关重要，但人工反馈昂贵，评测平台往往**自适应地**采集反馈（优先挑那些基于已观察反馈看起来信息量更大的模型对）。为在有限人工预算下进一步提升精度，评测者本可动用大量未评分回复与相对便宜的 LLM 裁判；然而**裁判偏差**与**自适应依赖**两点，使标准 i.i.d. 推断框架失效。
- **方法**：提出 **Prediction-Powered Ranking (PP-Rank)**：把 LLM 裁判的预测与人工反馈结合，在自适应采样下仍提供**有效推断**；数据驱动的预测权重在所提类别内最小化渐近协方差迹；理论上建立一般评测目标的**渐近正态性**与**同时排序推断**；用联合鞅分析处理自适应人工反馈与辅助数据之间的依赖；并导出一条降低探索的规则（优先低成本比较同时匹配保守方差界），刻画成对均值在 √T 率估计下的分配极限。
- **主要结果**：UltraFeedback-Extended 上的半合成实验中，分数估计精度、置信区间宽度、排序认证三项均优于纯人工基线；合成实验显示对裁判质量与自适应分配稳健，并能**在不牺牲精度的前提下大幅降低评测成本**。
- **与 Reliable Agent · 统计推断的关系**：这是"**用便宜 agent 当裁判 + 少量昂贵人工**做模型评测"的正确统计做法：prediction-powered inference（预测通道 + 人工通道）正面处理裁判偏差与自适应依赖这两个评测偏差的主要来源。可直接作为用户评测流水线的统计骨架；注意保证是**渐近**的，小样本场景需另配校正。

## Counting Under Disagreement: Dollar-Weighted Measurement, Selective Machine Labelling and Budgeted Human Review from Disagreeing AI Readers of Administrative Text（2611.13215）｜cs.AI cs.LG stat.ME｜George Koomullil (Ascendr, PBC)　（11-11 已列）

- **问题背景**：AI 辅助测量——一条文本标签适用于大量行政记录、目标是货币总额，而**锚定机器的人类读数彼此不一致**。测试床：美国税务申报中的 121,070 份 grant-purpose 文本（799,675 条记录，$126.4B），由一个规则分类器与三个语言模型标注；另设计抽样 651 份文本，由三人按同一 codebook 独立阅读。
- **方法**：给出**固定预测器的差分估计量**与**交叉拟合预测器**（fold 在抽样之前就分配到整帧、Poisson 抽样）的精确成立条件；用仿真评估所实现的固定规模流程；提出两条「接受机器标签」的规则——**美元加权误差下的加权 conformal p 值**与 **Learn-then-Test**（用设计阶段估计的误差）；并在嵌套留出折与设计重抽（合成真值）上评估。
- **主要结果**：8 个预测器自身总额 $11.2–15.0B，整改后彼此差异收敛到 $0.4B 以内；两条规则**在部署中的误差控制并未被建立**，且基于计数的规则在美元抽样下不接受任何文本；在"每一条人工标签都计费"的重放中，两阶段复核策略（校准器拟合于自身第一阶段）在 100 份预算下把总额 RMSE **降低 28%**，而纯 Neyman 分配因预测器未校准而失败；**独立读者使估计总额漂移 $3.93B，是读者内抽样区间的 2.2 倍**，机构级区间在所有规模下覆盖不足；每个头条结果都在每一位读者下重跑。
- **与 Reliable Agent · 统计推断的关系**：**全批次最贴近"Agent 做统计推断的偏差"的一篇**。机器标签 + 人类读数分歧 → 总额估计漂移与区间不覆盖；conformal p 值、LTT、预算化人工复核，正是"把 agent 当测量工具"时的偏差 + 覆盖保证三件套。迁移到自己课题时，可把"美元加权误差"换成"按估计量方差加权的误差"，把"金额总额"换成"参数或决策价值"。

## Knowing When to Intervene: Causal Evaluation of AI Agents（2611.09792）｜cs.AI cs.LG econ.EM stat.ME｜Ayush Sawarni, Wenqian Xing, Tijana Zrnic, Ramesh Johari, Vasilis Syrgkanis　（11-11 已列）

- **问题背景**：当前 agentic AI 的评测主要依赖 benchmark，但 benchmark 的**静态本质**使它无法说明部署期的审计干预是否有价值。可靠部署常需在 agent 轨迹的某一点判断是否介入——例如验证 agent 当前输出、或引导它改变行为——手段可能是人工复核、更贵的模型或耗时的 agentic 监督。**干预的价值本质上是一个因果推断问题**：干预对最终结果的因果效应究竟有益还是有害。难点在于问题的动态性：干预的影响取决于当前上下文与环境，以及 agent 未来的行为。
- **方法**：提出首个有方法论根基的框架，用于评估 **agent 轨迹内随机化干预的因果效应**；只需少量在随机干预（验证、筛查）下收集的轨迹数据，即可估计一大类（含上下文相关的）干预策略的**动态因果效应**；估计出的**结构参数**还可用于构造 **safety leaderboard**，刻画各类 agentic 动作的风险，供实践者做审计优先级排序。
- **主要结果**：在 tau-bench Retail、ToolSandbox、ImpossibleBench 上，干预效应**随 agent 动作与状态显著变化**（并非均匀的正向干预收益）；作者由此提出"因果推断 × agent 评测"交叉处的研究议程，认为这对 AI agent 的可靠与安全部署是必要的。
- **与 Reliable Agent · 统计推断的关系**：给"**审计/自监控模块自身的偏差**"提供了可识别路径——随机化干预 + 结构参数 + 反事实 leaderboard，而不是靠 agent 自评打分。对用户课题，它同时是"在有 agent 介入的数据上做无偏因果估计"的范例框架。

## High Probability Risk Control for Online Policy Learning（2611.13163）｜cs.LG（NeurIPS 2026）｜Yihong Guo, Drew Prinster, Suchi Saria, Anqi Liu　（11-11 已列）

- **问题背景**：研究**在线策略学习中的风险控制**：agent 自适应地收集数据，目标是学出一个在**每一轮**风险都低于容差阈值的新策略。策略更新与数据收集共同引起**反馈协变量偏移（feedback covariate shift, FCS）**——观测数据通过不断演化的策略与收集过程依赖于历史。由此带来两个实质问题：候选策略的**有效风险评估**，以及带**高概率风险控制**的**有效策略选择**。
- **方法**：提出**基于置换（permutation）的加权风险评估器**，其权重用 Sinkhorn 算法高效近似；选择风险估计的**上置信界（UCB）**低于目标阈值的策略，UCB 由提出的 **Gaussian bootstrap** 方法给出；理论上证明该风险评估器的**方差上界不大于标准重要性加权评估器**；策略控制方法给出**渐近有效的同时风险界**以及所选策略的**渐近高概率风险控制**。
- **主要结果**：在在线上下文老虎机、安全问答基准、医保理赔过滤三个任务上验证：维持目标风险水平、风险低于基线方法、风险估计方差更低、策略选择可靠地满足高概率风险控制；消融实验支持理论主张。
- **与 Reliable Agent · 统计推断的关系**：**反馈协变量偏移正是 agent 自我改进循环中的分布漂移**——这恰好是"agent 迭代时统计推断失效"的核心机制。「Sinkhorn 置换权重 + Gaussian bootstrap UCB + 同时风险界」可以直接当作给 agent 迭代过程做风险保证的模板。

## A Theory of Cross-Validation Variance（2611.14463）｜stat.ML cs.LG math.ST stat.TH｜Nathaniel S. O'Connell, Jaime L. Speiser　（11-11 已列）

- **问题背景**：交叉验证通过反复把数据切成训练集与验证集来估计预测性能。关键观察：**每个观测以两种角色影响估计**——被留出时接受评估，参与训练时帮助拟合模型；随机划分决定了它在两种角色上的权重。此前这类方差缺少精确刻画。
- **方法**：从"双重角色 + 权重"表示出发，证明交叉验证估计**方差的精确有限样本恒等式**：给定训练集大小相同的切分方案，方差是这些权重的函数，另有来自模型、度量与总体的常数；恒等式同时覆盖对观测取平均的度量（如 MSE）与对 case–control 对取平均的度量（如 AUC）。
- **主要结果**：方差可分解为**采样方差**（只依赖训练集大小）与**随机划分带来的方差**；K-fold 因设计上各观测权重相等，故**一阶方差最优**，而 Monte Carlo 与 bootstrap 交叉验证不是；K-fold 的一阶方差不依赖 K；在合理条件下 leave-one-out 在所有 K-fold 方案中方差最小，AUC 上同理 leave-pair-out 最优；CV 估计渐近正态，且方差即恒等式给出的量。
- **与 Reliable Agent · 统计推断的关系**：**agent 基准分数本质上就是留出估计**，其可靠性问题正落在这篇靶心：它给出留出估计方差的精确恒等式，并回答"该用哪种切分"。任何拿 agent 基准分数抖动做显著性比较的结论，都应先用这套分解解释方差来源。与"bias"主题的接口：方差与系统偏差是评测不确定性的两个正交来源，应分别报告。

## Reliability of Claude Code as an Agentic AI Grading System for Handwritten University Exams（2611.13217）｜cs.AI cs.CY｜Rayed AlGhamdi　★本期新增

- **问题背景**：考察 Claude Code（Claude Opus 4.6 的 agentic 部署）作为**手写大学试卷评分系统**的可靠性，四个研究问题：与专家人工评分的总分一致性（RQ1）、五类题型（从选择题到评价性判断题）的一致性（RQ2）、相隔一周的两次独立评分之间的**重测一致性**（RQ3）、AI 生成反馈的准确性（RQ4）。
- **方法**：在沙特某计算机图形学课程中，单次 agentic session、三份 rubric，评阅 60 名知情学生的 20 分期中卷；可靠性在**不相交样本**上估计（20 份用于 RQ1/2/4，15 份用于 RQ3）；用 Pearson 相关、MAE、Bland-Altman、加权 Cohen kappa、类内相关（ICC）与区分诊断型/确认型反馈的四类编码；作者本人是课程唯一学科专家，因此该设计评估的是"与领域专家参照的一致性"而非评分者间信度。
- **主要结果**：总分与人工评分**高度一致（r = 0.97；MAE = 0.85 分）**，但存在**小而显著的 AI 正偏 0.68 分**（约占 20 分的 3.4%）；重测一致性极佳（**ICC = 0.96**）；反馈准确（92.8% 诊断型、97.8% 确认型）；**作图题**在四个指标中的三个上是异常项；三个反复出现的失效模式：**关键词匹配而无概念深度**、订正后的选择题**状态歧义**、手绘图上的**注意力区域漂移**。
- **与 Reliable Agent · 统计推断的关系**：这是本批次少见的、**直接量化 agent 评分偏差**的实证（正偏 0.68 分 + 三个可检测的失效模式），可作为用户课题的现实案例参照。同时它自己写明了循环性限制：专家参照是单一且非独立的——**agent 评分偏差的估计本身也有参照偏差问题**，这正是用户可以切入的空隙。

## Towards Reliable VLM Judges: State-Conditional Invariance and Presentation-Aware Diagnostics（2611.13596）｜cs.AI cs.CL cs.CV cs.LG｜Qinan Zhang, Xinyu Wang, Qihang Jin, Tianyuan Wang, Hongbing Luo, Pengfei Li, Wenjun Lv, Yu Kang, Jian Di　（11-11 已列）

- **问题背景**：VLM 越来越多地被当作多模态与具身任务的自动裁判，但**聚合准确率或一致性并不能揭示裁判是否因正确理由改变判决**。
- **方法**：提出 **State-Conditional Invariance（SCI）** 这一可靠性原则：要求裁判在**语义保持的呈现变化**下保持稳定，同时对**改变任务结果的因果干预**有响应。在 **GridWM-Judge** 中实例化——基于确定性 MiniGrid 轨迹构建，含 Full、证据移除、反事实三类变体，以及呈现与表征探针；五个诊断任务：局部感知、动作条件转移、呈现稳定性、表征可交换性、Full-CF 因果判别。
- **主要结果**：诊断暴露出**异质的失效模式**：对证据的呈现与编码敏感、成功轨迹上的激活偏低、成对反事实判别能力弱；感知受控分析进一步表明**视觉 grounding 与目标恢复是实质的、依赖模型的瓶颈**。作者据此主张：应**联合报告正确性、呈现稳定性与因果敏感性**，而不是依赖单一分数。
- **与 Reliable Agent · 统计推断的关系**：这是"把裁判可靠性拆成可检验的统计条件"的范式——**呈现不变性 + 因果敏感性**。方法论可平移到文本 agent 裁判（换探针即可），并为"不要用单一准确率评估 agent"提供了直接论证。

## Dependable Long-Horizon LLM Agents: A Trajectory-Centered Empirical Study of Where Errors Enter and Which Controls Reach Them（2611.13254）｜cs.AI｜Shaohuang Wang, Jinghao Wen, Xulei Zhang, Xun Jiao　（11-11 已列）

- **方法**：定义 episode record，把候选故障与其**起源、传播、检测、响应、后果**绑定，并指出能覆盖它的控制族；写成书面标注协议，对 6 个多 agent 系统（公开的 Who&When 与 MAD 语料）**95 次失败运行**逐条通读轨迹。
- **主要结果**：故障进入得很早（中位数在运行进度的 **0.18** 处），多为对任务状态的错误决策或编造；Who&When 的 88 次运行中有 **37 次**在语料人工标注认定的决定性步骤之前就已出错；**72% 的失败运行中，轨迹在失败前已包含反对该错误的证据，而其中 88% 的情形没有任何 agent 采取行动**；有东西标记出偏差的占 31%，但没有任何响应移除了偏离状态；独立裁判阅读那些**未被使用的证据**、在准入时固定任务契约、与环境重新核对信念，能覆盖多数情节；仅恢复 agent 自身状态在 95 次中的 35 次即足够；语料扫描还显示 45% 的手工 Who&When 失败以 provider 内容过滤崩溃告终，之后 harness 发出**并非任何 agent 产生**的最终答案。
- **与 Reliable Agent · 统计推断的关系**：对 agent 可靠性最实证的一篇——**可靠性的瓶颈往往不是"没发现"而是"发现了没人处理"**。这正对应用户关心的"监控/自检模块是否真的起作用"，也是设计 agent 可靠性实验时该控制的混淆（provider 崩溃 + harness 代答）。

## Agent Benchmarks Stop Ranking Before They Run Out of Tasks（2611.13541）｜cs.AI｜Zihan Dong, Qishi Zhan, Minxuan Hu　（11-11 已列）

- **背景与方法**：数据科学/ML 工程 agent 在 MLE-bench、ALE-Bench、SWE-efficiency、AlgoTune 等基准上被评测，任务产出一个量（Kaggle 指标、竞赛分、加速比）；当基准不再区分最好模型时，惯常补救是"更难一版"。作者重新评分 8 个基准（含 SWE-bench Verified、Terminal-Bench）的公开发布运行，发现**饱和主要在测量而非任务**：多数 agent 基准把一次运行压成 1 bit 的 pass/fail——既**太粗**（SWE-bench Verified 上相邻前十 agent 的差距小于其测试自身的误差；修正误差后重排幅度不超过删除每个 agent 随机六分之一的通过量），又**被参照封顶**（ALE-Bench 前十按竞赛分在以人类中位数评分时并列，但近一半运行其实超过了该人类）。
- **结果与结论**：在固定任务上提高门槛只是把问题挪个地方，**分级给分**才能解决；作者提出带日期锚点的截断对数比分数，并把**成本**作为独立轴；在 Terminal-Bench 的一次重跑中，pass/fail 打平的模型在测试所丢弃的那个量上相差十倍以上。
- **与 Reliable Agent · 统计推断的关系**：这是 agent 榜单**统计效度**的直接证据——"榜单排不动了"多半是测量分辨率不够，而不是模型能力到顶；对用户而言，任何基于 agent 榜单做显著性比较的结论都要先过这一关。

## Causal Learning with Invalid Instruments for High-dimensional Imaging Responses（2611.13187）｜stat.ME math.ST stat.AP stat.TH｜Yiting Wang, Chunlin Li, Shan Yu, Lily Wang　★本期新增

- **问题背景**：大规模神经影像研究提供高维影像表型以理解脑部疾病与生物风险因素的因果关系。工具变量（IV）方法可处理这类观测数据中的**未观测混杂**，但现有 IV 方法在高维影像上受限：既难扩展到大规模数据，也难利用图像内在的空间结构；更关键的是**多数候选工具变量可能局部失效**。
- **方法**：提出 **Hi-FIVE**，估计空间变化的因果效应。先建立**可识别性条件**：当有效工具变量在某些区域构成"多数"、且无效-IV 的效应以非光滑方式切换时，**因果效应面的空间连续性**可把识别从有效区域**传播**到没有有效工具变量的区域；方法上结合三角剖分上的惩罚多元样条（因果面）与区域级惩罚（空间局部化的无效-IV 效应），并施加**锚约束**——保证每个单纯形上至少有一个相关工具变量有效；用分布式算法在单纯形上并行（支持二维与三维图像）；证明一致性与逐点渐近正态性，并构造 bootstrap 校准的**同时置信区域**（有限样本覆盖由仿真评估）。
- **主要结果**：在 ADNI 数据上分析磷酸化 tau 对 FDG-PET 影像的效应（在所声明的 IV 假设下解释）。
- **与 Reliable Agent · 统计推断的关系**：**工具变量失效是因果 bias 的经典来源**。空间连续性传播识别 + 锚约束，给出了"多数工具变量不可信"时的稳健做法；对用户做 agent 因果评估（用干预构造工具变量）时，可直接借用其可识别性条件的表述方式与同时置信区域的报告习惯。

## Measuring Definition Sensitivity in LLM Annotation of Social Science Concepts（2611.13339）｜cs.CL cs.CY｜Bogdan Mamaev, Qizhou Wang, Christopher Leckie, Matteo Vergani　★本期新增

- **背景**：社会科学研究中文本标注是基础环节，传统上昂贵且难扩展；研究者用 LLM 标注时把概念定义写进 prompt，而 hate speech、fake news、terrorism 等概念存在**多个理论上可辩护的竞争定义**；更根本的问题是——**模型究竟用了你给的定义，还是用了它预训练里的概念**？
- **方法与结果**：让模型用两个不同定义各标注同一批文本，把两次标注的分歧称为**定义敏感性**；作为对照，对一个定义只做改写而保持要求不变，两种措辞下的分歧构成**改写地板（paraphrase floor）**。在六个概念、三个 LLM 上，**替换竞争定义总是比改写引起更多标注变化**（平均而言）。结论是：标注结果依赖所给定义，**任何标注集都必须与产生它的定义一起解读**，且应同时报告定义敏感性与改写地板。
- **与 Reliable Agent · 统计推断的关系**：这是"**测量/标注偏差**"的操作化定义，可直接迁移到统计推断的"标注者效应"上：把「定义敏感性 − 改写地板」当作标注噪声下界，与 MediPFN 的 nuisance 偏差、Counting Under Disagreement 的读者漂移放进同一套偏差分解里。
