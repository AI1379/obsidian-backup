## Inference after coding agents（2611.23174）

`stat.ME`、`cs.AI`、`econ.EM`｜Florian Gunsilius, David Van Dijcke, Kaspar W"uthrich

**问题背景.** AI coding agent 正渗透实证研究的每一步（写代码、操纵数据、产出「发现」）。作者指出：把 agent 用在**假设检验**上，对经典推断构成实质性威胁，因为 agent 实现了一种「超级版的选择性推断」——人类式的开放式搜索（在一张隐式的估计量空间里找）+ 选择过程与估计过程的**程序化可重放性**。

**方法.** 给出一个简单的检测与校正流程：agent 跑完分析后，**reset 并在数据子样本上重放**它，估计「当分析看起来统计显著时，agent 相对更倾向选中该分析」的概率。对选择行为稳定的 agent，校正后的检验**渐近有效，且在给定选择下相合**。关键设计在于校正量是从黑箱 agent 的**实际选择**中学到的，而不是对「它如何搜索」建模，因此技术快速演进后依然有效。

**主要结果.**
- 在**零效应**模拟数据上，四个前沿 agent 被要求「产出一个有说服力的发现」时，报告显著 p 值的比例在 **54%–98%** 之间。
- 校正在模拟中稳健地把这一虚高的假拒绝率压回接近名义 **5%**。
- 在两篇已发表论文的实际应用上做了演示。

**与 Reliable Agent · 统计推断的关系.** 本期与旅行者课题最直接同构的一篇：把「agent 做统计推断」形式化为**选择后推断**问题，并给出可操作的黑箱校正——用子样本重放估计选择概率。54%–98% 的假 p 值率说明在 agent 主导的实证流水线里 p 值几乎失去意义；「重放校正」不依赖对 agent 内部机制的任何假设，是可以直接搬进实验流水线的做法。

**链接.** https://arxiv.org/abs/2611.23174

## SOTA or Luck? The Winner's Curse in LLM Leaderboards（2611.22227）

`cs.LG`、`cs.CL`、`stat.ME`、`stat.ML`｜Sikun Xu, Raphael Thomadsen, Dennis J. Zhang, Heng Zhang

**问题背景.** 公开 LLM 排行榜引导模型评估与采用，但榜首模型报告的性能会被**系统性高估**：在含噪基准分上排序，同时奖励采样运气与真实能力，即 **winner's curse**。同一选择效应还会扭曲榜单全部分数，作者称之为 **rank-induced bias**。

**方法.** 提出 **m-out-of-N bootstrap** 校正该偏差。假设固定模型池、任务 i.i.d. 且有界，同时允许模型之间存在任意任务内相关。在存在正间隔的总体分层下证明：该 bootstrap 把 $\Theta(N^{-1/2})$ 的排序偏差降到期望残余偏差 $o(N^{-1/2})$。再用同一 bootstrap 给出每个模型**可能排名的区间**，把模型分组为层（tier），并给出总体分层被一致恢复的充分条件。最终整合为 **RULER**（Rank Uncertainty and Leaderboard Evaluation Report），用样本分裂与校准模拟验证有限样本表现，并建议与原始排名一并发布。

**主要结果.**
- 跨 5 个基准家族、14 个基准，rank-1 的校正量约在 **0.09–3.86 个百分点**之间。
- SWE-bench Verified 快照中，并列榜首各获 **0.90 个百分点**校正。
- 在 SWE-bench Verified 上，RULER 把 173 个模型中的 **13 个**放入领先层。
- 高估幅度足以让「表面赢家」在统计上脆弱。

**与 Reliable Agent · 统计推断的关系.** 这是「LLM 评测中的 winner's curse」在统计层面的严格刻画，正对旅行者的**评测选择偏差**：模型被反复提交、试到分数高为止，分数的抽样噪声就被当作「能力」写进榜单。可操作的结论是：发布榜单时应同时给出校正分与排名区间（分层），而不是只给一个点估计。

**链接.** https://arxiv.org/abs/2611.22227

## Revisiting the Survival of Agent-Attributed Code: How Measurement Choices Decide the Verdict（2611.21784）

`cs.SE`、`cs.AI`｜Musfiqur Rahman, Mahi Begoug, Emad Shihab

**问题背景.** 关于「AI coding agent 产出的代码合并后存活更久还是更短」的研究结论互相矛盾：有人说留存更久，有人说差不多，有人说改得更快。每份研究都有各自可辩护的测量选择，但**这些选择对结论的影响有多大**此前无人量化。

**方法.** 重访作者早前的 AIDev 数据集研究（215 个仓库、2,802 个合并 PR、新增 **854,139 行**代码），系统变动**九个测量选择**，在五个研究问题上构造 **88 份生存分析**的 specification curve，并配合三种方差估计量、多个观测窗口与**标签置换**做稳健性检验。

**主要结果.**
- 对**人类监督型** agent（主要是 GitHub Copilot）：测量选择改变效应量大小，但不改变方向。
- 对**全自主 agent** Devin：测量选择**直接决定结论**。跨仓库看，行被视为独立观测时 **22 个规格中有 15 个**报告「被改得更早」，但按仓库聚类标准误后只剩 **3 个**，不超过标签置换产生的假阳性数；仓库内则没有任何规格检测到差异。
- LLM 意图分类器与人类标签的一致程度约等于两个人类之间（$\kappa$ 0.69–0.72），关键词规则明显更差（$\kappa$ 0.38），两者对「为何被修改」给出不同结论。
- 把已发表的五种研究设计放回自己的数据上，**每种设计只要改动一个选择就会改变结论**。
- 结论：agent 代码是否比人类代码活得更久，**由测量方式与代码本身共同决定**；文末给出面向合并后研究的操作化清单。

**与 Reliable Agent · 统计推断的关系.** 一篇关于「偏差从哪来」的元研究：如果结论能靠一个分析选择翻转，那么报告的效应量本质上是**研究者自由度**的产物而非被测系统的属性。对 agent 评测而言，这提供了可复用的负对照范式——标签置换、聚类标准误、规格曲线。

**链接.** https://arxiv.org/abs/2611.21784

## Consistency Is Not Correction: Separating Confidence, Abstention, and Recovery in LLM Agents（2611.21651）

`cs.CL`、`cs.AI`、`cs.MA`｜Khushal Sethi

**问题背景.** 控制器重采样答案、升级到更大模型或直接弃答，通常都以「置信度信号」为理由。但关于这个信号的三个主张**互不蕴含**：能区分答案好坏（discrimination）、能支撑弃答（selective prediction）、能把错误答案改对（correction utility）。

**方法.** 给出第三个主张的**精确分解**：correction utility = gated recoveries − gated harms；并给出一个**事前上界**——一个只替换提案的 gate 只能在基础策略原本就错的地方起作用，因此初始错误数**封顶**了任何正确 gate 能产生的不一致对数量。若该上界低于配对检验所需的样本量，则该实验**根本不可能得到正结果**，也无法区分「机制有效」与「gate 从未触发」。作者在两个模型尺度上同时测量三个目标，发现上界确实 binding。

**主要结果.**
- 小模型套件上，扰动一致性 verifier 达到 within-policy **AUROC 0.990**（95% 区间 [0.95, 1.00]），但每次 episode 的结果与单次采样解码完全一致，却花了 **4.32 倍**的调用次数。
- 840 episode 的受控研究中，verifier 在 60 个 GSM8K 决策上**一次都没有**替换提案——该比较**什么都没检验**；六个 controller 在 GSM8K 上的全部增益其实来自**一个任务**，而正是该任务的 temperature-zero 重复结果彼此不一致（服务本身复现不了这个答案）。
- 诊断集上 gate 最多能触及 4 个错误，而检验需要 6 个：**即便完美的 gate 也没有显著结果可用**。
- 作者给出两项可在花费预算之前发现问题的检查，并指出同一数据集里**并列处理、并列选择截断、不等输出上限**各自都会移动一个头条数字。

**与 Reliable Agent · 统计推断的关系.** 指出 agent 可靠性文献真正的瓶颈是**测量分辨率**而非信号选择：把「置信度」「弃答」「纠错」混成一个 claim，会让阴性结果无从解读。方法论上给出了 agent 评测实验的功效事前分析模板。

**链接.** https://arxiv.org/abs/2611.21651

## Lost in the Funnel: Selection-Induced Miscalibration in Ranking and Decision Systems（2611.22595）

`cs.LG`｜Aditya Somani, Rahul Ragesh, Vikas Joshi, Amit Singh

**问题背景.** 现代排序与决策系统由目标各异的组件串联，模型边界处校准良好的分数被当作校准过的概率一路用到下游漏斗（过滤、重排、业务规则、拍卖）。然而校准通常只在**产生分数的地方**验证，分数被**使用**之处的失效被系统性忽略。

**方法.** 提出 boundary-wise 诊断框架，用**残差恒等式**回答三个问题：校准能在多大程度上存活于这种选择之下、继承误差与选择效应如何区分、以及一个完美校准的分数在组件边界上仍可能出什么问题。为使校准在漏斗每一层都可测，研究刻意以 **rubric 评判的相关性**为目标，而非 CTR 这类依赖呈现方式的指标。在此基础上提出 **FAR**（Funnel-Aware Recalibration）：在分数驱动决策的那个边界做**后验的、选择策略感知的**重校准。

**主要结果.**
- 一个行业级案例研究把决策时的校准退化溯源到**选择**而非模型误差。
- 线上双区域 A/B 测试中，FAR 把决策时 ECE 降低 **60–80%**，并改善拍卖效率。
- 另用两个公开数据集模拟行业场景，为该机制提供补充证据；作者计划公开适配后的数据集与生成流程。

**与 Reliable Agent · 统计推断的关系.** 「选择诱导的失准」是 agent 流水线里极常见的偏差来源：agent 自评、verifier 打分、过滤重排都在「校准良好的分数」之上再做一次条件化选择。本文的边界诊断 + 选择感知重校准，可直接搬到 agent 评测流水线（例如用 LLM judge 分数做弃答阈值）。

**链接.** https://arxiv.org/abs/2611.22595

## What Does a Bias Head Measure? Non-Identifiability in Head-Level Bias Attribution（2611.23218）

`cs.CL`、`cs.LG`｜S.M Seefat Alam

**问题背景.** 把社会偏见定位到 LLM 的单个注意力头、再用消融把它移除的方法族，其验证方式从来只是「公平性指标变好了」，**从没有证据表明选头的统计量本身在度量偏见**。

**方法.** 在 Qwen-2.5-7B-Instruct 与 Llama-3.1-8B-Instruct 上做审计：先考察 head map 与各种混杂量的相关，再用**打断长度—标签耦合的干预**做识别。

**主要结果.**
- head map 与「标签盲」的**回复长度图**相关高达 $\rho = -0.950$ 与 $-0.768$，表面上锁定了一个表面混杂。
- 干预之后（prompt 固定），长度只解释该统计量方差的 **1%**；真正解释它的是 **prompt 身份，占 64% 的方差**，且与长度不成单调关系。
- 在任一固定 prompt 内，公平性标签、回复长度与受保护群体 token 的出现**共线**（$\phi = 0.95$），部分由标注规则的定义所致——因此**没有任何观测分析**能把该 map 归因于三者之一，也没有方法做过能够这么做的实验。
- 实质结论独立失败：在两种模型、两种参考读法下，偏见选择性都**不是**晚期层集中；所测的任何头集合消融后都**没有**降低不公平率。
- 反向打分的补集可靠地摧毁拒答行为（$p = 2.7\times10^{-5}$），说明该流水线在此尺度上能检测效应。

**与 Reliable Agent · 统计推断的关系.** 教科书级的**不可识别性**案例：LLM 输出上的「偏差量」往往是多个共线混杂的函数，不做干预就无从归因。对旅行者课题的启示是双向的——既提醒 agent 评测中的偏差指标常常只是混杂的别名，也说明非识别性论证本身可以成为「agent 声称自己无偏」时的形式化反驳工具。

**链接.** https://arxiv.org/abs/2611.23218

## The Price of Hard Coverage Constraints in Online Conformal Prediction（2611.22646）

`cs.LG`、`math.ST`、`stat.ML`、`stat.TH`｜Mingrui Liu

**问题背景.** conformal prediction 提供分布无关的不确定性量化，但在**序贯部署**中，标准覆盖保证仍允许误覆盖的**累积次数**随时间大幅波动。作者研究更硬的设定：预测集逐轮产生，累积误覆盖数在整个部署期内必须始终留在给定预算内。

**方法.** 刻画达成硬覆盖所需的**不可避免的效率代价**（额外预测集大小）。结果出人意料：即使数据 i.i.d.、分数分布已知、且**完全知道总体最优预测集**，代价依然存在。在覆盖率与预测集大小之间的适当正则条件下，确定任何满足硬覆盖约束的在线方法所需的最小累积超额预测集大小。

**主要结果.**
- 期望代价（评价时点**事先固定**）：$\Theta(\log T)$。
- 所有事先固定时点中**最大期望代价**：$\Theta(T^{1/3})$。
- 评价时点**事后选定**时最坏实现代价的期望：$\Theta(\sqrt{T})$。
- 这些速率**仅用过去的分数**即可达到，无需知道分数分布。

**与 Reliable Agent · 统计推断的关系.** 直接对应「agent 长时间连续给出带保证的判断」：逐轮加严的覆盖保证不是免费的，硬约束下预测集必须膨胀，且膨胀速率随时点选择方式变化（$\log T$ / $T^{1/3}$ / $\sqrt{T}$）。对于要宣称「部署期始终安全」的 agent 风险控制，这给出了效率代价的下界。

**链接.** https://arxiv.org/abs/2611.22646

## COSI: A Framework for Robustly Valid Inference（2611.22096）

`stat.ME`、`math.ST`、`stat.ML`、`stat.TH`｜Arun K. Kuchibhotla, Sivaraman Balakrishnan, Larry Wasserman

**问题背景.** 经典 Wald 与 bootstrap 置信集依赖较强的正则条件，在模型误设、小样本或高维下失效；需要一种在更弱假设下仍然渐近有效、且小样本覆盖更接近名义水平的置信集构造。

**方法.** 提出 **COSI（COnfidence from Scale Invariance）**，建立在 HulC（Hull-based Confidence）之上：用**中位无偏性**从批量估计构造置信集，并利用常见估计量共有的**尺度不变性**。具体做法是把数据分批，在每批上计算一个估计，保留所有「批次估计通过尺度不变性检验」的候选参数值。

**主要结果.**
- 所得置信集在**比经典 Wald 与 bootstrap 更弱的假设**下渐近有效。
- 小样本下覆盖可以**更接近名义水平**。
- 应用包括：均值的稳健推断、**误设线性模型**中的回归系数、张量范数、Féchet 均值。

**与 Reliable Agent · 统计推断的关系.** 提供了 Wald/bootstrap 之外的第三条路：对**模型误设**稳健的置信集，正是 agent 生成的模型与数据被默认「正确」时最容易出错的地方。「分批 + 尺度不变性检验」的构造在精神上也与本期的 agent 选择后推断校正（见第 1 篇）相通——都是用数据切分去检验流程内部一致性。

## Not All Mislabels Are Equal: Efficient Task-Aware Auditing with Confidence Sequences（2610.33262）

`stat.ME`、`cs.LG`、`math.ST`、`stat.AP`、`stat.ML`、`stat.TH`｜Fangyuan Lin, Noah Krever, Jakub \v{C}ern\'y, Lily Xu

研究固定数据集上分类标签的**高效自适应审计**（动机来自生物多样性信用项目：专家核验物种记录昂贵，且下游评分对不同标签的误标敏感程度不同）。方法上提出 **ATLAS** 框架：把 **anytime-valid 推断**与**任务感知的自适应审计策略**耦合；用混淆矩阵表示标签修正，并按「标签不确定性」与「潜在修正对下游评分的影响」联合决定下一个该人工检查的数据点。

**主要结果.**
- 肯尼亚生物多样性案例中，任务感知审计在保持 anytime-valid 保证的同时**显著减少**专家复核量。
- 在图像分类与命名实体识别的公开数据集上，ATLAS 通常以**远少得多的审计次数**达到与同类 anytime-valid 方法相同的精度（线性与非线性评分皆然）。
- 当分布无关保证代价过高时，给出基于建模假设的**贝叶斯替代**，可进一步减少审计量。
- 作者点出「统计有效性与实际可行性之间的落差」：Serfling 界等通用方法与已有置信序列程序虽然严格，却可能需要**高得离谱的专家复核量**。

**与 Reliable Agent · 统计推断的关系.** 与「用 LLM 给数据打标签、再做下游统计」这一典型 agent 流水线高度相关：标签错误对不同下游分数的影响并不相同，ATLAS 给出了「用有限审核预算换最多精度」的任务感知策略，且带有限样本、anytime-valid 保证。

## Thinking Harder Doesn't Lead to Better Choices: Reasoning Effort Increases the Confidence but Not the Correctness of LLM Shopping Agents（2611.22033）

`cs.AI`、`cs.CL`、`cs.CY`、`cs.HC`、`econ.GN`、`q-fin.EC`｜Adi Krishnamoorthy, X.Y. Han

在 WebShop、Amazon SQID、Wayfair WANDS 三个商品选择基准上评测十个前沿模型作为「购物 agent」。**增加思考预算并不显著提升决策质量**；同样的改动却**显著提升自报置信度**——额外思考买到的是信心而不是正确性。校准测量显示多数模型在各思考档位上**都没有良好校准**；且错误在模型间**高度共享**：一个模型出错时多个模型往往在同一任务上出错，在多个模型全错的任务上，大量模型会挑中**同一个错误商品**。

**与 Reliable Agent · 统计推断的关系.** 提供「自报置信度不能当正确性代理」的又一证据，与第 4 篇「置信度 ≠ 纠错效用」互为印证；「错误共享」还意味着依赖多 agent 投票的可靠性保证会因错误相关而失效——这是评估 ensemble 式 agent 保证时必须计入的一项。

**链接.** https://arxiv.org/abs/2611.22033

## RAW: Refusal Aversion in the Wild, A Causal Measurement Method for Deployed LLMs（2611.21641）

`cs.CL`、`cs.AI`、`cs.HC`、`econ.GN`、`q-fin.EC`｜Pavel Kireyev

已部署 LLM 每天处理数亿次对话并拒答相当比例的请求，但**拒答的用户侧代价**在任何生产模型上都没被测量：前沿实验室产品做 A/B 测试受伦理与运营限制，第三方平台又受限于固定 API。作者提出 **RAW**：把 LLM 的**随机性当作自然实验**——在任意已有日志中，近似相同的提示有时被拒、有时不拒，这种变异可识别拒答对用户后续行为的因果效应；推断按用户聚类处理。

**主要结果.**
- 在 LMSYS-Chat-1M 与 WildChat 的 **15 个已部署 LLM** 上应用。
- 对约一半可精确测量的模型，**一次拒答导致后续再参与率下降 3–17 个百分点**；其余模型无可区分效应。
- 其中一个部署的正向点估计被追溯为**持续用户反复重试**被拒请求所致。
- 方法成本约**每 1000 次对话 0.30 美元**，可仅凭日志对任何已部署模型运行；标签、审核分、提示嵌入与流水线代码一并发布。

**与 Reliable Agent · 统计推断的关系.** 把「用日志里的随机性做准实验」的因果识别范式搬到**已部署 LLM** 上，是研究线上 agent 行为因果效应的可复制模板；「随机性即自然实验 + 用户聚类推断」正是应对日志数据选择偏差的标准做法。

**链接.** https://arxiv.org/abs/2611.21641
