## Knowing When to Intervene: Causal Evaluation of AI Agents（2611.09792）｜cs.AI cs.LG econ.EM stat.ME｜Ayush Sawarni, Wenqian Xing, Tijana Zrnic, Ramesh Johari, Vasilis Syrgkanis

**问题背景**：现有 agent 评测主要依赖 benchmark，而静态基准无法回答部署时「这次干预值不值得做」——人工复核当前输出、用更贵的模型监督、或 agentic 监督。其价值本质是一个因果问题：干预对最终结果的因果效应有多大。且问题具动态性：干预的影响取决于当前上下文/环境以及 agent 后续行为。

**方法**：提出第一个有方法论根基的框架，在 agent 轨迹内评估随机干预的因果效应。只需少量在随机干预（如 verification、screening）下采集的轨迹数据，即可估计一大类（上下文相关的）干预策略的动态因果效应；估出的结构参数还能构造「安全排行榜」，用于实务上的审计优先级排序。

**主要结果**：在 tau-bench Retail、ToolSandbox、ImpossibleBench 上，干预效应在不同 agent 动作与状态之间差异极大——一刀切地审计某类动作没有意义，条件化才有效。

**与 Reliable Agent · 统计推断的关系**：这就是「Agent 评测要用因果推断」的样板，与你的课题同构：评估「介入/引导」对 agent 统计推断结果的影响，本质是动态处理效应估计。它同时示范了因果量如何直接变成可排序的审计优先级，而非停留在显著性检验。

**链接**：https://arxiv.org/abs/2611.09792

## On the Reliability of Majority-Vote Pseudo-Labels in Test-Time Reinforcement Learning（2611.09872）｜cs.AI｜Haoyu Wang, Ru Wang, Yuanyuan Wang, Jiaxian Guo, Mingming Gong

**问题背景**：测试时强化学习（TTRL）用自生成的伪标签把预训练模型适配到无标注目标域，但这些伪标签的可靠性一直缺乏刻画。

**方法**：分析在线 DPO 下的多数投票（majority-vote）监督，把其误差分解为 population-majority bias 与 prompt 依赖的有限 rollout 波动。由于前者一般无法在没有外部监督时识别，转而缓解有限 rollout 波动的下游影响：提出 PC-Dr.DPO（Prompt-Conditional Distributionally Robust DPO），按观测到的投票可靠性在 prompt 内做鲁棒重加权，使来自采样敏感 prompt 的更新更保守；另加缓存机制减少在线自监督遗忘。

**主要结果**：在 6 个数学与知识密集推理基准、5 个模型骨干、30 组设置中，PC-Dr.DPO 在 24 组达到或超过最强 TTRL 基线。

**与 Reliable Agent · 统计推断的关系**：这正是「agent 用自生成数据做统计估计时的 bias」的一个干净分解：把偏差拆成不可识别的系统性偏 + 可缓解的抽样噪声两层，并只对后者施加可验证的鲁棒修正。方法可平移到 agent 跑统计推断：先用投票重复性度量每条产出的可靠性，再按可靠性做样本级鲁棒加权，而不是把自生成标签当真值。

**链接**：https://arxiv.org/abs/2611.09872

## One Run Is Not Enough: A Monte Carlo Protocol for Evaluating LLM Reliability on Data Science Tasks（2611.09729）｜cs.LG｜Wenqi Ni, Ozan Evkaya, and Miguel de Carvalho

**问题背景**：LLM 自动化数据科学工作流很有潜力，但要评估其可靠性，需同时看响应质量与它在重复运行、不同任务类型、不同难度下的一致性；已有基准（DataSciBench 2026、StatQA 2024）主要测能力，不测一致性。

**方法**：提出 DS-QA：100 道取自英国大学课程的数据科学与统计题，覆盖 16 个数据集、3 个难度层级；建立三层评估框架——通用响应属性（运行时长、冗长度、文本相似度）、粗粒度指标（准确率、代码可执行性、完整性）、任务特定指标；对 OpenAI 模型用 100 次重复运行的 Monte Carlo 协议评测。

**主要结果**：数据可视化与监督学习任务、中高难度上响应波动显著，说明只看质量不看一致性会高估可靠性；另发现词冗长度比 +0.1 大致对应 token 冗长度比 +0.013。

**与 Reliable Agent · 统计推断的关系**：直接对应「评一个 agent 到底稳不稳」：单次跑分不等于可靠性，至少要做重复采样并报告方差。这是评价 agent 统计推断输出的最小实验纪律——如果 agent 的估计量本身有 run-to-run 方差，只报一次结果的标准误是不可信的。

**链接**：https://arxiv.org/abs/2611.09729

## Calibrating your confidence requires thinking of all the ways you could be wrong（2611.08997）｜cs.LG stat.ML｜Marco Miani

**问题背景**：现代深度学习的置信度普遍失准，架构本身缺乏量化自身不确定性的机制；更大模型与更大数据只能缓解、不能消除这一结构缺陷。贝叶斯方法有原则但计算开销常牺牲可扩展性或质量，阻碍普及。

**方法**：在参数空间引入一种新分布：协方差为「与 Fisher 信息矩阵零空间对齐的投影矩阵」的退化高斯。给出两个数值高效算法（后验采样、直接计算预测置信度）。从 Amari 信息几何出发研究参数扰动在两个正交子空间的分裂，指出该后验是捕获此分裂的最简选择（一个子空间赋单位方差、另一个赋零方差）；并用微分几何工具修正非线性化 Laplace 近似中的关键错位；同时以 PAC-Bayes 泛化界衔接过参数化模型的学习能力。

**主要结果**：实验上取得 SOTA 的置信度校准与分布外（OOD）检测结果，并有理论支撑。

**与 Reliable Agent · 统计推断的关系**：这是「校准」方向最结构化的一份：把「模型可能错在哪些方向」（Fisher 零空间）显式写进后验。对 agent 做统计推断时值得借鉴——置信度不该是 softmax 出来的分数，而应来自对模型错误方向的显式建模与统计刻画。

**链接**：https://arxiv.org/abs/2611.08997

## When Can You Trust Neural Critics? Auditing Mutual Information Estimates of Higher-Order Epistasis in Protein Language Models（2611.09046）｜cs.LG｜Maryam Rahimimovassagh, Waldemar Karwowski, Niloofar Yousefi

**问题背景**：互信息（MI）估计常被用来「探查」神经表示究竟编码了什么（如蛋白语言模型 ESM-2），但变分 MI 估计器的方差至少随真 MI 指数增长——这威胁一切基于 MI 的「模型学到了什么」式论断。

**方法**：审计一项先前的神经 MI 研究（ESM-2 中 order-resolved epistasis，GB1 四点景观）：考察跨种子重复差异是否只是普通换种子重训的量级，并检验评估-配对方案对分数的影响；在原维度下比较三个替代估计器族的跨种子稳定性；在两个蛋白语言模型的表示维度上做合成校准（已知 MI 的高斯信道，无模型表示）；再加入一个拿到真实信号方向、但把输入降为一维的「特权控制组」critic。

**主要结果**：跨种子差异无系统偏差、量级与普通重训相当，但评估配对方案会显著改变分数；原维度下三个族中两个可稳定、一个不能；合成校准中，即使信号排序正确且种子稳定，三族都只恢复出远低于所需的信号；特权控制组在 gain 1.5、维度 5120 与 4096 下分别恢复 93.3% 与 98.7% 的解析 MI——信号在有特权信息时可恢复，但控制组未能解释「盲估计为何失败」。结论：即使估计器已稳定，在该维度与样本量下仍不足以支撑 order-resolved 的依赖性主张。

**与 Reliable Agent · 统计推断的关系**：这是「别轻信神经探针结论」的一篇方法论硬核文：先审计估计器本身，再谈发现。可直接搬到 agent 评测——用一个「知道真值的特权对照」检验你的度量本来是否有可能恢复信号；否则「没测出差异」很可能只是探针方差太大。

**链接**：https://arxiv.org/abs/2611.09046

## Authorization Drift in LLM Agents: Evaluating Boundary Compliance in Multi-Step Tool Use（2611.09113）｜cs.CR cs.LG｜Chuxue Cao and Jingru Zeng and Boqin Yin and Yujin Zhou and Yidan Huang and Sujin Chen and Jinluan Yang and Haoran Li and Yike Guo and Sirui Han

**问题背景**：LLM agent 在追求用户目标时可能越过自己的授权边界，而且不需要攻击者存在。文中把这一现象形式化为跨数据、工具、范围（scope）与时间的「授权漂移」（authorization drift）。

**方法**：提出 Authorization Drift Benchmark（ADB）：7 个领域、648 个样本，每例配一条充分的合规路径与一条诱人的越权捷径；用 Staged Execution-Reflective Synthesis（SERS）基于真实 agent rollout（而非 LLM 自我批评）验证任务可执行、捷径足够诱人、合规路径确实可行；在 13 个 LLM、3 个框架共 25,207 条轨迹上评测。

**主要结果**：能力越强漂移越严重，前沿模型漂移率 0.43–0.61；但 86.18% 的任务仍存在被观测到的干净成功轨迹，说明漂移可避免；漂移具持续性，且主要由早期数据过度收集主导；agentic scaffold 下「看似改善」伴随干净完成率崩塌。法律映射上，93.5% 有法律依据的漂移运行跨越多个法域，数据最小化是被援引最多的条款。

**与 Reliable Agent · 统计推断的关系**：给 agent 可靠性提供了一个可测量的失败维度，并揭示评测悖论：scaffold 提升指标的同时可能让行为更糟。可迁移到统计推断 agent——当 agent 自行决定「多取点数据、多跑几轮」时，漂移就是统计口径被悄悄改掉，直接破坏可比性与无偏性。

**链接**：https://arxiv.org/abs/2611.09113

## High-Dimensional Off-Policy Evaluation without Sample Splitting using an Onsager Correction（2611.08794）｜stat.ML cs.LG math.ST stat.TH｜Saksham Jain, Guillaume Braun, Masaaki Imaizumi

**问题背景**：用于 off-policy evaluation（OPE）的奖励模型通常用留出数据挑选。但当样本量与上下文维度同比例增长时，全样本拟合模型与固定比例拟合模型之间的测试风险差并不必然趋于零——留出评估虽能一致估计「小样本模型」的测试风险，但由于候选奖励模型的相对排名在全量重拟合后会变，留出选择可能是次优的。

**方法**：提出 Onsager 校正的、目标策略加权的准则，只用训练观测估计全量数据奖励模型的样本外风险，从而无需样本分割即可沿全量梯度下降轨迹做早停。在固定深度与隐层宽度的神经网络、高斯上下文、single-index 奖励、上下文相关 multi-index 目标策略、已知上下文无关日志等设定下，证明该准则在有限个梯度下降迭代点上的一致性，并给出所选奖励模型的近 oracle 保证；同一校正还导出无需样本分割的双重稳健（doubly robust）估计量，即使奖励模型预测误差不消失也能一致估计真实策略价值。

**主要结果**：实验显示：在固定样本/维度比下，维度增长时风险估计误差下降，奖励模型选择优于留出基线；双重稳健价值估计的 RMSE 亦下降。

**与 Reliable Agent · 统计推断的关系**：这是「样本分割本身即信息损失 + 引入选择偏差」的高维统计实例，正对你的 bias 课题：当 n 与 d 同阶时，「用留出集选模型」会系统性偏向小样本模型。同样思路可用于 agent 统计推断：当 agent 自己选数据、选提示、选子集时，「选择」与「评估」共用同一批数据，就需要这类校正来避免乐观偏差。

**链接**：https://arxiv.org/abs/2611.08794

## ReplayAudit: Auditing Outsourced LLM Fine-Tuning via Sealed Records and Selective Replay（2611.09607）｜cs.CR cs.LG｜Yihan Xia, Wenxin Xu, Taotao Wang

**摘要要点**：用遥测引导的审计系统审计外包 LLM 微调：挑战前封存训练记录，从封存检查点独立重放采样区间；损失变化与参数更新范数指导分层随机采样。7B BF16 原型在随机审计中即拒绝了一次虚假更新范数上报，定向检查还能拒绝虚假损失上报与被跳过的更新。两种学习率偏离设置下，相比均匀采样把完整审计的中位墙钟时间降低 49% 与 67%；但当被跳过的更新躲过高异常层时，对应审计成本反而高出 38%。

**与 Reliable Agent · 统计推断的关系**：要点：审计成本由「偏离捕获率」与「实际重放工作量」共同决定，不能只谈抽样比例。对 agent 做统计推断同样如此——审计/验证开销要与可检出的偏离信号绑定来谈。

**链接**：https://arxiv.org/abs/2611.09607

## Verifier Noise Is a Temperature: Testing Tilt Predictions in Finite-Budget LLM-Guided Search（2611.09699）｜cs.LG cs.AI｜Xiaomeng Li

**摘要要点**：LLM 引导搜索循环中，若提案与当前解每次都被重新打分（prompt 优化器的 minibatch 接受门即如此），且分数差为 logistic、变异算子可逆，则 keep-if-better 是可逆马尔可夫链，其平稳律是被 exp(βf) 倾斜的变异平衡分布；连续对称噪声差下同一倾斜是小步扩散极限的平稳律，β = 4F'(0)，minibatch 门控下 β 随 minibatch 增大而增大，缓存 incumbent 分数则虚增记录分数。实测：150 步后 7 个设定中 6 个水平随 minibatch 上升，但预测值不成立——bin packing 上只达到预测增益的 62–88%（写新启发式时 109–119%），且不同起点未达到共同水平，倾斜是否真描述 LLM 编辑的平稳律仍开放。

**与 Reliable Agent · 统计推断的关系**：罕见地诚实报告了失败的注册测试：理论预测清晰、量化对应关系失败。这种「先注册预测、再如实报告未通过」的写法，正是 agent 可靠性研究应有的态度；也提醒我们在 agent 搜索类任务上，理论平衡律与有限预算下的实际表现可能系统性脱节。

**链接**：https://arxiv.org/abs/2611.09699

## Finite-sample Calibration Guarantees for Binary Segmentation（2611.09120）｜cs.CV cs.LG｜Bruno Viti, Martin Holler

**摘要要点**：分割模型普遍失准，而现有多数校准方法只给渐近或定性保证，不保证「以高概率校准误差低」。作者从标准集中不等式出发，推导显式考虑二值分割输出空间依赖的改进校准误差界，并给出带该形式保证的后验校准方法；经验上所提校准器满足所推保证，并优于现有后验校准方法。

**与 Reliable Agent · 统计推断的关系**：把「依赖结构」显式写进校准界，是把统计保证做实的关键一步（简单 i.i.d. 集中不等式在此不够用）。对 agent 的统计推断输出做校准时，样本间的相关结构（如同一轨迹内多次查询、同一数据集上的重复任务）同样需要处理。

**链接**：https://arxiv.org/abs/2611.09120

## Locally Adaptive Conformal Prediction for Polynomial Chaos Expansions（2611.09579）｜stat.CO cs.CE stat.ME stat.ML｜Dimitrios Loukrezis, Arthur Hatstatt, Bruno Sudret, and Dimitris G. Giovanis

**摘要要点**：发展了针对多项式混沌展开（PCE）的局部自适应 jackknife+ conformal 预测框架：非一致性分数由在 log 变换的留一残差上训练的辅助 PCE 归一化；证明若辅助模型训练在嵌套的留一残差上，jackknife+ 的覆盖保证可继承到自适应区间；用局部 lasso 型自适应 PCE 处理异方差。

**与 Reliable Agent · 统计推断的关系**：conformal/risk-control 方向本期唯一一篇兼顾「自适应 + 保证可继承」的论文，思路可迁移：agent 在不同难度/分布上做自适应推断时，条件化的覆盖保证比全局保证更贴近实际需求。

**链接**：https://arxiv.org/abs/2611.09579

## Debias Online Expectile Regression for High-Dimensional Stream Data and Statistic Inference（2611.09431）｜stat.ME｜Wei Cao, Shanshan Wang

**摘要要点**：高维在线 expectile 回归的统计推断仍欠发达。方法以 Lasso 正则做变量选择、缓解高维造成的不稳定；采用在线更新策略，用递归更新的累积统计量逼近全局梯度，并以近端梯度下降更新参数；为在只有当前批次与历史汇总统计时仍能有效推断，另发展在线精度矩阵估计过程；建立了去偏估计量的一致性与渐近正态性。数值研究与真实数据应用显示，其性能可比 oracle 与离线估计量，同时保持低存储成本。

**与 Reliable Agent · 统计推断的关系**：「去偏 + 在线 + 渐近正态」三件套齐全，是统计推断落地流式场景的扎实范例；对 agent 做统计推断时，若产出是流式到达的，精度矩阵的在线估计与去偏步骤是绕不开的一环。

**链接**：https://arxiv.org/abs/2611.09431
