## 1. Almost Controlled: The FDR of Benjamini-Hochberg on Weighted Conformal p-Values（2611.21509）

`stat.ME`、`cs.LG`、`math.ST`、`stat.ML`｜Ryan Lim

**问题背景.** 加权 conformal p 值把 conformal 推断推广到协变量偏移场景，一个常见用法是把它送进 Benjamini-Hochberg（BH）做单元选择或离群检测。但加权 conformal p 值可能**不具备正相依性**，于是「BH 是否仍在有限样本下控制 FDR」成为一个悬而未决的问题。作者指出实验看起来是能控的。

**方法.** 构造**两个反例**（用精确有理数运算认证），证明 BH 并不能控制 FDR；随后刻画 FDR 与目标水平 q 的偏离幅度：设有 n 个校准点、m 个检验单元、权重比 B，则相对超出量 FDR/q − 1 被一个只依赖 n、m、B、q 的函数界住，量级为 $\sqrt{Bm/(nq)}$（当 $Bm/(nq)$ 较小时）；该界对所有 $B\le n$、所有 n 都成立。再把这个界「翻译」成一个**被证明有有限样本控制的、更低的 BH 水平**，同时给出一个不保守但无保证的经验规则。

**主要结果.**
- FDR **确实会失控**：存在被精确有理数认证的反例使 FDR 超过目标 q。
- 相对超出上界量级为 $O(\sqrt{Bm/(nq)})$；在多个非零单元共享同一阈值的 Poisson 极限模型中该量级可**达到**（$c(q)\sqrt{Bm/(nq)}$，$B/n\to 0$ 再 $m\to\infty$）。
- 对某些固定分布，超出量只以 $n^{-1/2}$ 的速度随 n 衰减（收敛很慢）；若所有检验单元均为零假设，固定 m 时超出量为 $O(B/n)$，某些构型下随 m **线性增长**。
- 修正：按该界下调 BH 水平可获得被证明的有限样本控制。

**与 Reliable Agent · 统计推断的关系.** 这是本期最贴近「保证在有限样本下悄悄失效」的证据：把 *conformal 分数* 与 *多重检验* 组合使用时，「看起来控住了」是危险的——失效幅度随校准点减少、检验单元增多而变大，恰好是 agent 流水线里「小校准集 + 大量候选/多 verifier 比较」的场景。作者给出的下界修正可直接嵌入 agent 多重比较流程。

**链接.** https://arxiv.org/abs/2611.21509

## 2. Anytime Valid Conformal Prediction on Streaming Time Series（2611.20905）

`stat.ME`｜Chencheng Fang

**问题背景.** 流式预测（金融、能源、医疗的持续监控与风险控制）要求预测区间在**任意停时点**仍然有效，并能适应分布漂移。常规 conformal 依赖可交换性，偏移下失效；Adaptive Conformal Inference（ACI）放宽了假设，但它只保证**已实现的平均误覆盖率**沿单条轨迹长期趋近目标。风险敏感的监控要控的是**真误覆盖率**（预测集 miss 的条件概率），也就是「集合本身可不可靠」而非「碰巧发生了什么」。

**方法.** 先给出不可能性结论：**在不假设分布偏移性质的前提下**，不可能对每一个预测集在任意停时都控制真误覆盖率；因此转而控制**真运行平均**与**真滚动平均**误覆盖率；方法上把 ACI 与 **anytime valid confidence sequences** 结合。

**主要结果.**
- 以高概率，**真运行平均**误覆盖率在整个时间轴上始终低于目标水平（对时间一致成立）；**真滚动平均**对任意窗口规则同样成立。
- 滚动平均的效率损失在窗口增长足够快时**消失**，但对固定窗口**不消失**。

**与 Reliable Agent · 统计推断的关系.** 直接对应「agent 在长时间运行中持续给出带保证的判断」这一课题：ACI 这类只管长期平均的做法在偏移下会给出虚假的安全感，本文把保证改写成 anytime 有效的、对时间一致的版本，并指出「每个决策点都安全」在无额外假设时不可能——这为 agent 风险控制的声明边界划了线。

**链接.** https://arxiv.org/abs/2611.20905

## 3. Honest confidence sets under experiment-level failure（2611.20079）

`stat.ME`、`math.ST`｜Yuxin Han, Lanjun Cheng, Fengshi Jing

**问题背景.** 「实验级失败」（experiment-level failure）会替换联合观测分布但保留目标。论文研究：当声明的失败概率上界**恰好等于**允许的非覆盖概率时，如何构造诚实的（honest）置信集。这正是「试验会失败、且失败概率预算被全部用掉」时还能给出多宽区间的问题。

**方法.** 在 Uniform 支撑端点与已知方差 $\sigma^2$ 的 Gaussian 均值两类目标、紧参数区间上分析；对任意或绝对连续的联合失败分布给出最坏情形期望直径；用独立随机化给出尖锐的 minimax 风险；再用单侧局部 Kullback-Leibler 界得到带对数因子的下界；在无并列的可交换失败下给出确定性界；在 reference-calibrated roster 上导出随机化 minimax 可靠性率。

**主要结果.**
- 端点目标（区间 $[1,2]$）：sharp 随机化 minimax 风险 $(2+o(1))\log N/N$；均值（已知方差 $\sigma^2$）：$(2\sigma+o(1))(\log N/N)^{1/2}$。
- 失败分布被多个目标共享时，会**迫使 clean-state 非覆盖率随期望直径下降**（误差预算被失败吃掉）。
- 端点实验在剩余误差预算趋零时存在**尖锐的确定性前沿**；预设一个对数规模的 reference reserve，可在条件独立且概率被界定在 0/1 之外的子类上确定性地达到同一阶。

**与 Reliable Agent · 统计推断的关系.** 「实验级失败」几乎是 agent 评测的常态：一次 agent 运行崩了、工具调用超时、任务被判失败——这会**替换整个联合分布**而不是删掉一个样本。本文的 honest 区间把「失败率预算 = 漏覆盖率预算」这一临界情形算清楚了，对设计 agent 统计推断的置信区间/显著性结论很有用：失败会直接吃掉误差预算，且两者相等时区间宽度是 $O(\log N/N)$ 量级。

**链接.** https://arxiv.org/abs/2611.20079

## 4. The stable false discovery rate（2611.19585）

`stat.ME`、`math.ST`｜Aaditya Ramdas（61 页）

**问题背景.** 当一个「发现」取决于分析选择（目标 FDR 水平、pipeline 里用了哪个机器学习算法、检验统计量的选法……），一份控住 FDR 的入选假设列表，几乎不能说明这个结论有多容易翻转。

**方法.** 提出 **stable FDR（sFDR）** 并给出控制方法：给每个假设分配一个 0 到 1 之间的 **allocation**，sFDR 定义为「零假设 allocation 的期望份额 ÷ 总 allocation」。对同一份数据跑多次合理变体的分析时，allocation 取「各次 selection indicator ÷ 该次发现数」，再跨分析平均并重标定；作者也给出直接从 p 值、**e-values**、knockoff 统计量出发的 allocation 方案，得到 stable-BH、stable e-BH、stable knockoff；并用 e-value 表示刻画哪些 allocation 规则能控制错误率。

**主要结果.**
- 所得 sFDR **等于各次运行普通 FDR 的平均**——即使各次运行之间相依；因此在原 FDR 控制成立的同样假设下，sFDR 控制也成立。
- 反例：天真地报告「每个变量被选中的频率」**并不能**控制 sFDR。
- 可解释性：总被选中的假设 allocation 为 1，从未被选中的为 0。
- 实证：白白血病基因表达与神经影像分析中，allocation 越大的发现在独立样本中越常被支持。

**与 Reliable Agent · 统计推断的关系.** 这是本期最直接的 **e-value** 论文（作者 Aaditya Ramdas 即 e-value 框架的提出者之一），并把「agent 流水线里的超参选择」直接形式化成需要控制的误差率：对同一批数据反复换 prompt、换 verifier、换聚合规则重跑，相当于多次分析，stable FDR 正是「结论对分析选择有多稳」的度量。这与旅行者的课题「Agent 做统计推断时的 bias」高度同构——**分析选择本身就是一种未被计入的偏差来源**。

**链接.** https://arxiv.org/abs/2611.19585

## 5. A Hierarchical Statistical Framework for Evaluating Agent Reliability（2611.19614）

`cs.AI`、`cond-mat.stat-mech`、`math.PR`｜Mirco Milletarì, Tuhin Kundu

**问题背景.** agent 在复杂场景中常因环境信息不完整、用户意图歧义、业务规则复杂、策略本身随机而表现不稳；新基准（如 Thinkingbox）上即使最强模型也难以在多样业务场景中稳定发挥，因此需要系统评估 agentic 系统并**量化其可靠性**。

**方法.** 定义 **scenario / instance / sample 三层层级结构**，对文献中常见指标（mean pass rate、$pass@k$、$pass\hat{}^k$）给出不确定性估计；把层级聚合与物理/统计中的 **coarse-graining** 过程对应起来；并**独立推导**出无偏 $pass@k$ 与 $pass\hat{}^k$ 估计量的**精确有限样本**抽样方差表达式。

**主要结果.** 不同层级的聚合会揭示 policy model 的不同结构与性质；层级化不确定性传播给出了构造性推导，把**执行噪声**与**任务异质性**明确分离。

**与 Reliable Agent · 统计推断的关系.** 这是「Agent 可靠性」这条线上方法论最扎实的当篇：它明确了 agent 评测中的不确定性有三个来源层级，若把 scenario/instance/sample 混在一起算方差，得到的可靠性数字会被任务异质性污染。独立推导的有限样本方差表达式，可直接用于给 agent 成功率报告置信区间——是 agent 统计推断的**基线工具**。

**链接.** https://arxiv.org/abs/2611.19614

## 6. Anytime-Valid PAC-Bayes Certificates for Adaptive Test-Time Scaling（2611.21241）

`cs.LG`、`cs.CL`、`stat.ML`｜Xiaoyu Li, Jiangxuan Long

**问题背景.** test-time scaling 系统会反复查看 calibration set 后再决定采样多少、用哪个 prompt、信哪个 verifier、用哪种聚合规则。**标准 validation error bar 在这种自适应选择之后不再有效。**

**方法.** 把 test-time scaling recipe 建模成**带随机代价的随机预测器**，证明一个 **time-uniform PAC-Bayes 证书**：它同时对所有 calibration 时刻、所有 recipe 的后验混合、所有数据依赖的停止规则成立——即同一个事件覆盖了部署前那段 recipe 搜索，而不只是最终报告的那个固定 recipe。对有限预算/verifier 网格，惩罚是熟悉的 $\log M/n$（最坏情形无法避免），而非均匀先验与局部后验混合可给出更紧证书；再特化到 self-consistency 给出**余量律**与 oracle 算力分配律。

**主要结果.**
- plurality voting 只在「正确答案恰为生成器唯一众数」的样本上随预算**指数级**改进；否则更多算力**可证地放大错误**。
- 合成审计量化了自适应预算选择带来的**乐观偏差**；另用 gpt-4.1-mini 在 GSM8K 上做 192 例审计，展示真实推理流水线的风险—算力报告方式。
- 两个模型在 GSM8K 与 MATH-500 上：selected-best error bar 在名义 5% 水平下，于**至多 22.5%** 的随机划分中低于 out-of-split GSM8K 风险，而**证书从不如此**；在完整 GSM8K test split 上收紧到 **0.109**（held-out risk 0.039）。

**与 Reliable Agent · 统计推断的关系.** 直击「agent 自适应选择之后还能不能声称显著性」。verifier 选择、采样预算、聚合规则本质上是在校准集上做选择，传统误差棒必然乐观；本文给出 anytime 有效、无需留出集、可跨搜索过程成立的证书，并给出可算力分配的理论边界（多数票并非越多越好，甚至可能放大错误）——对「agent 做统计推断时的偏差」是可直接引用的框架。

**链接.** https://arxiv.org/abs/2611.21241

## 7. Tight PAC-Bayes Generalisation Guarantees for Large Language Model Judges（2611.20818）

`cs.LG`｜Tom A. Lamb, Philip H. S. Torr, Tim G. J. Rudner

**问题背景.** LLM judge 被越来越多地用来监控 LLM agent 的输出，但针对这些 judge 可靠性的**形式化保证几乎空白**，这限制了把它们用于安全攸关监督的信心。

**方法.** 定义 judge 的风险为「从部署中的生成器抽取的 prompt–response 对上做安全分类」的风险；把 PAC-Bayes 框架用到该设定，并细化既有基于压缩的方法（更紧的界 + 更高效的编码）；提出 **LoRA-GT**（跨层共享同一个量化 scale），在不牺牲预测性能的前提下给出最紧的证书。

**主要结果.**
- 标准参数高效微调（PEFT）即可得到**非平凡甚至紧的证书**（分类风险与 Brier 风险皆然），且**无需留出验证集**。
- 在 **5 个 guardrail 模型 × 4 个 benchmark** 上发现：证书的紧度更多由**适应复杂度**决定，而非基座模型规模。
- 量化可以推到多远才不至于让风险增幅超过「更短描述」带来的界收紧收益，本文给出了这条边界。

**与 Reliable Agent · 统计推断的关系.** 「谁来评判 agent」是可靠 agent 体系里最脆弱的一环，而 judge 本身只是一个被微调过的分类器，因此它同样需要**有保证的泛化界**。本文给的是「可认证的可扩展监督」的具体路径（PEFT + PAC-Bayes + 量化编码），并指出一个反直觉结论：加大基座模型换不来更紧的保证。这对 agent 评测里「用更强的 judge 就更可靠」的常见假设是一个直接反驳。

**链接.** https://arxiv.org/abs/2611.20818

## 8. Calibrate Once, Grow the Vocabulary: Candidate-Independent Scores for Conformal Risk Control in Open-Vocabulary Segmentation（2611.20715）

`cs.LG`｜Md Tanveer Hossain Munim, Bijoy Ahmed Saiem, Muhammad Abdullah Adnan

**问题背景.** 开放词表分割器在推理时接受类名；conformal risk control（CRC）本可界定预测集 miss 真标签的频率，但**校准之后再往词表里加名字，这个界就会破**。

**方法.** 先诊断机制：剪枝（pruning）、跨标签注意力（cross-label attention）与词表归一化使每个标签的分数依赖其它被请求的标签，分数可升可降，故在大词表上重校准的阈值未必在更小词表上成立。修复方式**不需要训练**：把每个标签与一个**固定参考库（reference bank）**对比打分，使标签分数在加入新名字时保持不变，从而一次校准即可随词表增长保有保证。

**主要结果.**
- 在 ADE20K 上，为 10% 风险、150 个名字校准的阈值，在 **845 个名字**时于 released CAT-Seg 模型上达到 **15.4%** 风险；**每个 calibration split 都超标**，而预测集增长远小于目标所需。
- 改成 candidate-independent 打分后，在三个 benchmark、五个 segmenter 上，转换后的模型在**评测的每个词表规模**都达到目标风险。

**与 Reliable Agent · 统计推断的关系.** 一个干净的「保证静默失效」案例：风险保证不是被噪声破坏，而是被**候选集合的变化**破坏，而且失效方向不可预测。agent 场景里候选集合天天在变（换工具、换检索池、换可选动作），这直接对应「保证在 agent 换候选集后就悄悄失效」的偏差，且本文给出了无需重训的修复法。

**链接.** https://arxiv.org/abs/2611.20715

## 9. Weighted conformal prediction under covariate shift: process limits, estimated weights and efficiency（2611.20052）

`math.ST`、`stat.ME`、`stat.ML`｜Mehrdad Pournaderi

加权 split conformal 用似然比 $v=dQ_X/dP_X$ 重加权校准分数；论文研究过程 $\sqrt m(\hat F_m-F_Q)$，证明其**当且仅当** $\chi^2(Q\|P)<\infty$ 时在 $\ell^\infty$ 收敛到高斯过程 $W(G(t))-F_Q(t)W(K^2)$（$\sup v$ 不起作用），据此给出各覆盖率水平的联合律、一致 bootstrap、渐近精确的 inflation 与 Berry-Esseen 型速率；用校准协变量估计比率时统一展开仍成立（估计误差以协方差项进入，必要时方差可低于 oracle）；已知比率时加权 conformal 阈值**当且仅当**比率与覆盖指示在测试分布下不相关才是半参数有效。

**与课题的关系.** 给出加权 conformal 在协变量偏移下的**过程极限与效率刻画**，是「分布偏移下 agent 分数还能不能用」的底层统计。

**链接.** https://arxiv.org/abs/2611.20052

## 10. Learning the Average Dose-Response Function with a Right-Censored Treatment（2611.19204）

`math.ST`、`stat.ME`、`stat.ML`｜Sihan Wu, Yifan Cui

在治疗时长右删失、结果缺失的情形下估计平均剂量-反应函数：用删失记录给出的时长下界，经**增广局部估计方程**构造 **multiply robust** 估计量；只要结果回归、治疗密度、删失生存函数三者中**任意两个**被一致估计，估计量即一致；在交叉拟合框架下给出收敛率与渐近分布；再构造**去偏估计量**以消除局部平滑对置信区间覆盖的扭曲（支持不过度平滑下的渐近有效逐点推断），并在附加一致条件下用 **Gaussian multiplier bootstrap** 构造同时置信带。模拟评估估计精度、逐点与一致推断有效性及对 nuisance 误设的稳健性；NHANES 校准的半合成研究验证了已知剂量-反应函数下的表现。

**与课题的关系.** 部分识别 + multiply robust + 去偏，是「观测到的统计推断有偏」的典型模板，对 agent 统计推断中「数据生成机制被部分观测/删失」的情形可直接借鉴。

**链接.** https://arxiv.org/abs/2611.19204

## 11. Regularizing Treatment Leakage for LLM-based Uplift Estimation（2611.20794）

`cs.AI`｜Bojing Feng, Jinqiu Deng, Zihan Hong, Yuan Xue, Wenqi Xiang, Shuhan Wang, Feng Xiao, Shiwei Wang 等 11 人

LLM 编码产品文本时，处理效应相关信息会形成**不可迁移到部署环境的捷径**。论文提出 LULR：对因果头的可训练共享表示施加 CLUB 惩罚、冻结 LLM 编码器。受控代理实验显示排序分数交互为正、优于所测 weight-dash 配置，但作者明确指出**处理依赖的评估只支持探索性解读**，结构化对比仅提供参考性能、未确立相对树模型的普遍优势。在百万条定价 RCT 上，离线 `lift@0.3` 在 **4/5 个种子**上提升，但**差异不具统计显著性**、估计策略价值近乎持平；一周线上 A/B 实验记录到销售量 **+5.45%**、GMV **+1.91%**。作者强调这些聚合结果是整条定价策略的短期业务证据，**并未隔离出该正则项的贡献**。

**与课题的关系.** 「LLM 造成的处理泄漏 → 因果估计有偏 → 部署后失效」，是 agent 参与统计推断时偏差的教科书式案例；同时它是一篇**诚实报告**的范本：显式写出「不显著」「未隔离贡献」。

**链接.** https://arxiv.org/abs/2611.20794

## 12. A Crowd-Audited Atlas of Implicit Bias in LLM-Powered Agents（2611.21376）

`cs.CY`、`cs.CL`、`cs.HC`｜Jason Alexander, Yuxuan Li, Michael Licamele, Wesley Hanwen Deng, Sauvik Das

用美国时间使用调查（ATUS）的 **17 个日常活动领域**生成 **506 个决策场景**，让带有人设（种族、性别认同、政治意识形态）的 LLM 表达显著隐性偏差；随后 **500 名参与者**完成 **8,010 次二元选择**，标注哪些场景最值得进一步审查。发现：参与者优先考虑**广泛相关**（如饮食）、**高风险**（如健康）以及**同一社会人口群体内全体一致**（刻板印象更明确）的场景，而较少受差异幅度或具体 ATUS 领域影响；理由分析显示参与者常把差异解读为群体特质并以自身内化的刻板印象判断其是否「合理」。

**与课题的关系.** 把「agent 的偏差」从单点高曝光场景（招聘、测评）扩展到**日常决策全谱**，并给出众包审计方法；对研究「agent 偏差如何被度量与审计」有直接参考。

**链接.** https://arxiv.org/abs/2611.21376
