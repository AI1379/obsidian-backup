## High Probability Risk Control for Online Policy Learning（2611.13163）｜cs.LG（NeurIPS 2026）｜Yihong Guo, Drew Prinster, Suchi Saria, Anqi Liu

- **问题背景**：在线策略学习中，agent 自适应采数并逐轮更新策略，目标是让新策略的风险在每一轮都以高概率低于容忍阈值。但策略更新与数据采集共同造成 **feedback covariate shift (FCS)**：观测数据通过不断演化的策略与采数过程依赖历史。由此带来两个实质问题：其一，如何对每个候选策略高效做风险评估；其二，如何做带高概率风险控制的合法策略选择。
- **方法**：提出 **基于置换的加权风险评估器**（permutation-based weighted risk evaluator），权重用 Sinkhorn 算法高效逼近；再选取「风险估计上置信界（UCB）低于目标阈值」的策略，UCB 由作者提出的 **Gaussian bootstrap** 方法获得。
- **主要结果**：理论上证明该风险评估器的方差上界**不大于**标准重要性加权评估器；策略控制方法给出渐近有效的 **simultaneous risk bound**，并对被选中的策略给出渐近高概率风险控制。实验（在线 contextual bandit、安全问答基准、Medical Claim Filtering）显示方法能维持目标风险水平、风险低于基线、风险估计方差更低，且策略选择可靠。
- **与 Reliable Agent · 统计推断的关系**：这是「agent 在线更新策略时的统计保证」的范本：UCB + 同时风险界 + 高概率控制，正是处理 agent 统计推断中 bias/方差的现成工具箱。其「置换加权 vs 重要性加权」的方差比较尤其对应「哪种重加权引入更小偏差」这一核心问题；同时置信界的思路也可延伸到 e-value / anytime-valid 式的序列风险监控。
- **链接**：https://arxiv.org/abs/2611.13163

## Knowing When to Intervene: Causal Evaluation of AI Agents（2611.09792）｜cs.AI cs.LG econ.EM stat.ME｜Ayush Sawarni, Wenqian Xing, Tijana Zrnic, Ramesh Johari, Vasilis Syrgkanis

- **问题背景**：当前 agentic AI 系统的评测主要依赖 benchmark，但 benchmark 的静态本质使它无法说明**部署期审计干预**是否有价值。可靠部署常需要在 agent 轨迹中的某一点判断是否介入——例如验证 agent 当前输出、或引导它改变行为——而手段可能是人工复核、更贵的模型，或耗时的 agentic 监督。这种干预的价值本质上是一个**因果推断问题**：干预对最终结果的因果效应究竟是有益还是有害。
- **方法**：提出首个有方法论根基的框架，用于评估 agent 轨迹内随机化干预的因果效应。只需**少量在随机干预（如验证、筛查）下收集的轨迹数据**，即可估计一大类（含上下文相关的）干预策略的**动态因果效应**；估计出的结构参数还可用构造 **safety leaderboard**，刻画各类 agentic 动作的风险，供实践者做审计优先级排序。难点在于问题动态：干预的影响取决于当前上下文与环境，以及 agent 未来的行为。
- **主要结果**：在 tau-bench Retail、ToolSandbox、ImpossibleBench 上，干预效应**随 agent 动作与状态变化显著**（并非均匀的正向干预收益）。作者据此提出「因果推断 × agent 评测」交叉处的丰富研究议程，认为这对 AI agent 的可靠与安全部署是必要的。
- **与 Reliable Agent · 统计推断的关系**：把因果推断正式接进 agent 可靠性评测，是本批次中最贴近「agent 做统计推断」主线的论文之一。随机化干预 + 结构参数 + 反事实 leaderboard 三件套，正好回应「agent 自评/自监控模块自身的偏差」这一难题——它要求干预是随机化的、效应是结构化的，而不是靠 agent 自评打分。

- **链接**：https://arxiv.org/abs/2611.09792

## Prediction-Powered LLM Ranking with Adaptively Collected Human Feedback（2611.13186）｜cs.LG stat.ME｜Gabriel Sargent, Will Wei Sun, Zhengwu Zhang, Yufeng Liu

- **问题背景**：用人工评测给 LLM 排名对下游决策至关重要，但人工反馈昂贵，评测平台往往**自适应地**采集反馈——优先比较那些基于已观察反馈看起来信息量更大的模型对。为在有限人工反馈下进一步提升精度，评测者本可动用大量未评分回复和相对便宜的 LLM 裁判；然而**裁判偏差**与**自适应依赖**这两点，使标准的 i.i.d. 推断框架失效。
- **方法**：提出 **Prediction-Powered Ranking (PP-Rank)**：把 LLM 裁判的预测与人工反馈结合，在自适应采样下依然提供**有效推断**。数据驱动的预测权重在所提类别内最小化渐近协方差迹。理论上建立一般评测目标的**渐近正态性**与**同时排序推断**；用联合鞅分析处理自适应人工反馈与辅助数据之间的依赖；进一步导出一条降低探索成本的规则，优先选低成本比较同时匹配保守方差界，并刻画成对均值在 √T 率估计下的分配极限。
- **主要结果**：在 UltraFeedback-Extended 上的半合成实验中，分数估计精度、置信区间宽度、排序认证三项均优于纯人工基线；合成实验显示方法对裁判质量与自适应分配稳健，并能**在不牺牲精度的前提下大幅降低评测成本**。
- **与 Reliable Agent · 统计推断的关系**：这是「用便宜裁判 + 少量昂贵人工做模型评测」的正确统计做法：把 prediction-powered inference（预测通道 + 人工通道）用到 LLM 排名上，并正面处理裁判偏差与自适应依赖这两个 agent 评测中最核心的偏差来源。与 2611.13485 共同构成本批次「LLM 评测的统计推断」双子篇。
- **链接**：https://arxiv.org/abs/2611.13186

## Conformal Risk Control for QoT-Aware Lightpath Feasibility Under Technology-Driven Domain Shift（2611.13893）｜cs.LG｜Kiarash Rezaei, Omran Ayoub, Paolo Monti, Carlos Natalino

- **问题背景**：AI/ML 回归模型支撑光网络的运营决策，但通常只输出点预测，**不携带任何关于自身可靠性的统计受控信息**。当光纤、放大器、交换设备升级造成技术驱动的域偏移时，这种无保证的可靠性尤为危险。
- **方法**：提出 **post-hoc conformal risk control (CRC)** 框架：冻结预训练回归器不动，对不确定性带的**失覆盖**给出有限样本保证，再通过策略规则把置信带映射为运营决策。保证只作用于区间失覆盖，决策错误率则仅作经验评估（作者明确区分）。应用于 QoT 感知的光路可行性判定（预测光纤信噪比 OSNR）；用特征偏移贡献分数识别在技术换代中「与 QoT 关系变化最大」的光路特征；两条策略把置信带翻译为接受/拒绝光路的决策。
- **主要结果**：在 CONUS 拓扑的 SDM QoT 数据集上，目标覆盖率 90% 时，不确定性带在 **170 次试验 × 17 种域偏移 × 10 组校准-测试划分**中全部达标，而只做 source-only 的分位数回归（QR）基线**一次都没达标**。重度偏移下，效率导向（EO）策略把零样本可行性决策准确率从约 **85% 提升到 99% 以上**，接近需要重训的迁移学习（TL）策略，同时免去重训。
- **与 Reliable Agent · 统计推断的关系**：域偏移下的风险控制正是 agent 部署时的核心统计问题（分布漂移 + 风险保证）。其「冻结模型 + 后验校准 + 有限样本保证」路线可迁移到 LLM/agent 的漂移监控；更值得学习的是它的**诚实边界**：只对区间失覆盖给保证，把决策错误率明确留给经验评估，不做过度声明。
- **链接**：https://arxiv.org/abs/2611.13893

## A Theory of Cross-Validation Variance（2611.14463）｜stat.ML cs.LG math.ST stat.TH｜Nathaniel S. O'Connell, Jaime L. Speiser

- **问题背景**：交叉验证通过反复把数据切成训练集与验证集来估计预测性能。关键观察是：**每个观测以两种角色影响估计**——被留出时接受评估，以及参与训练时帮助拟合模型；随机划分决定了它在两种角色上的权重。此前这类方差缺少精确刻画。
- **方法**：从上述「双重角色 + 权重」表示出发，证明交叉验证估计**方差的精确有限样本恒等式**：给定训练集大小相同的切分方案，方差是这些权重的函数，另有来自模型、度量与总体的常数。恒等式同时覆盖对观测取平均的度量（如 MSE）与对 case–control 对取平均的度量（如 AUC）。
- **主要结果**：方差可分解为**采样方差**（只依赖训练集大小）与**随机划分带来的方差**。K-fold 因设计上各观测权重相等，故**一阶方差最优**；Monte Carlo 与 bootstrap 交叉验证则不是。K-fold 的一阶方差不依赖于 K；在合理条件下 leave-one-out 在所有 K-fold 方案中方差最小；AUC 上同理 leave-pair-out 最优。交叉验证估计渐近正态，且方差即为该恒等式给出的量。
- **与 Reliable Agent · 统计推断的关系**：**这是「Agent 评测里的 bias / 方差」最该读的一篇。** Agent 基准分数本质上就是留出估计，其可靠性问题正落在这篇的靶心：它给出留出估计方差的精确恒等式，并回答「该用哪种切分」。任何拿 agent 在基准上的分数抖动做显著性比较的结论，都应当先用这套分解解释方差来源。
- **链接**：https://arxiv.org/abs/2611.14463

## Counting Under Disagreement: Dollar-Weighted Measurement, Selective Machine Labelling and Budgeted Human Review from Disagreeing AI Readers of Administrative Text（2611.13215）｜cs.AI cs.LG stat.ME｜George Koomullil (Ascendr, PBC)

- **问题背景**：研究 AI 辅助测量的一个真实场景：一条文本标签对应许多行政记录、目标是**货币总额**、而锚定机器的人工读数**互相不一致**。测试集为美国报税中的 121,070 份 grant-purpose 文本（799,675 条记录、$126.4B），由一个规则分类器与三个语言模型标注；另设计抽样 651 份文本，由三人按同一码本独立阅读。
- **方法**：给出**固定预测器差分估计量**与**交叉拟合预测器**（各折先分配到整个总体、再抽样）在 **Poisson 抽样**下确切成立的条件，并以模拟评估所实现的定长程序。评估两条「接受机器标签」的规则：美元加权误差下的**加权 conformal p 值**，以及基于设计估计误差的 **Learn-then-Test**；在嵌套留出折与「设计重抽 + 合成真值」两种方式上检验。
- **主要结果**：8 个预测器自身总额跨度 $11.2–15.0B，修正后彼此一致到 $0.4B 以内。但两条规则在**部署中的误差控制并未建立**，且基于计数的规则在美元抽样下**不接受任何文本**。回放中若每次人工标注都计费：两阶段复核策略（校准器在自身第一阶段上拟合）相对美元比例抽样把总额 RMSE **降低 28%**（预算 100 份文本），而纯 Neyman 分配在预测器未校准时**失败**。独立读者使估计总额偏移 **$3.93B**（为读者内抽样区间的 **2.2 倍**），机构级区间在**所有规模下均覆盖不足**。每个头条结果都在每个读者下重跑。
- **与 Reliable Agent · 统计推断的关系**：「机器先读、人来复核」的 agent 监督范式，其统计保证正是核心。本文罕见地给出了**边界与负面结论**：dollar-weighted conformal 与 Learn-then-Test 的部署误差控制并未成立、计数规则完全失效、机构层级区间覆盖不足。对「LLM 监督能否低成本替代人工标注」这一常见命题，这是一个审慎的、基于实测的答案，值得直接引用。
- **链接**：https://arxiv.org/abs/2611.13215

## Pseudo-marginal Sampling for Selective Inference（2611.13492）｜stat.ME stat.CO｜Jiali He, Sifan Liu

- **问题背景**：自适应选择之后的推断必须处理选择偏差。一种做法是对被选事件做条件化，但当选择程序复杂时，所得条件分布往往**解析上不可得**，只能用采样方法。**拒绝采样**是自然基线：反复从提议分布抽取，只保留那些能复现所观察选择的样本；当选择事件罕见时，代价可能高得不可行。
- **方法**：提出 **pseudo-marginal MCMC 算法**，直接从选择分布采样。作者用**弱 Poincaré 不等式**分析其相对拒绝采样的计算效率，并识别何时能带来实质增益。
- **主要结果**：在经典 **file-drawer 问题**中推导出两种方法的精确计算成本，展示随选择事件变稀有呈**指数级改进**。在涉及复杂选择程序、且无可解析条件分布的数值实验中，pseudo-marginal 采样器常常比拒绝采样**高效数百倍**，同时所得检验达到名义的**选择性 I 类错误率**。
- **与 Reliable Agent · 统计推断的关系**：这是无线性假设的选择后推断。Agent 系统里「先筛选再报告」的流程——先让 agent 挑出值得看的样本、再做显著性检验——本质就是选择后推断。pseudo-marginal 给出可计算的选择后置信区间路径，是「agent 自选样本 + 统计检验」组合的实用工具箱。
- **链接**：https://arxiv.org/abs/2611.13492

## Dependable Long-Horizon LLM Agents: A Trajectory-Centered Empirical Study of Where Errors Enter and Which Controls Reach Them（2611.13254）｜cs.AI｜Shaohuang Wang, Jinghao Wen, Xulei Zhang, Xun Jiao

- **问题背景**：当 LLM agent 在长任务中途失败，常规分析只记录**症状**：一个失败模式标签，或被判定负责的 agent 与步骤。它不说明错误**从哪里进入**、哪个状态把它带到了症状、轨迹中是否早已存在反证、哪个控制本可抓住它。
- **方法**：定义 **episode record**，把候选故障与其起源、传播、检测、应对、后果绑定，按运行阶段与状态域定位，并命名能够覆盖它的控制族；据此写成书面标注协议，对公开语料 Who&When 与 MAD 中六个多 agent 系统的 **95 次失败运行**逐条通读全文。
- **主要结果**：故障进入得**很早**（中位数在运行的 **0.18** 处），多为对任务状态的错误决策或捏造；在 Who&When 的 88 次运行中有 **37 次**，错误出现在语料人工标注认定的「决定性步骤」之前。**72%** 的失败运行中，轨迹其实已包含针对该错误的证据，但 **88%** 的情况下没有任何 agent 据此行动。**31%** 的运行有东西标记了偏差，却没有任何响应移除被偏离的状态。独立裁判阅读未被使用的证据、在准入时固定任务契约、以及把信念与环境重新核对，能触及大部分事件；**仅恢复 agent 自身状态**就足以解决 95 次中的 **35 次**。此外对原始语料的文本扫描显示，**45%** 的手工 Who&When 失败以 provider 内容过滤崩溃告终，之后 harness 输出一个**没有任何 agent 产出的最终答案**——这类失败既非症状分类法、也非「负责 agent」标签所能表示。
- **与 Reliable Agent · 统计推断的关系**：直接对应「agent 失败归因」，并把「错误何时进入」与「证据是否被使用」分成两个独立可测量的量。对可靠 agent 的设计含义相当尖锐：多数失败**不是检测问题，而是状态恢复问题**。这与 2611.09792（何时该介入）形成互补——一个讲事后归因，一个讲事前干预。
- **链接**：https://arxiv.org/abs/2611.13254

## Towards Reliable VLM Judges: State-Conditional Invariance and Presentation-Aware Diagnostics（2611.13596）｜cs.AI cs.CL cs.CV cs.LG｜Qinan Zhang, Xinyu Wang, Qihang Jin, Tianyuan Wang, Hongbing Luo, Pengfei Li, Wenjun Lv, Yu Kang, Jian Di

- **问题背景**：VLM 越来越多地被用作多模态与具身任务的自动裁判，但聚合准确率或一致性**无法揭示裁判是否因为正确的理由改变判断**。
- **方法**：提出 **State-Conditional Invariance (SCI)** 可靠性原则：要求裁判在**保持语义的呈现变化**下保持稳定，同时对**改变任务结果的因果干预**作出响应。实例化为 **GridWM-Judge**——基于确定性 MiniGrid 轨迹构建的模拟器锚定诊断基准，含 Full / 证据移除 / 反事实三种对齐变体，外加呈现与表征探针；覆盖局部感知、动作条件转移、呈现稳定性、表征可交换性、Full-CF 因果判别五个诊断任务。
- **主要结果**：诊断揭示出**异质的失败模式**：对证据呈现与编码敏感、在成功轨迹上激活偏低、反事实配对判别能力弱。感知受控分析进一步表明，**视觉落地**与**目标恢复**是显著的、且依赖具体模型的瓶颈。作者由此主张：应**联合报告正确性、呈现稳定性与因果敏感性**，而不是依赖单一分数。
- **与 Reliable Agent · 统计推断的关系**：这是把「裁判偏差」从抱怨变成可诊断对象的代表作：SCI 明确区分「表述变了却不该改判」与「任务结果变了就该改判」两类错误，正好对应 agent 评测中 judge 的 presentation bias 与 anchoring。
- **链接**：https://arxiv.org/abs/2611.13596

## Agreeing on the Answer but Not the Reason: Measurement Limits of LLM Reasoning Failure Taxonomies（2611.13140）｜cs.AI cs.CL｜Madhu Sudhan Rao Beesetty

- **问题背景**：论文越来越把「某个模型多大比例的错误落入某个命名类别」当作**测量**来做，然后跨模型比较这些比例。作者主张：对于其中某一类别，报告出来的比例**在很大程度上是测量程序的性质**，而非模型性质。
- **方法**：定义 **Compositional Collapse**（模型注意到问题某个必需子部分，随后将其丢弃或误用），在公开多语言数学基准的 **2,316 条评分记录**上，跨 **12 个模型、11 种语言**测量。分三步：(1) 检查标签共现与判定顺序；(2) 让 11 种语言的母语者评判 179 条转写，与检查者比一致性；(3) 让每种语言的第二位母语者复评 142 项，并重跑同一检查者模型。
- **主要结果**：(1) **50.1%** 的失败带有不止一个类别的证据，故报告的多数项取决于分类器的**测试顺序**：调换两个测试会在 12 个模型中的 **11 个**上改变多数项，6 种排序下 Collapse 占比横跨 **26.4%–76.4%**。(2) 一致性在**该类别上崩塌、而任务上没有**：母语者在答案正确性上与检查者 kappa = **0.932**，在 Collapse 上仅 **0.093**；两位人类之间 kappa = 0.659，而各自与检查者 ≤ 0.094；用同样的人类指令原样重跑检查者模型，把 kappa 从 0.147 提到 **0.636**，说明差距主要来自**提示词而非模型**。(3) 检查者标 Collapse 的频率是母语者的 **1.81 倍**，但排除一个损坏基准项（孟加拉语与中文译文中的删除从句）后降到 **1.17 倍**。作者建议跨模型比较失败模式前先做四项廉价检查：报告标签共现、置换 tie-break、在共享独立样本上验证、审计系统性分歧。
- **与 Reliable Agent · 统计推断的关系**：「**报告出来的失败率本身带有偏差**」的直接证据：分类器判定顺序、提示词措辞、人群标注一致性这三个偏差源被逐一量化。这对任何以「agent 失败模式分布」为证据的可靠性结论都是必要的前置检查。
- **链接**：https://arxiv.org/abs/2611.13140

## Differentially Private Statistical Inference for Rankings from Pairwise Comparisons（2611.13485）｜stat.ML cs.LG stat.ME｜Xintao Xia, Jia Gu

- **问题背景**：基于人工两两比较给 LLM 排名，其可靠推断必须同时保护个体偏好记录的**隐私**。
- **方法**：在 **Bradley–Terry 模型**与**边级差分隐私（edge DP）**条件下，发展打分与排名的推断方法。对目标扰动估计量做新的 **leave-one-out 分析**，给出欧氏误差与逐元素误差的**有限样本界**；证明在足够稠密的比较图上，误差界可延伸到更小的隐私预算，包括**隐私项压过统计项**的区域；给出统一的渐近展开以获得个体分数与分数差的**渐近有效置信区间**。为改善有限样本表现，同时考虑**正则化偏差**与**隐私诱导的随机性**，结合 plug-in ridge 偏差校正与 Gaussian–Laplace 校准；再建立 bootstrap 过程做**同时排名推断**，给出个体排名的渐近有效置信集与 top-K 成员检验。当比较概率公开已知时，所有推断过程**无需额外隐私预算**。
- **主要结果**：通过模拟评估有限样本表现，并应用于**创意写作**任务的 LLM 排名。
- **与 Reliable Agent · 统计推断的关系**：与 2611.13186 同属「LLM 评测的统计推断」，但额外加入隐私约束。它把**正则化偏差**显式写进推断流程（plug-in ridge 偏差校正），是「agent/模型排名中偏差被显式量化并校正」的一个具体可复用案例；「隐私项 vs 统计项谁占主导」的分析思路也可迁移到受监管场景的 agent 评测。
- **链接**：https://arxiv.org/abs/2611.13485

## Agent Benchmarks Stop Ranking Before They Run Out of Tasks（2611.13541）｜cs.AI｜Zihan Dong, Qishi Zhan, Minxuan Hu

- **问题背景**：数据科学与 ML 工程 agent 在 MLE-bench、ALE-Bench、SWE-efficiency、AlgoTune 等基准上被评测，这些任务产出的是一个**量**（Kaggle 指标、比赛分数或加速比）。当这个量不再能区分最好的模型时，通常的补救是「换个更难的版本」。
- **方法**：重新给 8 个基准的**已发布运行**打分（包含 SWE-bench Verified 与 Terminal-Bench 以保证广度），并把问题定位到「测量」而非「任务」本身。作者指出多数 agent 基准把一次运行压成 **1 bit 的通过/失败**，于是引入带日期锚点的**截断对数比分数**，并把成本单列为一个独立轴。
- **主要结果**：两个失败模式：(1) **太粗**——SWE-bench Verified 上相邻的前十名 agent 差距小于其测试自身的错误量，纠正后重排相邻名次的幅度不超过删除每个 agent **随机六分之一**的通过；(2) **被参考上限卡住**——ALE-Bench 前十名按比赛分数彼此可分，但以中位人类为标准时**全部打平**，尽管近一半运行实际打败了该人类。作者结论：在固定任务上把门槛调高只是**转移问题**，**分级给分**才能解决。在 Terminal-Bench 重跑中，通过/失败打平的模型在测试所丢弃的那个量上相差**超过十倍**。
- **与 Reliable Agent · 统计推断的关系**：Agent 基准的分辨率饱和会让「模型 A 比 B 更可靠」这类结论失去统计意义。它与 2611.13596、2611.13140 构成同一问题群：**指标的度量性质（measurement）本身在制造偏差**，而不是被测对象有差别。
- **链接**：https://arxiv.org/abs/2611.13541
