## Learn then Bet: Learning Interpretable Rules for Reliable Agent Intervention（2611.17662）｜cs.AI cs.LG｜You-Lin Chen, Xinyi Lisa Chen, Pedro Herrero-Vidal, Xiaojing Yu, Bingqing Song, Bin Xu　★最贴题

- **问题背景**：自主 agent 现在可以无人监督地跑数百步，实践中靠 turn limit、关键词过滤这类 **runtime monitor** 决定何时停机、升级或人工协助。但这类启发式规则**会停掉本来会成功的运行，也会放行注定失败的运行**——「何时介入」本身是一个需要统计保证的决策问题，而现有做法只有阈值、没有保证。
- **方法**：提出 **LeBet（Learn then Bet）** 统计学习框架，学习目标由「干预有效且有功效」的**充分条件**导出：学习一个可解释的 **OR-of-AND 监控器**，用**固定下注统计量（fixed betting statistic）**累积证据，证据达到预设阈值时介入。针对学习问题中不可解的组合优化，用利用监控器布尔结构的**随机局部搜索**提议规则编辑，以提高经验可分性。
- **主要结果**：在**类内有限样本可交换性 + leave-one-out 稳定性**假设下，推出**有限样本保证**——假阳性控制（有效性）与条件于训练数据的检测功效；关键设计是用**同一批轨迹**既做学习又做校准，**不假设 i.i.d. 轨迹**。SWE-bench Lite + Ministral 3 8B：节省 **34.46%** 输入+输出 token，输出精度从 **18.33% 提升到 21.59%**，经验假阳性率 **13.64%**。
- **与 Reliable Agent · 统计推断的关系**：这是「agent 介入决策」的最小统计骨架——下注统计量是可合成的证据聚合，有限样本 FPR 控制 + 功效保证直接回答「监控器何时可信」。对「agent 做统计推断时的 bias」这一课题，它点出一个易被忽略的偏差源：**用同一批数据既学规则又做校准**，i.i.d. 假设在此失效正是偏差来源，作者用 leave-one-out 稳定性正面处理。
- **链接**：https://arxiv.org/abs/2611.17662

## Black-Box Uncertainty Quantification for Large Language Models via Ensemble-of-Ensembles（2611.18453）｜cs.LG cs.AI｜Wang Ma, Debarun Bhattacharjya, Junkyu Lee, Nhan H Pham, Harsha Kokel, Qiang Ji　★最贴题

- **问题背景**：可靠使用 LLM 需要不确定性估计，并区分 **prompt 固有的歧义（aleatoric）**与**真正的知识缺口（epistemic）**。贝叶斯与深度集成在原理上给出这个分解，但在 LLM 规模下算力上不可承受且需要白盒访问；现有黑盒方法则只汇总成单一标量，无法区分两者。
- **方法**：提出**两层集成**：对固定 prompt 的随机解码构成内层集成，对 prompt 的**保义语义扰动**构成外层集成；在连续嵌入空间度量波动，用**全协方差定律**给出精确的「组内/组间扰动」分解来估计 AU/EU，全程只需黑盒采样访问权。在此之上给出三个理论结果：(i) 嵌套蒙特卡洛的**有限样本偏差恒等式**与闭式的**偏差修正 epistemic 估计量**；(ii) **贝叶斯桥接**，界定「扰动总体 AU/EU」与贝叶斯目标之间的差距；(iii) **分离定理**，刻画出一类「任何仅靠一致性（consistency-only）的黑盒方法必然漏掉、而基于扰动的 EU 能检出」的失效模式。
- **主要结果**：5 个短问答 benchmark、4 个指令微调 LLM（2 个家族 × 2 个规模）上，估计量与强白盒基线具有竞争力；在**同等生成预算**下与领先黑盒方法的**错误排序**持平，同时完成 AU/EU 分解；受控配对干预显示 AU 与 EU 分别对 prompt 歧义与模型知识缺口**选择性响应**；NQ long-answer split 上的长文本试点表明无需重训即可扩展到 claim 级事实性。
- **与 Reliable Agent · 统计推断的关系**：本期最贴题的一篇——**模型/agent 输出的偏差被显式建模为嵌套蒙特卡洛的有限样本偏差**，并给出闭式的偏差修正量。对课题的意义在于：想要可靠 agent 的置信度，必须先说清「不确定性里哪一部分是采样噪声、哪一部分是模型真的不会」，否则下游统计推断会把 epistemic 缺口当作随机误差一并吞掉。
- **链接**：https://arxiv.org/abs/2611.18453

## Estimand-specific bootstrap confidence intervals after optimism correction for prediction models（2611.17774）｜stat.ME｜Seiya Takano, Kazuki Nishida, Ryo Emoto, Shigeyuki Matsui　★最贴题

- **问题背景**：预测模型在 bootstrap 乐观度校正（optimism correction）之后常报告置信区间，但**区间到底覆盖什么取决于 estimand**——是「用观测样本开发出的最终模型在目标人群上的表现」theta_FM,n，还是「重复整个建模流程的平均表现」theta_proc,n。二者不同，实践中却常被混用。
- **方法**：用估计误差的**一阶展开**，识别出与 theta_FM,n 误差相匹配的 bootstrap 根，把它作为**嵌套误差 bootstrap（NEB）**的新参照方法；并证明不需要内层 bootstrap 的乐观度误差 bootstrap（OEB）近似 NEB。同时证明常规的**两阶段 bootstrap（TSB）**与**位置平移 bootstrap（LSB）**复现的其实是 theta_proc,n 的一阶变异。
- **主要结果**：模拟中 NEB 在 AUC、Brier score、log loss 上**覆盖更接近名义水平**；OEB 在 EPV（每变量事件数）中等偏高时接近 NEB，但 EPV 低时区间可能更窄。**校准指标上的差异最为明显**：TSB 根中「扰动训练分布与评估分布」的一阶效应相互抵消，导致**退化的第一阶极限**；NEB 根的第一阶极限非退化，在正则条件下对 theta_FM,n **渐近有效**。与理论一致，**TSB 即使在较大样本量下对校准指标仍有严重欠覆盖**。
- **与 Reliable Agent · 统计推断的关系**：这正是「评测指标自身的置信区间覆盖了谁」的答案。审稿/评测 agent 常报告「bootstrap 校正后的 CI」，若不指明 estimand，**对校准指标的 CI 会系统性欠覆盖**——而校准恰恰是 agent 可靠性的核心读数。可直接把「指定 estimand + 指定性能度量」作为 agent 评测报告的硬性规范。
- **链接**：https://arxiv.org/abs/2611.17774

## Cross-Fitted Doubly Robust Estimation with Student-t Outcome Engines: ECM Algorithms, Monte Carlo Evidence and Schistosomiasis Programme Data from the Democratic Republic of the Congo（2611.18128）｜stat.ME｜Cosmas Kambale Musambi, Ernest Fokou'e　★最贴题

- **问题背景**：血吸虫病预防化疗的常规数据同时具备**混杂、聚类、重尾与堆值（heaping）**四个麻烦。要考察：当最小二乘被 **Student-t 结果引擎**替代（Huber / t 迭代重加权最小二乘、两成分 t 尺度混合回归配 ECM 算法、残差截断增强）时，交叉拟合的 **AIPW** 估计量**行为如何、以及应该如何计算**。
- **方法**：给出四条短命题——**AIPW 的精确偏差**、效率界、截断所对应的 estimand、尺度约束 ECM 的单调上升；提供单文件 Python 实现，含**聚类级 cross-fitting**、聚类稳健标准误与聚类 bootstrap；蒙特卡洛研究每格最多 **1000 次重复**。
- **主要结果**：鲁棒结果引擎**不改变 AIPW 本身**（RMSE 差异最多 **0.002**）；而在对称污染下，残差截断把 RMSE **降低 26–45%**，代价是**欠覆盖**，且当两组残差分布不同时会**改变 estimand**（在基于真实协变量与残差构造的疟疾模拟实验中证实）。**单侧伪影（one-sided artefacts）在两组之间不同时，会让每一个估计量都有偏**。堆值还会击穿朴素实现：MAD 尺度崩塌、混合似然无界，作者给出简单防护。应用到刚果民主共和国 ESPEN 2014–2025（**362 个卫生区、1485 轮**）：一体化配送使**项目覆盖率提高 17.4 个百分点，而流行病学覆盖率只差 0.9**——差距来自**分母定义**，是任何结果引擎都无法消除的真实差异性伪影。
- **与 Reliable Agent · 统计推断的关系**：这篇给出**「估计量偏差」最细颗粒度的清单**：精确的 AIPW 偏差公式、截断引入的 estimand 漂移，以及「分组间单侧伪影让所有估计量有偏」这一提醒。对课题「agent 做统计推断时的 bias」极有参考价值——**当 agent 替代了传统结果模型（outcome engine），它改变的不只是方差，还可能悄悄换掉整个 estimand**，而后者通常没人报告。
- **链接**：https://arxiv.org/abs/2611.18128

## Do Verifier Judgments Survive Abstraction? Measuring Verification Transport for LLM Agent Evaluation（2611.18471）｜cs.CL cs.AI｜Disha Sheshanarayana, Sai Linisha Reddy Goli

- **问题背景**：LLM verifier 被越来越多地用来评估 agent 执行，但可靠性通常只在**单一轨迹表示**下测量。真实部署里，同一次执行可能经由组合工具、委派边界或压缩历史暴露给 verifier，**可观测到的执行证据变了**，那么正确的判决能否保持不变就成了未知数。
- **方法**：提出 **Verification Transport（验证迁移性）** 这一可靠性测试，度量判决在「抽象引起的可观测性变化」下的稳定性。构造同一批**冻结执行**的**原生 / 抽象 / 复原（restored）三视图**，同时固定任务、实际轨迹、结果、真值、评测标准与 verifier 本身。
- **主要结果**：跨 4 个 agent 评测 benchmark、7 个 verifier 骨干、4 种验证协议、3 个抽象边界，发现**大量迁移失败**，在宏观抽象 + 委派下**约达 31%**。不同协议的失效模式不同：直接验证更常给出**错误判决**，而证据驱动与审议式协议更倾向于在可观测性不足时**弃权**——因此**迁移失败率低并不等于更可靠**。恢复对应的执行 provenance 可挽回 **85.5%** 的迁移失败，provenance 有损或缺失时挽回率下降。
- **与 Reliable Agent · 统计推断的关系**：指出了 agent 评测中一个常被忽略的**测量误差来源**：verifier 的读数依赖「它能看到什么」，而不只依赖「任务的真相」。若 agent 评测在抽象/委派架构下进行（几乎所有真实系统都是），则**原生视图准确率不足以刻画 verifier 可靠性**；且「错误判决」与「弃权」两种失效必须分开报告——这与统计上区分「偏差」与「方差」是同源的要求。
- **链接**：https://arxiv.org/abs/2611.18471

## Only as Safe as the Weakest Agent: A Break That Appears Only When the System Is Multi-Agent（2611.17520）｜cs.MA cs.AI｜Keegan Wang, Antantika Mannby

- **问题背景**：Codex、Claude Code 这类工业级多 agent 系统，能被一些**此前对前沿单模型长期无效**的攻击攻破。AI 安全作为学科长期聚焦于**孤立使用的模型**，而随着模型以 agent / 多 agent 形式部署，孤立时已被认为修补好的攻击会在特定条件下重新奏效。
- **方法**：构造攻击：让 agent 从磁盘上一组文件里回答问题，其中**植入一条伪造记录**。对比两种设置——**强模型 orchestrator 自己检索**（直接查文件）与**强模型委派给廉价子 agent**（正是这些 harness 的默认设计），全部使用**未经修改、各自带原生子 agent 机制**的真实系统。
- **主要结果**：强模型自己检索时，**1000 余次试验中几乎零有害修改**；但面对同样事实、改为委派给更弱的子 agent 后，失败数达到 **20/180、44/180、75/180 与 553/900**。结论是**系统的安全性落在最弱读取者身上，而不是 orchestrator 身上**。对 18 个模型的模拟进一步显示：在交付通道中，5 个单独几乎从不不安全的聚合者，在 **751/757** 次试验里复现了被污染子 agent 的错误。
- **与 Reliable Agent · 统计推断的关系**：给出多 agent 流水线中**可量化的可靠性衰减规律：聚合并不创造安全性**。做 agent 统计推断时，若把弱子 agent 的输出当作可用的观测值或标签，最终估计量的误差结构由最弱一环决定——这是「agent 做统计推断时的 bias」的**结构性来源**，与模型本身的统计能力无关。
- **链接**：https://arxiv.org/abs/2611.17520

## Conformal Risk Control for QoT-Aware Lightpath Feasibility Under Technology-Driven Domain Shift（2611.13893）｜cs.LG｜Kiarash Rezaei, Omran Ayoub, Paolo Monti, Carlos Natalino　★最贴题

- **问题背景**：AI/ML 回归模型支撑光网络的运维决策，但这类模型通常只给出**点预测，不携带任何受统计控制的可靠性信息**。
- **方法**：提出**事后（post-hoc）conformal risk control（CRC）**框架：保持预训练回归器不变，对**不确定性带的失覆盖**给出**有限样本保证**，再通过策略规则把不确定性带映射为运营决策。特征移位贡献分数识别出哪些光路特征与 QoT 的关系在技术换代中变化最大；两条策略把不确定性带转为可行性判定，让运营方在「保守拒绝」与「激进接受」之间调节。落地场景为 SDM（光分复用）QoT 数据集上的 CONUS 拓扑。

## Causal and conditional tail coefficients: asymptotics, inference and graph recovery（2611.18225）｜math.ST stat.ME stat.TH｜Axel Bücher, Mario Krali

- **问题背景**：**因果尾系数（CTC）**度量一个变量的极端值对另一变量的影响，被提出作为重尾模型下因果发现的工具，但其**经验对应物的渐近行为一直没有被充分理解**。
- **方法**：在满足所有标准 copula 模型的非参数条件下，为**基于秩的 CTC 估计量**建立**中间阈值**下的渐近理论。关键观察：CTC 由**条件尾极限分布的均值**决定，这既澄清了它的解释，也决定了估计量的渐近方差。建立**整个 CTC 矩阵的联合渐近正态性**，并证明**乘子 bootstrap（multiplier bootstrap）**对同时推断的一致性。
- **主要结果**：对重尾线性与递归 max-linear 结构方程模型，证明 **CTC = 1 当且仅当第一个变量是第二个变量的祖先**，由此得到祖先图的**置信图**，并带渐近覆盖保证；所有结果推广到一般的**条件尾系数**（作为条件尾极限分布的进一步函数）。模拟研究与膳食摄入数据应用演示了方法。
- **与 Reliable Agent · 统计推断的关系**：提供了一条「**从极端事件推断因果结构、且带覆盖保证的置信图**」的路径。方法论上最值得借鉴的是**乘子 bootstrap 做同时推断**——当 agent 批量产出多条候选因果结论、需要给出一组带联合覆盖率保证的结论时，这正是需要的工具。

## Identification and Inference of Bi-directional Causal Effects in Mendelian Randomization without Instrument Selection（2611.18291）｜stat.ME｜Liyuan Mo, Qingyuan Zhao

- **问题背景**：孟德尔随机化（MR）用遗传变异作工具变量估计因果效应。双向 MR 通常做两次反向的单向分析，但**反馈会使至少一个方向上的工具失效，并诱发相关多效性**。
- **方法**：把两个性状建模为**稳定的循环系统**，从 GWAS 汇总数据出发，**无需工具变量选择、也不需要预设的有效工具子集**，即可同时估计两个方向的效应。LD 分数归一化后，边际关联构成一个**异方差噪声独立成分分析（noise-independent ICA）模型**（假设变异对两个性状的直接效应相互独立）；若这些效应非高斯，则总效应矩阵可辨识到**尺度与置换**为止，再由「无自反馈」与「系统稳定性」消解剩余歧义。估计器基于**噪声调整的二阶与四阶矩**，**避免求逆高维 LD 矩阵**，计算量对变异数**线性**。
- **主要结果**：在弱局部依赖下证明**一致性、渐近正态性**，以及**按染色体划分的 moving block bootstrap 的有效性**。模拟显示偏差可忽略、区间覆盖总体可靠；对非零方向效应的拒绝率高于基于 focusing 的检验。三个真实数据应用说明：对反馈系统做**联合分析**可得到与两次独立单向分析**不同的因果分解**。
- **与 Reliable Agent · 统计推断的关系**：提供「**不预先指定有效工具、不做工具筛选**」的识别思路，对「agent 自动挑选特征/工具之后再做因果推断」这一常见做法有直接方法论参照——**筛选本身会改变识别假设**，而本文用矩方法绕开筛选，同时保留渐近正态性与 bootstrap 有效性。

## High-Dimensional Online Calibration from Harmonic Weights（2610.07740）｜stat.ML cs.LG｜Maxwell Fishelson, Mehryar Mohri

- **问题背景**：在任意凸集 Y 属于 R^d 上、相对任意误差范数的**多维在线校准**问题。
- **方法**：对同时预测 d 个二元结果（Y = [0,1]^d），给出**第一个轮数对 d 为多项式**即可达到 epsilon-校准的算法，需 **d^{O(1/epsilon)}** 轮，**指数级改进**此前界的维度依赖；多类预测（Y 为概率单纯形）同样得到 d^{O(1/epsilon)}，改进此前的 d^{Õ(1/epsilon^2)} 界。算法极简：每轮输出**对平滑后的历史结果做调和加权**的分布，同一算法适用于所有预测集与误差范数。更一般地，达到 epsilon-校准所需轮数为 exp(O(gamma(Y,L)/epsilon))，其中 gamma(Y,L) 是由一个矩阵偏差问题定义的几何参数。调和权重的动机是：**离散 Hilbert 变换矩阵达到最优偏差（差一个普适常数），且对每个误差范数同时成立**——这一最优性结果本身也可能有独立价值。相同的调和响应还给出高维 **Blackwell 可逼近性**的算法，其保证由一个刻画结果集与行动集联合几何的锐化几何参数支配。
- **主要结果**：以上均为理论结果（无实验数字）。调和权重之所以被选用，正是因为离散 Hilbert 变换矩阵在矩阵偏差问题上达到最优。
- **与 Reliable Agent · 统计推断的关系**：给出了「**高维 agent 输出同时校准**」在维度上可扩展的方案（d 为多项式而非指数）。对同时输出多个置信度/概率头的 agent 而言，这是少见的把**校准质量与输出维度解耦**的保证路径。

## More Agents, More Samples, or More Thinking? Untangling Coordination, Ensembling, and Test-Time Compute in Multi-Agent LLMs（2611.17610）｜cs.AI cs.CL cs.LG cs.MA｜Seyed Mahmoud Sajjadi Mohammadabadi

- **问题背景**：多 agent 语言的评测常拿「通信架构」与「单次贪心解码」对比，这**把协调、样本数与推理算力三者混为一谈**，导致结论不可比。
- **方法**：综合 **9 项主要实证评测、516 个不同的多 agent 配置**，沿六维资源向量组织，并建立四类基线阶梯（A 单次通过 / B 样本数匹配 / C 资源预算匹配 / D 其他）。
- **主要结果**：对单次通过基线（A 类），多 agent 准确率差异**总体为负**，剔除贡献最大的那项研究后接近零；换成**样本数匹配（B 类）或资源预算匹配（C 类）**的基线后，多 agent 系统平均准确率 **−0.042**，在对数几率尺度上的多层随机效应模型在各项敏感性检验下**仍为负**；**74% 的可比对比中多 agent 准确率等于或低于基线**，且几乎所有被评估研究的均值非正。跨同时报告两类基线的研究，从贪心通过换成采样基线使准确率差异平均变化 **−0.038**。核心洞见：**当 agent 共享相同证据时，通信并不增加信息**，正向回报需要**分区证据、外部验证或跨模型的错误多样性**。作者另给出审稿清单与核算工具。
- **与 Reliable Agent · 统计推断的关系**：这是一篇「**把 agent 评测的混淆变量拆干净**」的方法论论文——评测偏差（把采样量当成协调能力）正是结论不可信的根源。对课题的启示是：**任何「agent 更强」的说法都必须先控制资源向量**，否则测到的可能是采样量而不是可靠性。

## Fast Uncertainty Quantification for Kernel-Based Estimators in Large-Scale Causal Inference（2603.13662）｜stat.ME stat.AP stat.ML｜Matthew Kosko, Falco J. Bargagli-Stoffi, Lin Wang, Michele Santacatterina

- **问题背景**：核方法在因果推断中广泛用于处理效应估计、策略评估与策略学习。bootstrap 是标准的不确定性量化工具，但随着数据量增大，计算需求急剧上升——例如 2023 年美国 NVSS 出生数据含 **3,605,081** 例登记出生（其中 **2,980,739** 例经队列限制后进入分析样本）。核方法本就随样本量扩展性差，bootstrap 所需的**反复重拟合**让情况雪上加霜，最终在大规模场景下基于 bootstrap 的核方法推断**计算上不可行**。
- **方法**：把 Kosko 等（2023）的因果 Bag of Little Bootstraps（**cBLB**）算法**扩展到核方法**，通过**子采样 + 再抽样**的组合获得计算可扩展性，同时**保持一阶不确定性量化与渐近正确的覆盖**。在三种代表性实现上评估：核化增广结果加权学习、基于核的最小极大加权、以及基于核支持向量机的双重机器学习。
- **主要结果**：模拟中该方法以**名义覆盖**给出置信区间，而计算成本只是标准 bootstrap 的一小部分。真实应用：在 NVSS 数据集上估计「任意量吸烟对出生体重的影响」以及最优治疗策略，此时**标准 bootstrap 在此规模下计算上实际不可行**。
- **与 Reliable Agent · 统计推断的关系**：解决的是「**大样本下不确定性量化根本做不动**」这一工程约束——当 agent 参与估计流程、数据量达到百万级时，重抽样类推断（bootstrap、cBLB、乘子 bootstrap）会先在算力上崩掉。这条路径给出了一阶近似 + 渐近正确覆盖的折中，值得纳入 agent 统计推断的方案选型清单。
