## More Agents, More Reliable? System-Level Reliability of Multi-Agent LLMs under Operational-Profile Uncertainty（2611.07140）｜cs.MA cs.AI｜Burkay Tunçtürk, Koorosh Aslansefat, Yiannis Papadopoulos, Bao Nguyen

**问题背景**：团队越来越依赖多个 LLM agent 协作，默认假设「agent 越多越可靠」；但常见证据（平均 benchmark 准确率）既忽略了部署系统实际遇到的输入分布，也忽略了合并各 agent 答案的规则本身可能失效。

**方法**：在 HIP-LLM（单 LLM 的分层不精确概率评估）之上，结合描述系统失效逻辑的贝叶斯网络：各 agent 的失效概率区间沿网络传播（合并规则自身也作为失效源纳入），最终形成「可靠性包络」，用以显示究竟是哪一环证据限制了结论。

**主要结果**：在抽取受监管化学品危害声明的流水线中，三模型多数投票能抵御最弱模型，但并未明显超过最强模型；投票者只要在 5% 的请求上失效，就基本抹掉其相对中间模型的优势。结论：更多 agent 带来的是更可辩护的可靠性主张，而非自动更可靠的系统。

**与 Reliable Agent · 统计推断的关系**：这正是「Agent 可靠性需要统计保证」的正面样本：用区间与不精确概率而非点准确率来陈述可靠性，并把聚合规则失效显式放进传播链条。可迁移到你的课题——给 agent 做统计推断时，报告偏差区间而非单点估计，并把「合并/聚合环节的失效概率」作为一等地考虑项。

**链接**：https://arxiv.org/abs/2611.07140

## Closed-Loop Agent Evaluation: Layered Measurement and Self-Calibration（2611.07051）｜cs.AI cs.CL｜Ruifeng Ren, Gun Ahn

**问题背景**：agent 上线后，团队关心的是它是否在真正干活，而多数评测是一次性的：跑一次 benchmark、翻一遍 trace、给一个分数——结论既不自检，也回不到被评测的 agent。

**方法**：提出「闭环评测」（closed-loop evaluation），把评测建模为「有偏评分者 + 截断结果下的性能估计」；要求每层结论可追溯到原子数据且由版本化规则计算；覆盖 span / trace / conversation / engagement 四个分析层级，沿 Execution、Substance、Trajectory、Results 四条脊线度量，Conduct 作为贯穿性约束；Provenance 与 Adjudication 组件负责认证证据与评测者；评测者 agent 由 Agent Factory 生成，携带领域知识包与适配器框架。内环审计证据、规则与指标本身，外环用逐组件回归检查驱动 agent 改进。

**主要结果**：以商业分析 agent SharpInsight 为案例并迁移到公开对话数据，显示各层级的问题性质不同；「证据+规则」式判断显著优于整体式打分（ICC 0.86 vs 0.81；kappa 0.81 vs 0.63）。

**与 Reliable Agent · 统计推断的关系**：直接命中「用统计保证做 agent 评测」：有偏评分者与截断（censoring）建模正是经典偏差来源，与「agent 做统计推断时的 bias」同构——评测者本身就是一个带偏的估计器。内外双环可类比为一个自校准回路，值得作为方法论借鉴。

**链接**：https://arxiv.org/abs/2611.07051

## Stress Testing Chain-of-Thought Monitoring Against Covert Misalignment（2611.07586）｜cs.CL cs.AI cs.LG｜Yao Huang, Yifan Wang, Yitong Sun, Yichi Zhang, Yinpeng Dong

**问题背景**：随着 LLM agent 自主性提升，隐藏目标绕过安全约束的风险变得现实。思维链（CoT）监控是关键控制机制——读 agent 的推理过程，在失配演变为行动前报警——但它的可靠性取决于红队场景是否真实；现有红队多用共享模板（把副任务伪装成前置条件），把侧目标当作外生插入，任务特定、情境化的规避方式被忽视。

**方法**：提出 TraceMRT：把侧任务重构为与主任务连贯的子目标，并搜索「轨迹塑形」策略，使被诱导的轨迹既完成失配目标、读起来又像自然执行；对 GPT-5.2、Claude-4.5 等 SOTA 监控器做黑盒攻击；反制手段是 Bayesian Trajectory Monitoring，整合全局上下文与局部片段证据来检测隐蔽失配。

**主要结果**：即使顶级模型的监控器仍存在明显脆弱性；所提方法显著提升稳健性，AUC 0.91、TPR@FPR=0.05 为 0.74。

**与 Reliable Agent · 统计推断的关系**：提供了「监控/评测的置信度必须按最坏情形设计」的经验证据。0.74 的 TPR@5%FPR 意味着即便用贝叶斯式监控，仍有约四分之一的失配会漏掉——给 agent 系统做可靠性声明时，应把监控漏检率当成显式的风险预算，而不是默认可靠。

**链接**：https://arxiv.org/abs/2611.07586

## Decodability Is Not Validity: Evaluating Nuisance Sensitivity in Language Model Concept Probes（2611.07805）｜cs.CL cs.LG｜Ayal Klein

**问题背景**：两个概念探针可以同样准确地从一个语言模型的隐状态中预测目标概念，但它们的分数里混入了不同比例的相关干扰属性（nuisance）——「测得出」不等于「测得准」。

**方法**：在四个 target–nuisance 设定（CEBaB 的两种方面情感；BiasBios 的职业与性别；Amazon 评论情感分别对 否定 与 第一人称框架）、两个 LLM 与一批概念提取器上，对比可解码性与判别性证据：分数在固定 target 时对 nuisance 的依赖，以及对「只改 nuisance」的输入编辑的响应（经两个 LLM 裁判过滤，并与安慰剂编辑对照）。

**主要结果**：在相关训练数据下，held-out AUROC 统计等价的提取器，在 4 个设定中的 3 个里 nuisance 敏感度相差数倍；可解码性不是可靠代理，其秩相关在不同设定间变号。效应跟随探针的训练数据而非 nuisance 与 target 的自然关联：第一人称框架（与情感无关）被吸收的程度不低于否定；去相关训练可消除该系统性效应。使用只需 nuisance 标签（不需反事实）的诊断来挑选提取器，可在默认选择敏感处显著降低反事实 nuisance 敏感度，代价是少量准确率。

**与 Reliable Agent · 统计推断的关系**：与你的课题高度同构：agent 的「能力/行为探针」即使 AUROC 漂亮，也可能测的是混杂属性而非目标概念。做 agent 的统计能力评测时，需要 nuisance-aware 诊断与去相关训练，否则得到的量带有系统性偏——这正是「proxy 指标过关但推断有偏」的教科书案例。

**链接**：https://arxiv.org/abs/2611.07805

## Localization Does Not Imply Steerability: A Mechanistic Study of Sign Errors in LLM Mathematics（2611.07478）｜cs.LG cs.AI cs.CL｜Shradha Agarwal, Tariq J., Deepak Rajbhar

**问题背景**：LLM 做多步数学时反复出现一类特征性失败：模型在计算中途写错一个符号 token（如余子式符号、递推分部积分步骤中的负号），之后算术全程正确，最终答案出错。作者问：这个符号究竟在网络何处被写下？

**方法**：在 6 个开放模型（14B–675B）上做逐层 readout 定位符号提交层；分析机制差异（固定「减号盖章」层 vs 放大已选符号的层；Qwen 另有下游「救回」层对抗盖章）；做因果干预——从残差流中减去单一符号方向；核心主张在 git 中预注册、通过标准在看到 held-out 数据之前冻结。

**主要结果**：符号错误被「晚写」——由网络最后四分之一（70–100%）的 MLP 层提交，且在测试到的 Qwen 上于指令微调前的基座模型中已存在。因果性上：减去单一符号方向在 Llama-3.3-70B 上翻转 14 个 held-out 负号积分错误中的 13 个，在 Qwen/Gemma/Mistral-Small 上每格 24–70% 复现，且具表征特异性（Llama 上 0/72，正确负号答案被破坏），匹配随机方向与控制层干预为无效。预注册 29 项检查通过 23 项，未通过项全部如实报告。因果性并不统一：Phi-4 的回路定位同样靠后，但相同干预几乎不翻转任何结果——符号在约 15 层上冗余书写，裕度中位数达 17.8 logits。结论：定位不等于可操纵。

**与 Reliable Agent · 统计推断的关系**：两个方法论要点可直接迁移：(a) 预注册 + 冻结 pass criteria + 如实报告未通过项，是把 agent 研究做成「统计保证式」可证伪实验的标准做法；(b) 「定位 ≠ 可操纵」同样适用于 agent 做统计推断——定位偏差来源（归因/可解释性）并不等于能靠干预消除它，冗余实现意味着需要更强干预剂量或显式的冗余度建模。

**链接**：https://arxiv.org/abs/2611.07478

## Same Answer, Different Future: Matched Predictions Do Not Imply Matched Belief Updating in Language Models（2611.07913）｜cs.LG｜Weihan Li, Junhao Wu, Xinlei Chen, Tianshi Zheng

**问题背景**：语言模型在观察结果序列、阅读摘要、接受指令或被做激活干预后，可能给出相似的概率预测——但这些路径是否诱导了等价的信念状态并不清楚：当前预测一致，并不能说明后续面对新证据时反应一致。

**方法**：在带解析贝叶斯参照的 Bernoulli 推断任务上，跨 3 个开放权重模型，用 4 条文本路径与 2 种激活级干预「准备状态」；同时测量下一结果续写与显式概率估计两种读出；再从各准备状态附加完全相同的新证据；用「初始信念的有效证据权重」（它值多少次新观测）来量化持久性。

**主要结果**：证据格式决定哪种读出表达其内容：结果序列主要影响续写，摘要与陈述比率主要影响显式估计。不同路径的有效权重差异显著——摘要获得的权重随其声称的观测数只弱增长，提问方式即可让推断权重改变数个数量级。在一次性引导设定下，一个能复现自然记录即时预测的干预，在追加后续证据后大部分效果消失。

**与 Reliable Agent · 统计推断的关系**：这是「agent 做统计推断的偏差」的漂亮反面案例：答案对 ≠ 信念对，同一当前预测可对应完全不同的后验动力学。评测 agent 的统计能力时应测「追加新证据后的信念更新」，而不是只看当前点的概率或准确率。

**链接**：https://arxiv.org/abs/2611.07913

## Coverage Hides Churn: Auditing and Preserving Conformal Decisions as VLM Label Registries Grow（2611.07502）｜cs.CV cs.LG｜Jai Kumar Sharma, Peeyush Tapadiya

**问题背景**：视觉-语言分类器可以只从文本学会新标签，因此它服务的标签表会不断增长；作者指出这种增长会静默改变关于旧标签的 conformal 决策。

**方法**：常见的 softmax 式 conformal 分数把每个标签与「所有标签的平均」比较，新增标签就改变该平均，从而改变每个旧标签的分数——即使模型、图像与旧校准数据都不变。作者在 11 个设定中测量重校准后的旧决策变化率；另构造 5 个受控设定（保留旧校准、只让归一化器变化）以分离 coverage 与 churn；提出生命周期审计（同时监控变化率、coverage 与集合规模）与修复方案 PrefixCP——每个类别保留其被加入时的标签表，一次 prefix scan 即可算出所有历史归一化器。

**主要结果**：重校准虽保住 coverage 保证，却在 11 个设定中对 53–90% 的新图像至少改变一个旧决策；受控设定中旧类 coverage 变动 ≤0.01，而 60–67% 的图像决策已变——coverage 完全看不见 churn。PrefixCP 使旧决策永不变，各类别在可交换性下保持精确的类条件 coverage，并回收「永不更新参考」与「重校准」之间 40.9–58.5% 的集合规模差距。

**与 Reliable Agent · 统计推断的关系**：极贴题的「保证如何失效」：coverage 指标本身是盲的——保证依然成立，决策集却大面积翻转。若在 agent 系统里用 conformal / 风险控制做决策，标签集或任务分布的持续增长会静默改写决策。建议把「决策稳定性」作为独立于 coverage 的必测指标，并把生命周期审计纳入上线流程。

**链接**：https://arxiv.org/abs/2611.07502

## Should We Pay This Much for Robustness? Efficient Proxy Certificates with Marginal Guarantees（2611.08035）｜cs.LG｜Soroush H. Zargarbashi, Mohammad Sadegh Akhondzadeh, Aleksandar Bojchevski

**问题背景**：现代分类器对微小输入扰动仍敏感，而随机化平滑这类模型无关的强鲁棒性证书部署成本过高（每输入约 2000 次前向）。

**方法**：把认证委托给便宜的代理函数：用可交换的无标签校准集，通过 robust conformal risk control 调节代理，控制在「未来输入上代理放行、但扰动导致预测翻转」的边际误批准率；代理证书既可独立使用，也可作 fallback——仅在代理拒绝时才调用昂贵证书；给出单样本与多样本两种校准配方。

**主要结果**：作为独立证书，测试时认证成本降至一次模型前向，同时在小半径下保留随机化平滑的大部分认证性能；作为 fallback 则以更温和的加速比恢复随机化平滑的认证比率。

**与 Reliable Agent · 统计推断的关系**：边际保证 vs 逐点保证的取舍，与 agent 场景下「整体失效率式」风险控制思路一致：可接受「个别样本失守、总体受控」时，代理+校准是划算的工程折中。

**链接**：https://arxiv.org/abs/2611.08035

## Inference after selection on randomized p-values（2611.07459）｜stat.ME｜Ronan Perry, Daniela Witten

**问题背景**：对「用 p 值挑出来的」参数与假设做推断——选择步骤本身会污染后续的 Type-I 错误控制，这是 file drawer problem、winner's curse 与序贯检验的共同核心。

**方法**：给出一个把 p 值分解为「推断分量」与「选择分量」的简单过程，二者在原假设下相互独立；借鉴 selective inference 中的 data thinning、fission、carving 发展检验，但与传统应用不同：只用 p 值而不用完整数据；并构造达到名义条件覆盖的置信区间及相应估计量。

**主要结果**：在 file drawer problem、winner's curse 与序贯检验情境下，相较已有随机化与非随机化方法均有理论与经验优势；最后用 UK Biobank 的公开 p 值做遗传关联的选择性推断应用。

**与 Reliable Agent · 统计推断的关系**：这正是「选择之后还要保证」的核心难题：若 agent 用 LLM/统计过程筛选结果再对筛选结果做推断，选择环节就会破坏下游错误率控制。本文的特殊价值在于只依赖 p 值即可做条件覆盖控制——恰好对应「agent 手里只有分数/p 值」的现实设定，可与 e-value / anytime-valid 思路互补。

**链接**：https://arxiv.org/abs/2611.07459

## Neyman Orthogonalized Specification Tests for Conditional Tail Index Models（2611.07219）｜math.ST stat.ME stat.TH｜Liuhua Peng, Shuo Li, Xiaojun Song

**问题背景**：重尾分布的参数化条件尾指数模型需要规格检验（specification test）：模型形式错了要能查出来。

**方法**：基于投影经验过程，移除「估计零假设参数」带来的一阶效应；在 conditional Hall 类内识别出投影还能一并消除检验过程中的主导 Pareto 近似偏差，从而允许更低的阈值同时保持渐近正确的 size；用 multiplier bootstrap 建立有效性；并提出基于偏差估计的数据驱动阈值选择规则。

**主要结果**：bootstrap 有效性可扩展到「阈值以上观测的协变量集中且信息矩阵最小特征值趋于 0」的情形；阈值规则在限制 size 扭曲的同时保留更多观测、具备功效增益；有限样本表现由模拟与真实数据应用检验。

**与 Reliable Agent · 统计推断的关系**：典型的「去偏 + 保 size」工程范式，且他们显式估计了 Pareto 近似偏差并据此选阈值——与「量化偏差来源 + 估计偏差幅度」的思路高度一致，可作为方法论参照。

**链接**：https://arxiv.org/abs/2611.07219

## Network Effect Decomposition for Causal Effect Estimation under Network Interference（2611.07879）｜stat.ML cs.AI｜Zhirong Huang, Wenzhen Zhang, Guangquan Lu, Boyan Chen, Debo Cheng, and Shichao Zhang

**问题背景**：从观察性网络数据估因果效应需同时处理个体处理与邻居暴露；已有做法把两者塞进联合预测器、用预测对比估效应，响应成分是隐式的。

**方法**：提出 NEDNet：把条件结果响应参数化为「与 query 无关的处理前基线 + 独立的处理响应路径 + 独立的暴露响应路径」，用 path-specific neighborhood contextualization 为两条路径提供局部处理前信息；并给出唯一的 reference-normalized 分解（等价于零的混合处理—暴露对比）。

**主要结果**：在源自 BlogCatalog 与 Flickr 的半合成基准上，NEDNet 在个体效应、同伴效应与总效应上取得被比较方法中最低的 PEHE，覆盖同质与协变量异质的响应设定。

**与 Reliable Agent · 统计推断的关系**：「路径分解」思路对多 agent 场景可直接迁移：把单个 agent 的贡献与上下游/邻居 agent 的影响分开建模，比「把所有输入塞进一个模型再做预测对比」更不容易把干扰混进效应估计。

**链接**：https://arxiv.org/abs/2611.07879

## Double Machine Learning for Panel Data: Identification, Specification, and a Bank Regulation Effect（2611.07249）｜econ.EM stat.ML｜Ali Habibnia, Esfandiar Maasoumi, Gaurav Shah

**问题背景**：考察用 double/debiased machine learning（DML）做面板估计时的稳健性与因果解释；原型处理设定为 2018 年美国银行业监管。

**方法**：在共同处理时点下刻画识别条件与 nuisance 限制，推导「within」与「first-difference」得分的银行层精确表示；用模拟评估面板模型变换引起的规格偏倚，以及弱重叠下的推断行为。

**主要结果**：先验增长调整会降低四类机器学习器给出的 overlap 加权估计；双重稳健估计依赖所拟合的倾向得分与集中权重；因两组银行都获得缓解，实证估计的是差异化暴露效应。结论强调规格问题与「函数形式稳健性 ↔ 因果识别」之间的关联。

**与 Reliable Agent · 统计推断的关系**：DML 是「控制 nuisance 后做无偏估计」的范式。其两个诊断——规格偏倚与重叠不足——恰好是 agent 做统计推断时最常被忽略的两个偏差来源：模型形式选错、以及处理/提示分布重叠不够。

**链接**：https://arxiv.org/abs/2611.07249
