## Realized versus Population Reliability: Anytime-Valid Self-Consistency Certification under Correlated Reasoning（2611.26592）

`stat.ME`、`cs.AI`、`cs.LG`｜Terence D. Agbeyegbe, Toneukarin G. Agbeyegbe

**问题背景.** 自一致性（self-consistency）认证把「对语言模型重复采样」当成**序贯证据累积**：每采一次就更新一个 $e$-process，一旦越过阈值就停手，由 Ville 不等式给出**有限样本 I 类错误控制**。但既有构造都假设各次 rollout **条件独立**。本文指出：真实推理流由于共享推理前缀、跨 prompt 异质性而**正相关**，于是被认证的假设本身变了——不再只是效率下降，而是**结论对象发生漂移**。

**方法.** 用**逐单元潜状态**（随机效应 / 组内相关结构）建模依赖，得到可交换、等相关的增量，相关系数记为 $\rho$。相关性把单一零假设**裂成两个**：**实现零假设**（realized null，关于这一次抽到的信念）与**总体零假设**（population null，关于模型平均行为），二者仅在 $\rho = 0$ 时重合。

**主要结果.**

- (i) 标准下注型 $e$-process 对**实现零假设**仍然 anytime 有效，但对**总体零假设**不成立；
- (ii) 若当作总体零假设检验来读，某个合适的混合过程其渐近越界概率**至少为** $\pi = P(\mu(Z) > 0)$，**可能超过名义 $\epsilon$**；
- (iii) 单元内均值的**有效样本量在 $1/\rho$ 处饱和**——所以「在同一 prompt 上多采几次」**无法**恢复总体有效性；
- (iv) **prompt 级 $e$-process 可恢复总体有效性**，且在纯 rollout 预算下最优分配是**每个 prompt 只采一次**。
- 仿真与 Claude Haiku 4.5 rollout 实证该依赖依赖性：GSM8K 上（$\hat\rho = 0.435$，$\hat\theta = +0.96$）差异处于潜伏状态；AIME 上（$\hat\rho = 0.480$，$\hat\theta = -0.15$）单单元规则在名义 $\epsilon = 0.05$ 下**有 24% 的 prompt 发生越界**，而 prompt 级程序**全部拒绝（0.00）**。

**与 Reliable Agent · 统计推断的关系.** 本期第一篇，也是 traveler 当前课题（「Agent 做统计推断时的 bias」）最正面的一次撞击：它证明**当采样相关时，agent 的「可靠性证书」支持的是另一个命题**——这不是估计量偏差，而是**声明层面的偏差**（certify 了 A，却讲成 B）。三条可直接落地的结论：（一）agent 做重复采样统计时，**先测依赖**（同 prompt 内 rollouts 的组内相关），再决定证书能说什么；（二）如果目标是「模型整体行为」，**采样预算应摊到不同 prompt**，而不是在单个 prompt 上堆样本，因为后者有效样本量会饱和在 $1/\rho$；（三）这正是「静默的 bias」——数值上「$\alpha$ 有保证」，语义上「保证的是另一个零假设」，除非报告里写清楚。

**链接.** https://arxiv.org/abs/2611.26592

## Sequential Anytime Valid Tests for Efficient Inference-Time Alignment（2611.26413）

`cs.LG`｜Vishesh Kumar Singh, Sayak Ray Chowdhury

**问题背景.** Best-of-N（BoN）这类推理期对齐方法给**每个 prompt** 固定预算，而不同 prompt 的难度差异极大，多数算力被浪费。已有的自适应早停方法阈值是**启发式**的，对「早停造成的错误」没有任何统计控制。

**方法.** 目标改为：给定误差容忍 $\alpha$，只在能证明某个答案占多数（$\theta_a > 1/2$）时才停手，且这个证明要**随时有效**。做法是按最终答案聚类、用**奖励加权自一致性**（RWSC）打分，再把「何时停」当成对聚类的序贯检验。朴素版 SPRT-RWSC（Wald 检验）经验表现好但**保证失效**：主导答案会在采样中途改变，且整个过程被持续监控（多重查看）。本文的 **e-RWSC** 把 Wald 换成**下注型上鞅（$e$-process）**，对策略产出的**每个**答案各建一个，把「曾认证过一个非主导答案」的概率压到 $\alpha$ 以内，且**对时间与所有答案一致成立**。RWSC 分数只影响**认证多快**，不影响有效性。认证所需样本数为 $O(\log(1/\alpha) / d_{\mathrm{KL}}(\theta_{a^\star} \| 1/2))$。

**主要结果.** 跨多个语言模型、数据集与奖励模型的实验证实了预测的 **$1/d_{\mathrm{KL}}$ 成本标度**；在**显著更低的 token 成本**下准确率优于基线。

**与 Reliable Agent · 统计推断的关系.** 与上一篇构成「同一套数学、两个落点」的一对：2611.26592 讲**怎么把相关性也算进去**，本文讲**怎么把 agent 的早停决策变成一个可证伪的检验**。对 traveler 的意义在于，BoN/自一致性/多数投票这类「看起来很统计」的 agent 组件，通常只报告最终准确率，**从不报告「我为什么敢停」**；本文给出的是一张可直接抄的报表结构——误差容忍 $\alpha$、认证对象（某答案占多数）、保证形式（随时有效、对所有答案一致）、以及随 $\alpha$ 变化的成本标度。特别值得警惕的是它对 Wald 检验失效原因的诊断：「**主导答案中途漂移 + 持续监控**」正是 agent 流水线里最常见的两个坑（候选集动态 + 反复 peek），换成 $e$-process 之后才补上。

**链接.** https://arxiv.org/abs/2611.26413

## Causal Discovery with False Positive Error Control（2611.25376）

`stat.ML`、`cs.LG`｜Erik Jahn, Venkat Chandrasekaran, Frederick Eberhardt, Leonard Schulman

**问题背景.** 因果发现给出的是**数据驱动因果假设**，它们可能成为新的科学发现或支撑下游干预决策；在这类场景里**假阳性因果声明比假阴性更致命**。但极少有方法以假阳性错误控制为目标，且既有误差保证多为渐近的、并依赖**强版本的忠实性假设**。

**方法.** 提出 **$m$-保守 PC 算法**，并证明在**线性高斯设定**下、仅需**极弱版本的忠实性假设**即可控制 FDR。框架中，因果图的假阳性错误按其**蕴含的独立性信息**定义，因此该指标**同时惩罚错误邻接与错误边定向**。参数 $m$ 量化了「算法复杂度」与「所需忠实性强度」之间的权衡。算法由三部分组成：无向图学习 + **Benjamini–Yekutieli 式**条件独立检验 + 保守定向步骤（把无法判定或方向冲突的边标记为 ambiguous）。

**主要结果.** 算法输出有效，且**在有限样本设定下仍保留误差保证**——即使条件独立检验本身带有随机误差。

**与 Reliable Agent · 统计推断的关系.** 「假阳性比假阴性更致命」这句话，正是 agent 做因果/统计推断时的标准处境：agent 一次抛出几十条候选因果边，**报错一条的代价通常远高于漏掉一条**。三点可迁移：（一）用**弱忠实性**换控制强度，这正是 agent 场景需要的取舍——真实数据几乎不满足忠实性；（二）把「假阳性」按**蕴含的独立性信息**来定义，等价于**同时考核边与方向**，避免了只对无向骨架做 FDR 而放任定向错误；（三）有限样本仍保 FDR 保证这一点很关键：agent 的 CI 检验是自己搭的、噪声不可控，这篇的做法（保守定向 + 标记 ambiguous）本质是**把「不确定」显式暴露**，而不是硬给一个方向。

**链接.** https://arxiv.org/abs/2611.25376

## A Statistical Framework for Training Data Auditing of Large Language Models（2611.26264）

`stat.ML`、`cs.LG`、`stat.AP`｜Shengjie Niu, Yeheng Ge, Jian Huang

**问题背景.** 「某份数据是否被用于训练某个 LLM」是隐私审计、版权保护与**基准污染检测**的核心问题。现实难点有二：训练成员信号往往**集中在一篇长文档的少数段落**，需要在文档内部聚合证据而不稀释这种局部信号；面对一个**目标数据集集合**，又需要一个总体层面的评估。

**方法.** 提出统一统计框架，覆盖三件事：**文档级成员推断**、**目标集合的全局审计**、**可疑子集识别**。做法是先用 **Cauchy 组合**把互补的 chunk 级成员证据整合成文档分数，再用其**校准 p 值**支撑全局审计与子集识别（子集识别通过多重检验完成）。

**主要结果.** 在**可交换性**条件下证明了：文档级 p 值的**有限样本有效性**、全局审计的 **I 类错误控制**、子集识别的 **FDR 控制**。案例研究覆盖 BookTection、Pile-arXiv、Cosmopedia、HealthCareMagic（预训练与微调两类场景）。

**与 Reliable Agent · 统计推断的关系.** 这是「统计保证 + LLM 评测」的教科书式范例：**把一个含糊的问题（有没有被训过）翻译成检验问题**，再逐层给出有效性、I 类错误、FDR 三种不同强度的承诺。对 traveler 的 bias 课题，它示范了一个很关键的迁移：**当 agent 声称「某结论来自某数据/某文献」时，这本身是一个可检验命题**，而且不同粒度需要不同控制（单个文档 → 有限样本 p 值；整个语料库 → 全局 I 类错误；可疑子集 → FDR）。另外「局部信号不能被全局平均稀释」提醒：**agent 报告统计结论时，要区分「整体层面成立」与「具体某一条成立」**，这与 2611.25376 的独立邻接/定向分别计分是同一个思路。

**链接.** https://arxiv.org/abs/2611.26264

## Conformal Selection for Hierarchical Streaming Data（2611.26328）

`stat.ML`、`cs.LG`｜Zhenyuan Sun, Chengyao Yu, Ruixing Ming, Bingyi Jing

**问题背景.** 许多现实任务要求**在候选的「应答」被看到之前**就序贯决定是否选择该候选。既有在线 conformal selection 框架都建立在 i.i.d./可交换假设上，而真实场景里候选往往来自**不同群体**（分层结构），可交换性被破坏。

**方法.** 提出 **Online Hierarchical Selection（OHS）**：一个分布无关（distribution-free）的方法，用于分层数据流上的候选选择。核心技术是为**组间**与**组内**样本分别构造**基于秩的 e-value**，再把平均 e-value 接入**在线 e-BH 过程**；进一步提出带反馈的 **OHSF**，利用「应答反馈」提升功效。

**主要结果.** 在较弱的**分层可交换性**与数据到达假设下，所提方法**在任意时刻**都实现 **FDR 控制**；并推广到协变量偏移、基于效应相关的应答选择等更广设定；仿真与真实数据实验均验证有效。

**与 Reliable Agent · 统计推断的关系.** 两个关键词值得单独记下：其一，**「在任意时刻控制 FDR」**——这正是 agent 边跑边报场景需要的性质（跑到一半就得给结论，而不是等全部结束再校正）；其二，**e-BH 与 e-value 的组合**把「多重检验」写进了**在线**流程，而不是事后补救。对 traveler 的课题，它提供了「**分层数据下的多重检验 + 在线决策**」这一具体模板：agent 在不同子任务/子群体上并行产生候选发现时，组内与组间的依赖结构必须显式建模，否则 FDR 保证不成立。

**链接.** https://arxiv.org/abs/2611.26328

## Causal Effect Estimation Under Uncertain Statistical Surrogacy（2611.26289）

`stat.ME`、`math.ST`、`stat.AP`、`stat.TH`｜Yi Liu, Alexander W. Levis, Shu Yang, Larry Han

**问题背景.** 代理终点（surrogate endpoint）能提升因果效应估计的效率，但这种「效率红利」依赖结构假设。其中一个是**统计代理性**（statistical surrogacy）：给定代理与基线协变量后，主要结局与处理条件独立。本文研究的正是**多个候选代理有效性存疑**的情形，并考虑主要结局完全被观测或存在缺失。

**方法.** 刻画「代理辅助估计量」与「基准估计量」之间的**渐近效率差**；刻画**违反统计代理性所引入的偏差**，并给出何种条件下引入代理信息带来效率增益或损失。提出 **SACES**（Surrogate-assisted Adaptive Causal effect EStimation）：**锚定在稳健基准估计量上**，再按估计的均方误差准则，在有限个代理辅助估计量中**自适应选择**。

**主要结果.** SACES 在统计代理性成立时**取得效率增益**，在假设被违反时**保持一致性**；在不同程度的代理性违反下取得良好的偏差–方差权衡；并用 **ACTG 175 临床试验数据**做了实证。

**与 Reliable Agent · 统计推断的关系.** 「**假设存疑时，不要直接用那个更准的估计量**」——这是 agent 做统计推断最常见的翻车姿势：agent 会拿到多个候选分析路径，挑那个**结果最好看**的报出来。本文给出的纪律是：先用**稳健基准**锚定，再按**可估计的 MSE 准则**自适应切换。对 bias 课题的含义很直接：**「选择哪个估计量」本身是一个需要被统计保护的决策点**，否则 agent 的挑模型行为就是一个隐式的多重检验问题（本期 2611.25376、2611.26264 也在讲同一件事的不同侧面）。

**链接.** https://arxiv.org/abs/2611.26289

## Pandora's Toolbox Or Why Agent Safety Cannot Be Verified（2611.25325）

`cs.AI`｜Mario Franco, Carlos Gershenson

**问题背景.** 现有 AI agent 的构造方式是**一个固定语言模型与一台通用计算设备的耦合**。本文问：这种耦合下，agent 的安全性是否可判定？

**方法.** 对「agent 是否会执行某个语义等价程序的判定」给出**不可判定性**证明，并分析若干放松设定。

**主要结果.**

- 一般情形下安全**不可判定**：给定某个危险程序，**没有任何算法**能预测 agent 是否会运行其语义等价物；
- 因此 **guardrail、黑名单、白名单、认证**都只能给出**不完美的**安全方案；
- 在**有限约束**（有界上下文、有界取值、有界运行时间）下安全变为**可判定但不可解**——即使已知 agent 的完整描述，该问题仍为 **PSPACE-完全**；
- 安全**不是可组合性质**：各自可被证明安全的 agent，组合起来仍可能产生不安全行为；
- 文中讨论了实践中可用的**放松版安全 notions**。

**与 Reliable Agent · 统计推断的关系.** 给「可靠 agent」划了一条硬边界：**不要指望存在一个通用的运行期检验器能证明 agent 安全**（这与 2611.26592 的「相关性会改变被认证的假设」互为镜像）。三条工程含义：（一）guardrail / 白名单是**工程上的缓解**而非**保证**，报告可靠性时不应把它们写成「已验证安全」；（二）**组合会破坏安全**——多 agent 系统里，逐个组件被验证过并不能推出系统安全，这对「用 agent 跑统计流水线」的场景尤其重要（工具链越长越危险）；（三）「不可判定 ≠ 不可改善」，文中给出的放松 notions 才是可落地的方向，与 2611.26413 那种「在具体环节给出有限样本保证」的做法一致。

**链接.** https://arxiv.org/abs/2611.25325

## Rubric Semantics or Numerical Priors? Auditing Scale-Direction Bias in LLM Judges（2611.25588）

`cs.CL`｜Chanwoo Kim, Doyun Kim, Minsoo Song, Sihyeon Lee, Chanjun Park

**问题背景.** 基准评测越来越多地依赖 LLM 当评委；这一范式隐含假设：评委依据的是 rubric 的**语义含义**，而不是它的**数值刻度**。本文直接质疑这个假设。

**方法.** 提出**语义忠实性**（semantic faithfulness）原则：语义等价的 rubric 必须给出一致的分数。为量化它，提出**尺度反转探针**（scale-reversal probe）——**只反转评分锚点、不改变评测标准**；再引入 **floor normalization**，把「反转不一致」相对于模型自身的内在波动做校准，使跨模型比较公平。

**主要结果.** 在**五个元评测基准**、**七个不同 LLM 评委**（开源权重与商用模型兼有）上的实验显示：**语义忠实性被普遍违反**；而且**仅看反转一致率本身会产生误导**（必须先做内在波动归一）；最后，**双向锚点平均**可降低对单一锚点方向的依赖，且**不损害与人类判断的一致性**。

**与 Reliable Agent · 统计推断的关系.** 本期最贴「bias」二字的一篇：当 agent 被用作**裁判/评估器**时，它的分数里混进了**与语义无关的数值先验**（锚点方向、刻度宽度），这属于典型的**测量偏差（measurement bias）**而非模型能力差异。对 traveler 的课题有直接的方法论价值：（一）任何基于 LLM 评委分数的**统计结论**，其「处理变量」其实是「分数」，若分数本身随刻度平移，**下游推断全部平移**；（二）**尺度反转探针 + 内在波动归一**是一套现成的**评估器有效性检验**，可以直接拿来给 agent 的评估器做校准审计；（三）「反转一致率会误导」提醒：报告这类指标必须**同时给出模型自身的重复测量方差**，否则「一致」可能只是噪声小。

**链接.** https://arxiv.org/abs/2611.25588

## General Methodology for Asymptotically Balanced Multiple Tests（2611.25915）

`stat.ME`｜Merle Munko

控制族错误率（FWER）的经典做法是 Bonferroni 与 Holm 校正，但它们**不利用检验统计量之间的依赖结构**，因此在多数设定下**偏保守**。本文给出一个非常灵活的理论基础：把检验统计量的**联合依赖结构**纳入临界值构造（例如用 bootstrap 等重抽样方案逼近联合分布），从而构造**渐近平衡（asymptotically balanced）**的多重检验，并在一般情形下**强意义下控制 FWER**；同时证明**一致性重抽样方案**满足所需条件。

**与 Reliable Agent · 统计推断的关系.** agent 一次生成几十个假设、逐个做检验时，Bonferroni/Holm 的保守会让**真实发现被淹没**——这在「agent 自作主张筛结论」时是实打实的代价。这篇提供了**依赖感知的替代路线**（重抽样逼近联合分布 → 渐近平衡检验），但要提醒的是：它给的是**渐近**控制，而 agent 常见的样本量很小，因此实务上仍需配合有限样本方法（如本期 2611.25376 的保守 PC、2611.26328 的在线 e-BH）。

**链接.** https://arxiv.org/abs/2611.25915

## DSFlow: A Neuro-Symbolic Data Workflow Agent with Statistical Diagnostic Guardrails（2611.25111）

`cs.AI`｜Junfeng Nie, Xiaohui Chen

数据科学工作流要求调用者掌握不少专门工具知识，LLM 降低了门槛，但在**灵活的通用 agent** 与**受统计控制的流水线**之间仍存在缺口。本文提出 **DSFlow**：一个基于 LangGraph 的**神经—符号**数据 agent 平台，把**可复用、由 LLM 选择的技能**（skills）与**确定性的诊断护栏**（diagnostic guardrails）结合起来。符号校验层可以**接受**所提议的方法、**要求澄清或重新规划**、**覆盖**不合适的方法，或**给出安全兜底**。回归与聚类两个案例展示了 DSFlow 如何用**诊断证据纠正方法选择**，并把这些决策记录在**可审计的报告**里。

**与 Reliable Agent · 统计推断的关系.** 提供了「**统计护栏 + 审计报告**」的现成工程范式：让 LLM 自由选方法，但由**确定性符号层**对方法选择与诊断输出做**接受 / 质疑 / 覆盖 / 兜底**四态处置，并把决定写进可审计记录。对 traveler 的 bias 课题，最有价值的是「**可审计报告**」这一条——bias 之所以难查，很大程度是因为 agent 的分析决策**没有留下痕迹**；把「用了哪个方法、为什么被改写」记录下来，bias 才可被事后审计。

**链接.** https://arxiv.org/abs/2611.25111

## Same Judgement, Different Scores: Numerical Scoring Topology in LLM-as-a-Judge Evaluation（2611.26077）

`cs.CL`｜Doyun Kim, Chanwoo Kim, Jiwoo Kum, Minsoo Song, Chanjun Park

本文引入**数值评分拓扑**（numerical scoring topology）概念，用**刻度宽度、粒度、偏移、对称性、边界位置**刻画评分方案的结构设计，并**首次系统研究**它如何影响**零样本 LLM-as-a-Judge** 评测。结果：**评分拓扑系统性地影响评委的分数、校准与稳健性**，在判断密集型（judgment-intensive）评测中尤为明显；**平移（shifted）与窄区间**的量表往往造成最大的分数偏移；更强、更大的评委模型通常**判别效度更高**、对拓扑变化**更稳健**。结论是：评分拓扑应被视为 LLM 评委评测的**内在组成部分**，需要更原则化、标准化的评分协议。

**与 Reliable Agent · 统计推断的关系.** 与 2611.25588 是同一问题的两面：上一篇测「**锚点方向**」带来的偏差，本篇测「**刻度结构**」带来的偏差。合起来给出一条可执行的建议：**agent 评测的分数刻度本身是实验设计的一部分**，换一套刻度可能显著改变排名与结论，因此跨论文比较 LLM 评委分数时，**必须同时报告刻度定义**，且「换刻度重跑一遍」应作为稳健性检验的标配。

**链接.** https://arxiv.org/abs/2611.26077

## LLMs Are Already Confidence-Aware Zero-Shot Classifiers（2611.25289）

`cs.CL`、`cs.AI`、`cs.LG`｜Owen Cook, Xingyi Song

零样本 LLM 被广泛用作文本分类器，但只有知道**能信到什么程度**，标签才有用。本文对比**黑盒置信度方法**（口头化置信度、采样）与**白盒方法**（读 token 概率的 P(True)，以及用受约束生成做多种 logit 打分），在 **11 个开源权重模型（1B–32B）**、**5 个分类数据集（3–151 个标签）**上，度量准确率 / F1-macro / 判别力（AUROC）/ 校准（ECE、Brier）。主要结果：**置信度方法的选择几乎不影响准确率**，但 **logit 类方法的判别力显著更好（AUROC 0.74–0.77）**，远高于黑盒方法（**0.57–0.66**）；把标签换成**单 token 标识**可保住判别力，但平均**损失 3–6 个准确率点**；新提出的 **decision-only scoring** 只在前缀树（trie）中标签分叉的位置打分，在三个最大标签集上把解码步数减少 **88–96%** 且效果相当；最佳开源配置（Gemma 4 31B、Qwen 3.5 9B）可与商用分类器竞争。

**与 Reliable Agent · 统计推断的关系.** 提供了一个「**校准从哪来**」的工程答案：**别让模型口头报告置信度，去读 logit**。这与 traveler 关心的「agent 报告的统计量是否可信」直接相关——若 agent 用自然语言自报「我有 90% 把握」，那是一个 AUROC 仅 0.57–0.66 的弱信号；换成读 token 概率，判别力升到 0.74–0.77。另需注意论文自己的提醒：把标签换成单 token 会**掉 3–6 个准确率点**，说明**校准与准确率之间存在真实权衡**，不能只谈校准。

**链接.** https://arxiv.org/abs/2611.25289
