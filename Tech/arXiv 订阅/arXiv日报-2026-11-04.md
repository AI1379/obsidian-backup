### 1. Stress-Testing the Robustness of LLM-Based Causal Inference（2611.03656）｜cs.LG｜Ankitkumar Patel, Jigarkumar Patel, Amit Kumar, Supreetha Sreeram, Venkatesh Kulkarni

**问题背景**
LLM 被用作因果发现（causal discovery）的新范式，但往往只做表层模式匹配而非真正的因果逻辑。需要一张精确的"地图"：模型在**什么维度上、多大程度上**失败。

**方法**
提出系统化 stress-test 框架，跨六个维度施压：**模型规模、因果图复杂度、提示策略、元数据质量、数据质量、对不确定性的敏感度**，并对每个模型给出推理不确定度。

**主要结果**
- 存在显著的 **"optimism bias"（乐观偏差）**：模型系统性地高估因果联系，全线 precision 偏低。
- **传统评测指标具有欺骗性**：reasoning-heavy 的模型分数领先，但最高分往往出现在**忽略推断不确定性**时；把不确定性计入评测后性能明显下降，才是对因果可靠性的诚实反映。
- 规模扩大确实改善结果，但**增益脆弱**：元数据质量下降时性能急剧退化。

**与 Reliable Agent · 统计推断的关系**
这是今天与"Agent 做统计推断的 bias"最直接对应的一篇：**乐观偏差**就是 LLM 因果估计器的方向性 bias，而"评测指标掩盖真实可靠性"则是 bias 研究里最危险的陷阱——它用聚合准确率把系统性高估洗成了成功。对我们的启发有两点：(1) 对 agent 做因果/统计任务时，**必须把不确定性显式计入指标**，否则我们测的是模型的自信而非正确；(2) 元数据质量是**外生且可控的**扰动轴，可直接作为我们实验里"agent 上下文退化 → 估计量 bias 放大"的设计维度。

**链接** https://arxiv.org/abs/2611.03656

### 2. Conformal Prediction at Performative Equilibrium: The Price of Performativity（2611.05277）｜math.ST cs.LG stat.TH｜Ahmed Mahrous, Roberto Di Pietro

**问题背景**
Conformal prediction 的有限样本覆盖依赖校准集与测试点的**可交换性**；但当部署本身会改变数据分布（performative setting，例如推荐系统的反馈回路、或 agent 的行为反过来塑造数据）时，可交换性失效，标准保证不再成立。

**方法**
研究"在 performative 平衡点处的预测集"：覆盖必须在分布 $D(f^\star)$ 下成立，其中 $f^\star$ 是 performatively stable 的预测器。在分布映射的总变差 **L-敏感度**假设下，证明存在**相变**；核心工具是一条 transfer theorem——任何返回与平衡点相差 ε 以内的预测器的过程，在 split-conformal 校准后给出**带加性 $L\varepsilon$ 项**的平衡点有效覆盖。

**主要结果**
- **相变阈值 $L=1$**：若 $L \ge 1$，任何有限样本过程都无法同时保证平衡点有效覆盖与非平凡预测集。
- 若 $L < 1$，对信息类过程（informative procedures）的**最坏超额漏覆盖**为 $\widetilde{\Omega}(1/((1-L)\sqrt{n}))$，即固定超额漏覆盖下样本复杂度按 $1/(1-L)^2$ 量级膨胀。
- 给出两个重训练算法实例化（可离散化类的 model-free 方法 + 参数尾平均方法），后者在 $n$ 与 $L$ 的依赖关系上匹配该率（差对数因子）；半合成信用评分实验复现了阈值行为与标度律。

**与 Reliable Agent · 统计推断的关系**
这是"**agent 改变了它所测量的分布**"这一类 bias 的理论骨架。我们的 agent 一旦上线，其输出就会改变后续数据（推荐、决策、实验设计都如此），此时用旧分布校准的 conformal 区间会**系统性地**偏掉。$L=1$ 的相变给出了一个可操作的判据：**当 agent 对分布的反馈强度逼近 1，任何有限样本覆盖保证都不可能同时保持区间可用**——这正好对应"agent 越激进、保证越退化"的直觉，而且是可以写进论文的定理。transfer theorem 里的 $L\varepsilon$ 加性项也提示我们：把预测器往平衡点拉近，漏覆盖是**线性**受罚的，这为"agent 迭代到平衡点所需的轮数"提供了保证。

**链接** https://arxiv.org/abs/2611.05277

### 3. StreamLTT: Risk Certification for Policy Selection under Stream Dependence（2611.04062）｜cs.LG math.ST stat.ML stat.TH｜Jinwen Xu, Qin Lu

**问题背景**
Learn-then-Test (LTT) 框架给"策略能否以指定风险上线"提供有限样本证书，但其标准形式针对的是**固定总体风险**（由校准损失估计）。顺序部署时损失可能**相依且非平稳**，固定策略的风险会随观测历史漂移。

**方法**
提出 StreamLTT，把"固定总体风险"替换为**平均可预测风险**（average predictable risk）：每次决策的损失都条件于其结果揭示前可得的信息。对该目标做**条件中心化**，使经验偏差化为**鞅和（martingale sum）**，从而同时得到 (i) 适应可预测方差的检验，与 (ii) 有限样本的 Hoeffding 备择。再叠加**族错误率（FWER）控制**，输出可同时认证的策略区域。

**主要结果**
- 条件中心化 + FWER 控制 → **同时认证**的策略区域，可支持后续部署选择。
- 在 **7 个预测数据集 × 7 种部署风险** 上，认证前沿显著接近指定风险目标，优于 IID、稳健方差、block-bootstrap 与集中式不等式等基线；经验族错误率紧随指定水平。
- 消融实验显示：**是"可预测风险"这一目标定义（而非方差自适应）驱动了更紧的风险前沿**；方差自适应则更有效地利用了族错误率预算。

**与 Reliable Agent · 统计推断的关系**
LTT/e-value 家族正是"Agent 做统计推断时的风险控制"最自然的落点，而这篇把它从 IID 推到**相依流**。对我们的课题有三点可用：(1) "平均可预测风险"给出了一个**在 agent 顺序决策下应该认证什么**的答案——不是总体风险，而是条件于决策时信息的前瞻风险；(2) 鞅化 + FWER 的组合说明，**多重比较预算可以显式地在多步 agent 流程中分配**（这与 e-value 的 anytime-valid 思路互补）；(3) 消融结论提醒我们：做 agent 风险认证时，**先定义对目标，再谈检验方法**，否则容易用错误的分母谈错误的保证。

**链接** https://arxiv.org/abs/2611.04062

### 4. Aggregate Calibration Can Mask Stress-State Undercoverage: Bounded-Memory Forecast Intervals under Recurrent Financial Stress（2611.04223）｜stat.ME q-fin.ST｜Ruihang Han, Li-Hsiang Lin

**问题背景**
序贯预测区间常以**聚合覆盖率**验收，但在校准记忆有限时这会误导人：经济上重要的状态可能在长期缺席后再次出现，"只看最近"缓冲可能总体达标，却已经不再覆盖该状态早期的误差。

**方法**
固定预测模型、符合性分数、自适应更新与记忆预算，只改变每次查询时可用的历史残差信息，对比 Recent-only FIFO 校准、无界状态历史参照与 Rare replay，在 ETF 研发面板与固定股票面板两个样本上评估次日金融区间预测。

**主要结果**
- Recent-only FIFO 校准在**聚合上接近名义水平**，却在**高波动状态显著欠覆盖**（两个面板一致）。
- 无界状态历史参照给出更低的压力期区间分数；Rare replay 在两个面板上的 high-VIX 区间分数都低于匹配的 Recent-n 与 Hybrid-n 对照。
- 状态结构化 vs. 仅最近历史的对比，在**压力状态再进入**时最大。
- 结论：**有界校准记忆本身是预测信息设计的一部分**，仅看聚合校准会掩盖状态特异性的可靠性失效。

**与 Reliable Agent · 统计推断的关系**
这是今天最像"我们自己的痛点"的一篇：**总体覆盖率达标 ≠ 条件覆盖率达标**，而 agent 在真实分布里遇到的恰恰是少数关键状态。我们的 bias 研究若只报总体 coverage / accuracy，就会复现同一个错误——聚合指标掩盖了 agent 在困难子群体上的系统性偏差。对我们的直接启示：(1) 评估 agent 的统计可靠性应**按状态/分层报告**，并显式检验"聚合达标是否掩盖条件欠覆盖"；(2) 有界记忆（滑动窗口、最近 k 条上下文）会**主动制造**这种失真，这对上下文截断型 agent 是现实约束，值得在实验设计中显式建模。

**链接** https://arxiv.org/abs/2611.04223

### 5. Silent Instrument Errors Reorder Agent Leaderboards（2611.04399）｜cs.AI cs.SE｜Yangze Liu

**问题背景**
一个公开 agent 榜单上，通用 agent 在涉及数据库的任务上落后于针对航空客服基准专门搭的脚手架 13 分，读者可能据此得出"通用性有代价"的结论。作者指出：**差距来自评测仪器本身**。

**方法**
仅从公开发布的产物出发，审计两个维护良好的公开榜单（HAL 与 tau2-bench），逐项检查评分基础设施（打分、日志、回放、版本管理）的行为。

**主要结果**
- 通用 agent 常以**无法触发打分**的方式结束对话，只有约**一半**的 episode 被计分，其余被存为失败；按基准自身规则给未计分的一半重新计分，**不重跑任何 agent** 就抹平了汇总差距。
- 审计另发现**三处仪器错误**：成本列把嵌套模型调用重复计数且各行不均；存档轨迹把**打分器写下的动作记成了 agent 的动作**；用更新的评估器重打分已存轨迹本身就是一次**新的测量**——一个"正确且已公告"的修复重排了榜单，而一个读错四个文件的模式检查让分数塌了 **59–82 分**却**不打印任何错误**。
- 每一个错误都**产出了一个看似合理的数字**；HAL 维护者在五周内确认了他们那三处。
- 提出的廉价检查：报告**已计分比例**、从根 span 聚合成本、给每个记录动作打**来源标签**、用**已发布的重打分 diff** 固定评估器版本。

**与 Reliable Agent · 统计推断的关系**
这篇是"评测基础设施属于测量本身"的强证据，对我们是一个**方法论警示**：agent 的统计结论若依赖一个会静默出错的仪器，bias 可能完全来自仪器而非 agent。尤其"约一半 episode 未被计分、其余记为失败"——如果我们的实验 pipeline 也存在这种静默丢弃，**被丢弃样本与保留样本的系统性差异会直接伪装成 agent 的 bias**。建议把它的四条廉价检查直接抄进我们的评测 harness：报告计分比例、聚合成本口径、动作来源标注、评估器版本钉死 + 重打分 diff。

**链接** https://arxiv.org/abs/2611.04399

### 6. Swapping the Judge Changes the Ranking: A Preregistered Study of Cross-Provider Replication in LLM-Judged System Comparisons（2611.04090）｜cs.CL cs.AI cs.CY｜Sangdo Han, Moonsoo Kim

**问题背景**
用 LLM judge 比较系统、又没有人工标注时，实践者常用"换一个厂商的 judge 再跑一遍"来验证结论。这个检查有多可靠？

**方法**
**预注册**研究（含披露的注册后 judge 集合缩减）：来自 3 家厂商的 **5 个 judge 模型**，对带人工投票的 **4,000 场 Chatbot Arena 对战**（9 个系统、33 个系统对）重新评判，且每场都跑**两种回应顺序**。

**主要结果**
- 判定层面与人工投票的一致性很低：**Cohen's kappa 中位数 0.22**。
- **系统排名不因换 judge 而存活**：与人工排名的 Kendall's tau 在 **0.17–0.89**（中位 0.67），**预注册假设（排名稳定）未被支持**。
- 两个跨厂商低成本 judge 的"复现式"结论比单 judge 结论更常与人工一致（**precision +0.10**），但增益来自**滤掉了一个对齐差的 judge**；而让该 judge 参与的复现对只有 **35%** 的比较能得出结论。
- 与人工对齐的 judge，用**不超过人工投票量**的判定数即可收敛到稳定结论；其余 judge 在所测样本量（每对至多 100 次判定）下有 **26–70%** 的系统对无法收敛。
- judge 与人工的分歧**跨 judge 共现**的频率远高于独立性假设所预测（但单次人工投票无法区分共同 judge 偏差与投票者噪声）。

**与 Reliable Agent · 统计推断的关系**
这是 LLM-as-a-judge 可靠性的**预注册量化**，直接命中我们关心的"评测器引入的 bias"。三条可直接落地的结论：(1) 用另一个 judge 复现**不能**当作稳健性检验——它换了仪器却没换真值；(2) judge 与人工的分歧**正相关**（共现远超独立），意味着"多 judge 投票降噪"在有偏 judge 下会**放大**而非抵消偏差，这一点与我们此前那篇 agent 分歧去相关的工作互补；(3) 判定级 kappa 中位 0.22 说明**以 judge 分数作因变量做统计分析时，测量误差必须显式建模**，否则会被误读成 agent 的能力差异。

**链接** https://arxiv.org/abs/2611.04090

### 7. Where Is the Truth When AI Agents Disagree? Dependence-Aware Belief Propagation for Unsupervised Truth Discovery（2611.04805）｜cs.AI cs.CL cs.DB stat.ML｜Laure Berti-Equille

**问题背景**
多个 LLM agent 对同一问题给出冲突答案，而现实中很多 agent 只是**同一基座模型的变体**，其错误高度相关。经典 truth-discovery / crowdsourcing 估计量奖励"意见一致的集团"，其效果可能**低于多数投票**。

**方法**
提出 BP-TD：在 one-coin Dawid-Skene 模型的**均值场变分推断**上加入**逐 agent 去相关权重**，使共享同一基座模型的 agent 合起来约等于**一票**。第一轮迭代恰为加权投票，后续迭代估计 agent 可靠性。

**主要结果**
- MMLU 上 13 个本地 agent、无任何标签：**0.716 vs 0.624**（160 题），**0.707 vs 0.674**（10,000 题），均优于多数投票。
- 能按**真实准确率**给 agent 排名，而经典估计量给的是**反转**的排名。
- 增益**依赖 agent 池的构成**：在 4 个基准的 **2,852 个子池**上，当最大的相关集团**较弱**时去相关有帮助，当它**最强**时反而有害；且**未找到任何无标签统计量**能区分这两种情形。
- 一旦有标签（20 题），**选出单个最好的 agent** 比我们测过的所有聚合器都更准（MMLU、ARC、TruthfulQA）。

**与 Reliable Agent · 统计推断的关系**
这篇给了一个精准的机制：**agent 之间的错误相关性会让"多 agent 聚合"产生系统性偏差**，而普通投票/多数假设正是把它当成独立样本——这正是我们说的 statistical bias 的一个具体来源。对我们的用处有三条：(1) 做多 agent 统计推断（尤其是"用 agent 群估计一个量"）时，**必须建模 agent 间的依赖**，否则标准误会低估方差；(2) 论文给出的失败模式（相关集团最强时去相关有害、且**无法无标签检测**）本身就是一条值得写进我们工作的负面结果——它说明"agent 去偏"这件事在无标签下不可识别；(3) "20 个标签就够选出单点最优 agent"的结论提示：在有真值的任务上，**与其聚合不如选一个**，这对我们的基线设计是个挑战性提醒。

**链接** https://arxiv.org/abs/2611.04805

### 8. Graph-Localized Coverage for Conformal Prediction on Inductive Graphs（2611.04066）｜cs.LG stat.ML｜Jinwen Xu, Qin Lu, Georgios B. Giannakis

**问题背景**
Conformal prediction 给的是**边际覆盖**保证，但边际覆盖不告诉你误差**落在图的哪里**——不同邻域的查询可以有显著不同的不确定度，即便总体覆盖接近目标。

**方法**
提出 GLocalCP：面向归纳式节点分类与边预测的**在线** CP 框架，把**边际校准**与**图局部校准**结合，并使用不确定性自适应的预测集。非符合性分数依赖 **MC dropout 预测的互信息**；再用**核方法的局部修正**在相似查询之间传播覆盖反馈。

**主要结果**
- 理论：在**不需要可交换性、也不需要平稳性**的条件下给出路径式 $O(N^{-1/2})$ 边际校准误差；对精确核形式给出显式的 $O(N^{-1/2})$ **图局部化覆盖保证**。
- 实验：**7 个节点分类 + 7 个边预测基准**上，相似的边际覆盖掩盖了**显著不同**的局部可靠性；GLocalCP 在保持覆盖接近目标的同时**持续降低图局部校准误差**。
- 不确定性缩放进一步在**不改变边际覆盖**的前提下缩小所有数据集上的预测集。

**与 Reliable Agent · 统计推断的关系**
提供了一条把"覆盖保证"从**全局标量**推到**局部/条件**的技术路线，与前面那篇"聚合校准掩盖压力态欠覆盖"是同一问题的两面。我们的 bias 研究若要给出"agent 在子群体上的偏差"的保证，可以借它的两层校准 + 反馈传播结构：边际层保证总体不失控，局部层定位"这个邻域/这类 query 上 agent 偏了多少"。MC-dropout 互信息作非符合性分数这一点还顺带给出一个 agent 自评不确定度的工程接口，可以用于**主动弃权（selective）**策略。

**链接** https://arxiv.org/abs/2611.04066

### 9. Predictive gains, causal losses: why interventional competence cannot be learned from data alone（2611.03861）｜cs.AI cs.LG｜Marcus Thomas

**问题背景**
一个反直觉命题：保留预测优势，可能要求模型在干预响应上**持续犯错**。

**方法**
在确定性预测器、平方误差损失、有限二阶矩下做理论刻画：任何仅用结果直接原因的最优预测器之外的观测优势，都要求模型**依赖其他输入**（与学习规则无关）。当可容许干预改变输入而保持世界结果不变时，这种依赖给出干预响应 RMSE 的**正下界**；并刻画总体梯度更新何时会从"仅父节点"基线引入这种依赖，或在改进其他预测的同时破坏原本正确的机制。

**主要结果**
- 干预响应误差存在**正下界**，且与如何学习无关。
- 干预对齐需要跨内部状态与不同物理过程的**共同输出映射**；同一次干预的不同实现方式会让模型行为漂移。
- 误差下限由**当前被承认的因果假设类**决定（而非模型原则上能表示的函数类）：对受限于这些替代假设的预测，干预均值误差**不可能**低于它们允许的最优逼近，无论证据是观测的还是干预的。
- 干预式批评能约束替换方案但不能决定替换方案；作者猜想，可靠获得并维持干预能力需要 agent **自主提出替代假设、检验后果并据错误修正**。

**与 Reliable Agent · 统计推断的关系**
这是把"**预测好 ≠ 因果对**"变成了可证的**下界**：任何只在观测数据上训练的 agent，其干预性统计推断误差存在不可消除的正下界，而且**换学习算法也躲不掉**。对我们的课题，这既解释了 bias 的**不可约成分**（可以据此给我们的方法设定合理天花板），也指出了唯一的出路：**扩大被承认的因果假设类**——也就是让 agent 主动提出并检验替代假设，而不是在固定假设类里优化。这恰好是"Reliable Agent"应有的内省机制，与我们设计"agent 提出统计假设并被审计"的方向高度一致。

**链接** https://arxiv.org/abs/2611.03861

### 10. Auditing Multi-Proxy Explanations of Web User Preferences: Identification Boundaries and Abstention（2611.04997）｜cs.LG cs.IR｜Yu Zhang, Zhihan Wang, Yuhang Lu, Shuai Li

**问题背景**
Web 系统从行为、评分、文本和 LLM 生成的画像推断用户偏好，但**解释一个代理变量，可能只揭示了它的测量过程，而不是目标偏好**。

**方法**
建立审计框架，区分相对于显式参照分布的**点识别 / 部分识别 / 弃权**三种结论强度。在"特征相关、符号任意"的代理偏差下，证明**严格多数未污染代理归因**足以让坐标中位数恢复潜在归因的支撑与方向（在外部正定标尺下还包括量级）；用"响应等价不可区分世界"论证该阈值**锐利**，刻画近似清洁度与标度不确定下的锐利 minimax 误差与精确相容目标集。

**主要结果**
- 干净代理归因审计在正确预算下达到 **100% 覆盖**、**95.40%–97.05%** 的主动驱动符号判定、**零假符号**；基准覆盖两种响应族、四种代理数、全部污染数、三档偏差强度与 11 种方法，焦点比较在 20 个未见种子上确认。
- 时序分离的 Amazon 研究中，中位数聚合对四个目标都降低了相对比较器的条件符号误差；8 个预设目标-指标对比中 **6 个的 Bonferroni 区间排除零**。
- **相容集**显示：当前代理配置**很少**允许"严格符号"结论。
- 弱比较器校准把 Amazon 证据限制在"拟合面吻合"而非"潜在偏好恢复"。

**与 Reliable Agent · 统计推断的关系**
这篇提供了我们最缺的一块方法论：**在多代理（multi-proxy）证据下做审计时，什么结论是被识别的、什么是只被部分识别的、以及什么时候必须弃权**。对我们的 bias 研究，它给了一个可操作的判据体系——不要问"agent 的结论准不准"，而要问"在当前证据结构下，**这个强度的结论是否被识别**"。同时它诚实指出：多数代理只支持**部分识别**，这意味着 agent 报告的偏差在很多场景下**无法被完全消除**，只能被界定在相容集内；这篇的 Bonferroni 区间与审计预算也提供了现成的多重检验纪律。

**链接** https://arxiv.org/abs/2611.04997

### 11. How Risky Is Your Data-Driven Policy?（2611.04292）｜stat.ML cs.LG math.OC｜Omar Besbes, Alon Rieger

**问题背景**
数据驱动算法的**平均**性能已被充分分析，但它们的**风险画像**（尾部风险）理解甚少。本文量化数据驱动策略的风险并**分离其来源**。

**方法**
在固定未知分布下，用损失在训练样本、策略随机化与未来结果上的**条件风险价值（CVaR）**评估策略。与知晓分布的 oracle 相比的遗憾分解为**期望样本后遗憾（PS）**与**样本风险溢价（SR）**——即"平均化评估所额外遗漏的尾部风险"。

**主要结果**
- SR 在**期望损失**下消失；文中刻画了它何时消失、相对 PS 有多大。
- 对尾部截断附近有连续密度的损失，两分量可以**同速衰减**，但 SR/PS 的极限比可达**数千**；当截断处的概率质量随动作移动时，SR 可衰减更慢并**主导** PS。
- 样本平均近似（SAA）在两种情形下都以 $n^{-1/2}$ 学到 oracle 动作，但其**组合风险遗憾**在第一种情形为 $n^{-1}$、第二种为 $n^{-1/2}$。
- 有限样本数值例（SAA）中，SR 解释约 **74%–97%** 的遗憾。

**与 Reliable Agent · 统计推断的关系**
这篇给"agent 做统计推断"提供了一套**风险分解语言**：我们的估计量误差 = 采样后遗憾（学得有多好）＋ **样本风险溢价**（平均化指标掩盖了多大的尾部风险）。对我们的 bias 研究，第 74%–97% 这个数字极有冲击力——**绝大部分"风险"并不是估计量本身不准，而是平均化度量丢掉了尾部**。而且"截断处概率质量随动作移动时溢价主导"这一情形，正是 agent 在**分布外/极端输入**上出错的场景，对应到 agent 语境就是：平均 benchmark 分数几乎不含这类尾部风险信息。

**链接** https://arxiv.org/abs/2611.04292

### 12. Treating the Symptom, Missing the Cause: Anatomy of a Scientific Reasoning Failure（2611.04473）｜cs.AI｜Anna Gogleva, Thomas Charman, Martin Balla, Karl Gemayel

**问题背景**
科学 agent 常能**找到有效的干预**却说不清**为什么有效**。本文在受控合成调控系统中研究这一失效模式：agent 需实验性地识别隐藏故障并救回表型。

**方法**
七个 LLM 在受控合成系统上执行"找故障 + 救表型"任务，并用定向探针定位实验推理在哪一步断掉。

**主要结果**
- 每个模型**救回健康表型的频率都高于正确诊断故障的频率**；Claude Opus 4.6 与 Sonnet 4.6 救回**全部**个体，却只诊断出 **55%** 与 **35%**。
- 失败**并非**探索不足或证据缺失：多数情况下原因是可实验识别的，agent 在 **91%** 的相关会话中遇到能区分竞争原因的证据，却仍频繁误诊。
- 探针显示：模型能可靠解读决定性证据、在因果比较显式时修正假设、也能在完整实验记录中定位该证据；但**难以预测"在每个竞争原因下实验会得到什么结果"**——而这正是用观察到的结果区分它们所必需的一步。

**与 Reliable Agent · 统计推断的关系**
这篇把"agent 的 causal reasoning 失效"定位到一个**具体、可测的环节**：不是找不到证据，而是**不能对竞争假设做结果预测（counterfactual outcome prediction）**。对我们的课题有两层意义：(1) 它给出一个可操作的诊断指标——不要只看 agent 的结论对不对，要看它**能否预测各假设下的结果分布**；(2) 91% 的证据可得率 vs 更低的诊断正确率，量化了"**证据充分但推断错误**"这一类 bias 的规模，这正是我们要用统计保证去约束的部分——如果 agent 连假设后果都预测不准，任何覆盖保证都救不了它，所以保证必须与**预测校准**联合考虑。

**链接** https://arxiv.org/abs/2611.04473
