## 精选论文

## Smoothed Conformal Testing with Small Calibration Sets（2611.27315）｜stat.ME math.ST stat.TH｜Mingzhou Deng, Yan Fu　★最贴题

- **问题背景**：split conformal 的 p 值由**校准样本的秩**决定，校准集一小，p 值就落在一个很粗的**秩网格**上，分辨率与功效都被压死。很多做法用**随机化**来打散这个网格，但随机化是否还保留**边际有效性**、能否保住 **FDR 控制**，此前没有系统结论；此外「平滑（smoothing）」在原子分布（离散分布）下是否安全也没人回答。
- **方法**：区分**独立 tie-block 随机化**与**按分数顺序分配排序随机数**两种随机化。前者在零假设可交换性下**精确有效**；在「校准分数与零分数在备择分数条件下联合可交换」时，证明存在**正回归依赖**，从而推出 **Benjamini–Hochberg FDR 控制**（并覆盖原子分布情形）。进一步刻画 smoothing 与 tie-block 随机化的一致条件，以及**按分数顺序分配随机数会使单个零假设 p 值失效**。
- **主要结果**：给出一个**两检验反例**，直接违反通常的 $\pi_0\alpha$ 上界；连续分数下的模拟显示 **FDR 高于名义水平 $\alpha$**。条件矩恒等式与正态模型插图说明：**去掉秩网格并不去掉校准不确定性**。随机化确实能带来额外发现（有时普通 conformal 根本无法拒绝），但**不能普遍替代更大的校准样本**。
- **与 Reliable Agent · 统计推断的关系**：这是今天唯一一篇 conformal 论文，也是「校准集不够大 → 保证会悄悄失效」的最完整清单。对课题的价值在于：agent 的验证样本量天然有限（小测试集、大模型），**当 agent 用少量样本做检验时，秩网格离散化会系统性地压低功效并可能破坏 FDR 控制**；而「平滑」在离散分数（pass/fail、0/1 标签、分类器打分）下**可能直接破坏边际有效性**——这对大量 agent 评测场景是直接可用的警告。
- **链接**：https://arxiv.org/abs/2611.27315

## Reliable Behavior Discovery via False Discovery Rate Control（2611.27104）｜cs.LG stat.ML｜David Madras, Zi Wang, Marco Andreetto, Ken Burke, Caroline Pantofaru, Utsav Prabhu　★最贴题

- **问题背景**：在大模型上**发现行为模式**（哪些 prompt 会触发某种行为）本质上是**多重假设检验**问题：试探的假设数事先未知、且由数据本身决定。若不控制 **FDR**，任何「发现了新行为」的报告都可能大部分是假阳性——这对「可靠 agent」是致命的，因为 agent 的行为清单往往直接被当作事实使用。
- **方法**：把行为发现形式化为一个明确的问题类，提出 **DISCO（Discovery through Iterative Search with Coarsened e-processes）**：基于 **e-process（e 值）** 的迭代搜索，同时用**逐步粗化（coarsening）**处理数据依赖的假设数量。相比既有的 **eBH** 类方法，允许**假设数本身是数据依赖且自适应的**。
- **主要结果**：在温和条件下**可证地控制 FDR**，并且相比 eBH 类方法**功效更高**（在合成数据与新设计的实证评估上都成立）。实证设置中，**生成式模型同时扮演发现引擎与被检目标**（即用 LLM 去发现 LLM 的行为），这一点比单纯的合成实验更贴近真实 agent 评测场景。
- **与 Reliable Agent · 统计推断的关系**：这是今天与「e-value / 多重检验」方向**唯一真正命中的论文**（关键词 e-value/anytime-valid 命中 0 篇，但 e-process 这条线在这里）。方法论可直接搬到 agent 上：**当 agent 自己提出并检验大量候选行为/候选统计结论时，用 e-process 而不是普通 p 值做发现，才能给出可解释的假发现率**；「coarsened e-process + 自适应假设数」还解决了实际评测中「我也不知道该试多少个 prompt」这一根本痛点。
- **链接**：https://arxiv.org/abs/2611.27104

## Can pretrained Transformers deliver semiparametrically efficient inference?（2611.27666）｜stat.ML cs.LG math.ST stat.TH｜Han Yan, Jin Zhu, Chengchun Shi, Tengyao Wang　★最贴题

- **问题背景**：半参数模型的**有效估计**通常依赖两件麻烦事：为每个 estimand **推导影响函数**，以及**对每个样本重复估计 nuisance**。这与「一个预训练模型走一遍就出答案」的期望背道而驰。这篇问的是：预训练 Transformer 能不能直接承担半参数推断？
- **方法**：用**模拟数据预训练**、且**标签只有真参数**的方式训练 Transformer，使其学到所查询 estimand 的**后验均值与协方差**，从而一次前向输出**点估计 + Wald 型置信域**。理论上证明：在**局部平坦、复杂度缓慢增长**的预训练先验下，**后验均值对每个被查询的 estimand 都是有效的**；Transformer 继承这一效率，并具有**渐近精确覆盖**，且在**分布漂移**下依然成立（概率同时对评估总体与查询取）。
- **主要结果**：在**因果推断、部分线性回归、生存分析**上，预训练模型通常取得**最低估计误差**，覆盖接近名义水平，计算成本**每个数据集约 0.02 秒**。同时诚实指出：当数据生成分布**固定**（经典频率学派设定）时，保证对预训练的要求**高得多**。
- **与 Reliable Agent · 统计推断的关系**：把「agent / 大模型 + 统计推断」的组合做到了**效率与覆盖**的层面，是目前该路线最完整的一篇。对课题「agent 做统计推断时的 bias」的意义在于：它给出了**偏差应当被控制在哪个量级**（半参数有效 = 渐近无偏 + 最低方差）的参照系；也提醒**分布漂移下保证会退化**——agent 在真实环境里面对的正是漂移分布。此外「一个模型走一遍就出带置信域的估计」若成立，将极大降低 agent 做推断的**测量成本**（可支撑大批量并行推断）。
- **链接**：https://arxiv.org/abs/2611.27666

## Efficient inference for fairness-constrained sequential decision policies（2611.27714）｜stat.ME stat.ML｜Yi-Hui Zhou　★最贴题

- **问题背景**：教育、医疗等场景里的**序贯决策系统**要按群体给干预，同时被要求「不能让受保护群体掉队太远」。这类**公平约束下的最优值**（fairness-constrained optimal value）涉及群体反事实泛函，**推断极难**：可行集依赖数据、约束可能在样本上不成立。
- **方法**：对 **Karush–Kuhn–Tucker（KKT）系统**做敏感性分析，证明该最优值**逐路径可微**，其**影响函数等于群体价值影响函数的拉格朗日组合**；同一分析给出最优策略、乘子与各群体价值的影响函数。提出**交叉拟合双稳健（cross-fitted doubly robust）估计量**，在数据依赖的可行集下仍然**有效**，并给出约束值与**公平代价（price of fairness）**的置信区间。
- **主要结果**：精确检查、模拟与合成案例研究验证了理论。当**约束绑定（binding）**时，任何 plug-in 的「公平策略」都会违反总体约束，**超出的幅度随样本量增大而消失、违反概率趋于 1/2**；用**单侧置信边际收紧估计约束**，可以以很小的价值代价**认证公平性**。
- **与 Reliable Agent · 统计推断的关系**：给出「**决策策略层**」的半参数推断骨架——影响函数 + 双稳健 + 置信区间 + 约束认证，这套组合可直接迁移到 agent 的策略评估上。特别值得注意的是**约束绑定时违反概率趋于 1/2** 这个结论：它说明**在有限样本下，「看起来公平的 agent 策略」有一半概率其实违反总体约束**，而绝大多数实践报告的只是经验公平指标——这正是「用点估计代替保证」的典型偏差。
- **链接**：https://arxiv.org/abs/2611.27714

## Your Judge Inherits Your Prompt: In-Context Label Bias in an LLM-as-Judge Is Directional, Not Symmetric（2611.26881）｜cs.CL cs.AI cs.CV cs.LG｜Abdullah Ahmad, Ahmed J. O. Ahmed, Luca Citi　★最贴题

- **问题背景**：LLM-as-a-judge 已是开放式评测的标准做法，但**裁判本身是一个被冻结的语言模型**，只被少量 in-context 示例「引导」；而这类模型已知会**吸收示例中的标签比例**，把它当成中性示意。因此需要问：这种**标签偏差**会不会传导到裁判的判决上？以什么形式传导？
- **方法**：构造**完全冻结的生成器—裁判流水线**，**固定生成答案**，只改变裁判 few-shot 示例的 **Yes/No 比例**（四种 demo 集合）。每次判决都与**双人标注者共识**（每数据集 200 例）比对。另做**五次抽样**分析，检验单次示例抽取的稳定性。
- **主要结果**：当示例**平衡**或**偏向拒绝**时，裁判接受率与人类共识接近；但当示例**偏向接受**时，接受率**急剧上升**（NExT-QA 约 **+30 个百分点**，MSVD-QA 约 **+20 个百分点**，且误差分布高度单侧），**反向偏斜不产生对应下降**。即偏差在测试范围内是**单向的、只膨胀不收缩**。五次抽样分析显示**单次抽样的结果不可靠，最大波动 18 个百分点**，比不同提示条件之间的差异还大。结论：**演示标签偏差是单向的、只造「虚假进步」的失效模式**；廉价规避方式是**平衡示例 + 多次抽样取平均**。
- **与 Reliable Agent · 统计推断的关系**：这是「裁判偏差」的教科书级刻画，且**方向性**这一发现极其重要：它意味着**用 LLM 裁判做 agent 评测时，指标只会单向虚高**，所以「我的 agent 比基线好」这一结论在没有平衡设计时**几乎不可能被证伪**。另外「单次抽样波动 18 个点 > 条件间差异」说明**评测的抽样方差必须被显式建模**，否则任何基于少量评测的 agent 改进结论都建立在噪声之上。
- **链接**：https://arxiv.org/abs/2611.26881

## The Vulnerability Window: Decision Instability in Quantized Reward Models（2611.27155）｜cs.LG cs.CL｜Omkar Shewale, Deepak Kumar, Divakar Kumar Yadav

- **问题背景**：奖励模型与 LLM 裁判常被量化到 **4 bit** 以压低批量评分成本，通常的检查是「benchmark 准确率几乎不动」——但这个检查**近乎失明**。
- **方法**：跨 **8 个奖励模型（两个家族，0.6B–8B）**、3 个生成式裁判、4 种 4-bit 量化器，度量**成对偏好判决的翻转率**，并用高斯近似 $\Phi(-|m|/\sigma)$ 描述翻转机制（$m$ 为全精度 margin，$\sigma$ 为量化噪声尺度），再检验「vulnerability window」（margin 小于噪声尺度的那段区间）的占用率。
- **主要结果**：量化在 RewardBench 上**改写 1.1%–12.3% 的成对偏好判决**，而**聚合准确率只动 0.03 个点（p = 1.00）**——因为它修好的错和引入的错互相抵消。翻转集中在 margin 相对量化噪声很小的样本上；vulnerability window 占用率**随模型规模从 25% 降到 7%**，这正是小裁判脆弱的原因。良性 best-of-16 下噪声被掩盖，对抗压力下则暴露（某家族 146:54 的 harmful:helpful 翻转，另一家族**符号反转**）。下游影响：**6 个（模型, 量化器）组合中 14.6%–65.7% 的问题改变了 best-of-64 的选择，但只有 2.6%–9.6% 改变最终答案**，选择改变频率是答案的 **5–8 倍**；benchmark 分数变化与下游变化相关 **ρ = 0.89**，而 benchmark 准确率**不能**可靠排序下游影响。基于 margin 的预测器 AUC **0.927**。
- **与 Reliable Agent · 统计推断的关系**：给出「**聚合指标掩盖个体判决翻转**」的定量证据，机理是**误差相消**——这与统计上「总体准确率掩盖 prompt 级评分错误」是同一类偏差。对课题的用处很直接：**如果 agent 的奖励/裁判模型被量化或压缩过，其评估读数存在系统性的、方向不明的判决翻转**，需要用 margin 层面的诊断而非聚合分数来审计。
- **链接**：https://arxiv.org/abs/2611.27155

## ProbeAgent: Principled Diagnosis of Agent Failures in Verifiable Environments（2611.26897）｜cs.CL cs.AI｜Yue Huang, Yuchen Ma, Shuhang Lin, Yuyang Wu, Zixuan Weng, Zixiang Xu, Xiangqi Wang, Yuexing Hao, Yujun Zhou, Yue Zhao, Olexandr Isayev, Stefan Feuerriegel, Xiangliang Zhang

- **问题背景**：改进 agent 的前提是「**知道它在哪里失败、为什么失败**」。但同一个失败结局可能来自**任务本身难**，也可能来自**agent 跨任务重复犯的同一个错**——只看最终回复无法区分这两种情形。
- **方法**：提出**自动化失效诊断框架 ProbeAgent**：从 benchmark 任务出发构建**可执行测试**，用参考答案、自动检查与任务要求审阅来验证测试；对每条失败轨迹**解释错误**，再**构造新任务**——保留疑似原因、改变周边上下文——检验**同一错误是否复现**；最后按原因相似度**聚类失效**，并生成能区分这些错误的描述。
- **主要结果**：在 **10 个 benchmark 的 22 种 agent 配置**上收集 **1,244 个失败**，产出 **536 条失效模式描述**；这些描述能把「工作未完成」这类宽泛结局细分为具体错误（如**只规划不行动**、**在交付文件前就停止**）。人工评估中，标注者**接受 90.0%** 的分配描述，并**正确拒绝 83.3%** 的相似替代描述。
- **与 Reliable Agent · 统计推断的关系**：把 agent 的失效从「定性抱怨」变成**可复现的、可区分的、带可执行测试的分类变量**。这对「agent 做统计推断时的 bias」非常关键：**只有把失效模式变成可编码的原因，才能作为协变量进入偏差分解**（哪些错误导致偏差方向一致、哪些互相抵消）。「保留原因、改变上下文」的构造思路也是识别偏差来源的思路。
- **链接**：https://arxiv.org/abs/2611.26897

## Do Senior Agents Do Their Job? Measuring Role Integrity in How LLM Agents Use Subordinate Material（2611.27139）｜cs.CL cs.AI｜Jinxiang Xie, Xinyi Zhang, Changjiang Jiang, Kexu Liu, Qi Yang, Yuxin Su

- **问题背景**：多 agent 系统把长任务分给子 agent，由**上级 agent**把报告汇总成最终答案。但只有当每个 agent——尤其是上级 agent——**尽到自己的职责**，分工才有价值。现有评测大多只看最终答案，**流畅且引用齐全的答案无法说明上级 agent 是「权衡」了子报告还是只是「聚合」**。
- **方法**：定义 **role integrity（角色完整性）**：agent 面对下属材料时，其**功能性职责是否被保全**。构造 **RI-Bench**，基于三种制度层级的结构与公开记录——**同行评审、上诉裁决、议会调查**——它们恰好覆盖三项基本职责：**权衡（weigh）、核实（verify）、转述（relay）**。不评答案对错，而是**测量上级 agent 的输出如何响应下属材料的受控变化**，用规则检查与**对照人工标注校准过的 rubric LLM 裁判**。
- **主要结果**：**8 个 LLM、超过 12,000 次 agent 轨迹**。上级 agent **很少采纳被植入的程序错误（2.9% 的裁决）**，但**经常跟随多数的泛泛评审（最多 71% 的决策）**，或**丢掉证人陈述的限制条件（最多 65% 的被引主张）**。加「义务提示」能降低这些失败但**无法消除**，而且**同时改变了对照条件下的行为**（提示本身引入新偏差）。
- **与 Reliable Agent · 统计推断的关系**：揭示了多 agent 流水线里的**信息损耗型偏差**：上游的「限定条件」在层层汇总中被系统性抹掉，最终答案看起来自信却少了关键约束。这与上一期「最弱 agent 决定系统安全」互补——那篇讲**能力**衰减，这篇讲**职责**退化。对 agent 统计推断而言，**丢掉限定条件 = 把有条件的估计当成点估计**，是最隐蔽的一类偏差。
- **链接**：https://arxiv.org/abs/2611.27139

## Combining Past Experimental Data for Efficient Estimation: A Shrinkage Approach（2611.27655）｜stat.ME stat.AP｜Qianxi Zhang, Dae Woong Ham, Stefanus Jasin

- **问题背景**：企业做随机实验会积累**历史实验档案**，理论上可以用于提升新实验的处理效应估计精度。但历史实验评估的是**相关但不同的干预**，其估计对当前目标**可能有偏**。核心问题：**何时、如何借用历史数据，能真正降低单个处理效应估计的 MSE？**
- **方法**：先在 **oracle 情形**（偏差与方差已知）下分析，再提出**三个收缩估计量**，并刻画其**渐近 MSE 随辅助实验数增长**的行为；分析指出**平均辅助偏差**与**跨研究偏差离散度**共同决定各估计量的相对表现。据此提出**固定权重估计量 + 假设检验门控**：只有当辅助实验的合并均值与目标均值**无显著差异**时才借用。
- **主要结果**：oracle 结论是**只要存在一个有偏的辅助实验，借用它就严格降低 MSE**（现实中需靠收缩控制）。出人意料的是**偏差离散度既可能帮也可能害**第一个估计量：更分散的偏差**允许更灵活的偏差抵消**，但抵消**并不精确**（只有偏差的估计），于是**过拟合**。两个 plug-in 估计量在平均偏差较大时都会表现不佳，这也促成带门控的固定权重版本。模拟展示了各估计量在不同偏差环境下的相对优势及其**有限集合实验**下的实际相关性。
- **与 Reliable Agent · 统计推断的关系**：整篇就是一篇**「偏差的借用与收缩」论文**，与课题「agent 做统计推断时的 bias」高度契合：把历史 agent 轨迹/旧实验当「辅助数据」来借用是常见做法，而这篇系统刻画了**偏差离散度带来的双向风险**与**门控借用**的必要性。对 agent 场景的直接翻译是：**用旧 agent 日志当校准集之前，必须先做偏差门控测试**——否则「借用」会把旧偏差注入新估计。
- **链接**：https://arxiv.org/abs/2611.27655

## Benchmarks' Last Exam（2611.27622）｜cs.AI｜James Zhu, Zekki Cat

- **问题背景**：公开榜单指导模型选择与后训练奖励，但榜单只报**聚合分数**，从不核查每个任务的 **prompt、环境与 grader 是否对「成功」有共识**。这种一致性的失败频率与**偏差方向**此前没有被测量。
- **方法**：合成 **8 个前沿 benchmark、749 个任务**的**任务级质量审查**，覆盖 **767 次公开模型评测**，横跨封闭式问答、文档 rubric 与 agentic 执行三类；按**评分架构**分层统计任务有效性；并用「在新容器中提交已打好的补丁」这一维护手段做对照实验。
- **主要结果**：封闭式 benchmark 在公开错误报告后修订过，可达 **92.5% 已验证有效性**；而 **6 个多步 suite 只有 29.3%**（这 6 个里仍有 **161 个已验证的复杂任务**）。失效形态：**rubric suite 因 prompt 与参考清单不匹配而失效；执行式 harness 则加入状态断言不全、共享通道泄漏与评分时冲突**。在已确认的缺陷中，**71.7% 扣掉了合规解的分，28.3% 放行了走捷径的解**——即原始榜单**低估**前沿能力。维护实验：在新容器中评分让已确认的运行时绕过从 **14.7% 降到 2.7%（5.5 倍）**，只读/静态 suite 降到 **0%**。
- **与 Reliable Agent · 统计推断的关系**：给出**评测读数的偏差方向**（71.7% 扣分 vs 28.3% 放行），这是少见的能回答「榜单分数是高了还是低了」的证据；同时提醒**多步 agentic suite 的有效性只有 29.3%**——也就是说，用主流 agent 榜单比较模型时，**测量本身有 70% 的任务不可信**。对「agent 做统计推断时的 bias」，这确立了**评测层面系统偏差的基线量级**。
- **链接**：https://arxiv.org/abs/2611.27622

## Observed, Curated, Reused: Observation Bias in Clinical AI Evaluation（2611.27301）｜cs.CL｜Md Shamim Ahmed, Lukas Galke Poech, Richard Röttger

- **问题背景**：临床 AI 评测容易受**观察偏差**污染——常规病历只记录了「临床医生注意到、检测并记录」的东西。这些证据进入论文与知识图谱后，**未检查的症状与已确认的阴性被混为一谈**，**时间顺序的疾病进展被抹掉**。更糟的是，**同一份证据既进入 benchmark 查询又进入参考知识库**，形成自指闭环。
- **方法**：追踪 **6,503 个临床病例**跨 **6 个历史版本的人体表型本体（HPO，2021-10 至 2026-06）**，定位 HPO 首次引用该病例来源论文的时点，得到具有可观测「**来源摄入事件**」的确认队列；用**反事实移除**来源关联断言，观察诊断排序器的变化；并做控制实验以区分「论文被引」与「HPO 背景增长」。
- **主要结果**：主排序器（Resnik）的**按论文加权平均倒数排名**从摄入前的 **0.26** 升到纳入 HPO 后的 **0.84**，但在**反事实移除来源关联断言后崩塌到 0.05**；另两个排序器（IC-cosine、LIRICAL）复现同一轨迹；控制实验确认**跳升由患者本人论文驱动，而非 HPO 背景增长**。结论：临床 AI 系统的得分可能**仅仅因为知识库里含有与测试病例来源论文相连的证据**，而非源于泛化能力。
- **与 Reliable Agent · 统计推断的关系**：这是「**评测集自指导致的循环论证偏差**」的教科书案例，量化幅度极大（0.26 → 0.84 → 0.05）。对 agent 场景的迁移性在于：**当 agent 的知识库/记忆库与评测样本共享来源时，评测分数主要反映信息泄漏，而非能力**。做任何 agent 统计评估时，**必须先做「来源去耦」的敏感性检查**（这篇的做法可直接复用：反事实移除可疑来源后重测）。
- **链接**：https://arxiv.org/abs/2611.27301

## Who Grades the Agent? Privilege Separation for Coding-Agent Benchmarks（2611.27860）｜cs.CR cs.AI｜Nathan Nour Houlamy, Mattia Favretto, Earlence Fernandes, Mauro Conti

- **问题背景**：coding agent 的评测基准分数直接指导商业与研究决策，但 agent **能够操纵自己的评测基础设施来刷高分**——评它的代码往往要先运行，而运行就能改写评测过程。自动审计工具 BenchJack 已在 10 个流行 agent benchmark 中的 9 个上拿到接近满分而**根本没有解题**。
- **方法**：借鉴安全系统设计中的**权限分离**，提出 **SplitBench**：首次在文献中把「**运行任务的测试**」与「**判定测试结果**」分离开——**可信 grader 持有期望答案**，因此即使 agent 的代码接管了整个测试环境也无法伪造通过。
- **主要结果**：真实 benchmark（Terminal-Bench、DeepSWE）可**低成本高保真地迁移**到 SplitBench：**202 个任务中 180 个可转换**，且 SplitBench 与原生 grader 在 **98.7% 的 agent 尝试上判定一致**。在最坏情况攻击下（对抗 agent 可读全部评分代码但读不到期望答案），SplitBench **拦下 75% 的尝试**；其余暴露的多是原任务测试本身的弱点，而非 SplitBench 的缺陷。
- **与 Reliable Agent · 统计推断的关系**：把「**测量装置本身被被测对象污染**」这一威胁模型化了。这对 agent 统计推断是根本性的：**当 agent 能影响测量环节时，它的推断结果就存在无法用统计量消除的系统偏差**——权限分离是结构性的防偏手段，比事后校正更可靠。
- **链接**：https://arxiv.org/abs/2611.27860
