## Simple, general strategies for correcting the upward bias of calibration summaries of prediction models（2611.33846）｜stat.ME stat.AP｜Mohsen Sadatsafavi, Ramin Rezaeianzadeh, Hessam Sadatsafavi

**分类**：stat.ME stat.AP　|　**作者**：Mohsen Sadatsafavi, Ramin Rezaeianzadeh, Hessam Sadatsafavi　|　**链接**：https://arxiv.org/abs/2611.33846

**问题背景**：临床预测模型评估「全预测值谱段上的校准」时，习惯用柔性校准曲线加一个标量摘要（如 integrated calibration index，ICI）。问题在于这类标量摘要建立在一个**绝对值估计量**上——其抽样分布可以跨过 0，于是天然带有限样本的**向上偏差（upward bias）**：真 ICI 越接近 0、样本越小，偏差越严重。

**方法**：① 揭示该偏差的产生机制，并把它量化为「真实校准误差 + 其方差」的函数；② 提出易于实现的降偏方法：plug-in 法与 inversion 法，各有局部与全局两个版本；③ 关键优势在于**通用性**——只要平滑方法能给出校准曲线上逐点的估计与抽样方差，就能套用。

**主要结果**：方法可覆盖不同结局类型（连续、二元、生存时间，以及预测治疗收益的**反事实结局**）；偏差调整后的校准误差曲线还能给出其他度量的偏差修正估计（如分位数类 E50、E90）。数值与案例研究显示：当样本小且真实 ICI 接近 0 时，向上偏差可能相当可观；**Global Inversion 去除的偏差最多**（尤其偏差本身较大时），但若偏差原本很小，它可能轻微增大平均绝对误差。摘要未给出具体偏差幅度数值。

**与 Reliable Agent·统计推断的关系**：这是今天与用户课题最贴的一篇「bias」正面写法——**偏差不在模型身上，而在度量装置的有限样本性质里**。任何 agent 评测只要用一个标量摘要（成功率、平均分、聚合后的校准误差）汇报结论，就会继承同类的向上偏差，而且恰在最需要它可靠的场合（样本小、真值接近 0、也就是"其实没差别"）最严重。三个可直接照搬的做法：① 报告偏差修正后的**曲线**而不只是标量；② 把「偏差可由真误差与方差预测」当作评估流程的前置计算；③ plug-in / inversion 是即插即用的后处理，几乎不改现有评测代码。

## LatentCP-DPO: Conformal Pessimism for DPO with Finite-Sample Guarantees（2611.34275）｜cs.LG cs.AI｜Hongwei Xu, Jingyi Liu, Vincent Y. F. Tan, Zai Yang, Yulian Wu

**分类**：cs.LG cs.AI　|　**作者**：Hongwei Xu, Jingyi Liu, Vincent Y. F. Tan, Zai Yang, Yulian Wu　|　**链接**：https://arxiv.org/abs/2611.34275

**问题背景**：DPO 用人类偏好数据训练响应策略，数据有限时会过拟合噪声或弱信息的偏好标签。conformal prediction 天然适合构造不确定集，但**「用不确定集做悲观优化」究竟对策略性能有多大影响**（是更保守所以更安全，还是引入了新的系统性偏差），此前缺乏统计刻画。

**方法**：把 conformal prediction 与悲观偏好优化结合，支持 Bradley-Terry（BT）成对反馈与 Plackett-Luce（PL）排序反馈。沿用 LatentCP 对**未观测模型参数**构造不确定集的思路；在可交换性 + 偏好模型正确设定下，从可观测偏好的 conformal 集构造出潜在相对奖励的不确定集，得到**有限样本边际覆盖**；随后用一组独立的 prompts 与候选回答（**无需偏好标签**）最大化不确定集上的最坏情形偏好对数似然。

**主要结果**：给出正则化策略次优性的**有限样本上界**，把误差干净地拆成三类——策略类逼近误差、conformal 不确定性、统计估计误差；BT 反馈下进一步给出与该上界在「无标签优化样本数倒数」这一依赖上**匹配**的最坏情形下界。下界还表明：**不确定集本身会引入一种随优化样本增大而持续存在的 bias**（不是随 n 消失的有限样本噪声）。实验支持该框架在有限偏好数据集上的收益。摘要未给出具体误差数值。

**与 Reliable Agent·统计推断的关系**：直接命中「Agent 做统计推断时的 bias」——它把"用保守不确定集会带来偏差"写成了**可量化、可匹配的上下界**，而不是一句"更安全所以更好"。三个可迁移点：① 三分误差拆解（逼近误差 / 不确定性 / 估计误差）可以直接当作自己 agent 系统评估结果的报告模板；② 强调**样本量增加不自动消除偏差**——这与"多跑几次就稳了"的直觉相反，值得在自己的实验里单独检验；③ 用**无标签的独立 prompts**做最坏情形优化，是一条成本很低、可以立刻在自己系统里试的路径。

## Certifying a Sufficient Gaussian Dependence Regime for Learned Weighted FDR Control（2611.33892）｜stat.ME math.ST stat.ML stat.TH｜Soyeong Oh

**分类**：stat.ME math.ST stat.ML stat.TH　|　**作者**：Soyeong Oh　|　**链接**：https://arxiv.org/abs/2611.33892

**问题背景**：从信息性的辅助数据里学出假设权重，可以提升多重检验的检验力。但**即使权重是从与检验独立的数据中学来的**，加权 Benjamini-Hochberg（BH）的有效性仍然取决于权重的联合分布。实践中权重来源五花八门（历史数据、相关结构、辅助协变量），缺乏统一的可控假设。

**方法**：用**参考观测（reference observations）**去认证一个充分的相依条件，适用于单侧 Gaussian 检验。做法是用一个「相关符号不确定」的 intersection-union test 来决定：采用加权 BH，还是退回到预先设定的 fallback（在调整后的显著性水平上）。在**认证数据与检验数据条件独立**的前提下，该程序对每一个满足既定抽样假设与权重约束的 Gaussian 相关矩阵都控制 FDR。

**主要结果**：证明了**统一性认证的边界性障碍（boundary obstruction）**，并给出匹配的 minimax 样本量界——覆盖最坏情形成对检验与全对检验问题；在匹配界覆盖的参数范围内，minimax 样本量随检验对数**对数增长**、随正边际的倒数**二次增长**。仿真最多 **4,950** 对检验，在**相同受试者预算**下做方法对比，并用基于 Healthy Brain Network 相关估计的 Gaussian 设计，展示**认证成本与检出检验力之间的取舍**。

**与 Reliable Agent·统计推断的关系**：本期唯一实质命中多重检验 / FDR 的论文，方法论上非常"可靠 agent"：给出的是**可证伪的充分条件 + 明确的失效边界 + 匹配的样本量下界**——即"在什么条件下我们敢保证控制 FDR"，而不是笼统地说"我们用了 BH"。类比到 agent：当你用"打分 + 阈值"对一批样本做批量判定时，权重来源不独立、符号不确定这些失效模式，在 LLM-as-judge 打分里几乎是默认状态。**认证成本 vs 检验力的取舍**这个框架也正适合描述"为 agent 加多少审计 vs 效率损失多少"的工程权衡。

## Sequential Testing on Complex and High Dimensional Data Streams Leveraging Unsupervised Model Errors（2611.33238）｜cs.LG cs.AI｜George Stamatelis and Iordanis Koutsopoulos

**分类**：cs.LG cs.AI　|　**作者**：George Stamatelis, Iordanis Koutsopoulos　|　**链接**：https://arxiv.org/abs/2611.33238

**问题背景**：在流式环境（如网络流量元数据）里，数据太复杂，无法为常规似然比驱动的检验写出精确的概率模型；同时存在**信息不对称**——只有 null / 变更前的数据，没有 alternative / 变更后的数据（零日攻击、新发疾病这类场景）。传统似然比路径在这里直接不可用。

**方法**：提出两个通用的**分布无关（distribution-free）**检验统计量，分别用于二元序贯假设检验（SHT）与序贯变点检测（SCPD）。核心机制是：监控一个**只用 null / 变更前数据训练**的预测或重构模型的**误差**，依赖的性质是"模型在 alternative 类数据上性能会退化"。在关于模型误差的温和假设下给出严格保证。

**主要结果**：SHT 具备**严格的非渐近误差控制**；SCPD 给出平均运行长度（ARL）与期望检测延迟（EDD）的**显式界**。在目标跟踪、混沌动力系统与真实网络安全数据集上的评估显示，框架持续满足预设约束，而既有算法会出现漏检或虚警膨胀。统计量只依赖标量误差，**无需在线重训或核计算**，因此可扩展。摘要未给出具体 ARL / EDD 数值。

**与 Reliable Agent·统计推断的关系**：这是"信息不对称下的序贯检验"——只有正常期数据、异常期数据从未见过的设定，几乎就是「agent 上线后收集不到失败样本」的镜像，而后者恰恰是可靠性研究里最难的情形。可迁移的核心是**用模型的误差 / 新颖度作为检验统计量**，把"异常检测"从调阈值的启发式变成有非渐近保证的检验。对 agent 系统而言：只要能拿到"仅用正常轨迹训练"的模型，就能对漂移、异常行为、越权动作开一条带误差控制的检测通道，而不必等真实事故发生。

## A Hierarchy of Risk Certificates for Representation-Based Prediction（2611.33333）｜cs.LG cs.AI｜Mohit Kumar and Somayeh Kargaran

**分类**：cs.LG cs.AI　|　**作者**：Mohit Kumar, Somayeh Kargaran　|　**链接**：https://arxiv.org/abs/2611.33333

**问题背景**：基于表示（representation）的预测支撑着大量 ML 系统。但**"拟合出的预测器不满足精度要求"并不能推出"它的表示-解码器类不满足"**——个体失败与类别失败是两件事，需要能对整类解码器做下界认证的工具。

**方法**：研究固定表示上、作用于 Lipschitz 解码器的**最优总体 MSE**。对 b≥2 个 iid 观测块，在成对 Lipschitz 约束下最小化总平方误差（按 b−1 归一）。证明：期望块分数构成最优类风险的**非递减下界**，并在紧致度量特征空间上**收敛**到该风险；但**不存在固定块大小能给出统一的相对保证**。再结合经验证的对偶下界与**与模型开发相互独立的 iid 校准观测**（要求目标与预测有界），得到最优类风险的**同时下置信界**与拟合预测器风险的**上置信界**。

**主要结果**：这些界可以支撑两类判定——"每一个可接受的解码器都超过给定 MSE 阈值"，或"某个可接受的拟合预测器达到了该阈值"。受控实验展示总体风险认证；固定 PTB-XL 与 Bike Sharing 数据集给出确定性的经验风险结论。**大规模下的高效认证，以及相依观测下的扩展，仍是开放问题**（摘要未给具体数值）。

**与 Reliable Agent·统计推断的关系**：提供了"整体性失败 ≠ 类别性失败"的严格证据，并给出一套可操作的判定协议（同时置信界 + 独立校准集）。对 agent 评测的直接启发：agent 系统某次运行失败时，**不能立刻判定"这个 scaffold / 这类 prompt 处理方式不行"**——单次失败只是个体证据，要下类别结论需要类级别的下界。这正是"多运行评测"与"单次评测"在结论强度上的差别所在，也解释了为什么可靠的 agent 评估报告里，跑几次、置信区间多宽是必写项。

## Joint Estimation of Abilities and Item Parameters for Large Language Models Using Probability and Binary Responses: A Fractional-Response IRT Framework（2611.33493）｜stat.ME cs.AI｜Masayuki Takayama and Shohei Shimizu

**分类**：stat.ME cs.AI　|　**作者**：Masayuki Takayama, Shohei Shimizu　|　**链接**：https://arxiv.org/abs/2611.33493

**问题背景**：LLM 评测天然有两类响应——模型赋给正确答案的**概率**（连续）与**正确性二元指示**。若只取一类，要么限制可用模型范围（需要模型能输出概率），要么直接丢弃概率信息。

**方法**：用共同的**两参数 logistic 项目反应模型（2PL IRT）**把两类响应整合到同一框架，用 **fractional-response 拟极大似然（QML）**估计。该框架**包含纯二元模型**，因此可以做共同尺度（common-scale）评测而不丢弃概率信息。

**主要结果**：模拟评估两类响应期望值相同时的统计效率——**加入概率型"受试者"比加入二元受试者更有效地改进题目标定**；但在等观测权重下，向一个已经精确的概率样本里加入噪声更大的二元响应，**可能反而增大估计误差**。应用于 MMLU：把 Open LLM Leaderboard 的概率响应数据与 HELM 的二元响应数据结合，揭示了模型家族的响应模式、题目特征差异，以及**不同评测协议之间的系统性能力漂移**。结论强调：更广的测量覆盖本身并不自动带来更高精度或测量等价性。

**与 Reliable Agent·统计推断的关系**：对 LLM-as-judge 评测最实用的一篇——只要裁判输出的是概率或分数而不是 0/1，就该用 fractional-response IRT，而不是二值化或直接丢弃；而且"加更多样本"并不等于"加更多信息"，**样本的响应类型比样本量更决定精度**。更值得警惕的是"**系统性能力漂移**"：不同评测协议（不同提示、不同采样参数、不同裁判）测出的能力不可直接比较——这与近期"评测装置自身可信度"这条主线直接呼应，说明协议差异足以在能力量表上造成系统性位移。

## Addressing Missing Exposures in Causal Inference: A Practical Guide（2611.33336）｜stat.ME｜Mo Wang, Elizabeth A. Stuart, Keith Barnatchez

**分类**：stat.ME　|　**作者**：Mo Wang, Elizabeth A. Stuart, Keith Barnatchez　|　**链接**：https://arxiv.org/abs/2611.33336

**问题背景**：流行病学研究里**暴露数据缺失**很常见，会让因果效应的识别与估计变复杂。尤其在构造双重稳健（doubly-robust）估计量时，研究者常不清楚标准方法（如增广逆概率加权 AIPW）该如何适配缺失暴露的情形。

**方法**：① 梳理缺失暴露带来的挑战，并归纳实践中的多种缺失机制；② **演示为什么仅有双重稳健性不足以保护 complete-case AIPW 免于缺失暴露偏差**；③ 给出三类处理路径：**multiply-robust 估计、单重插补、多重插补**；④ 以"若无缺失数据时本来会构造的" complete-data AIPW 作为基准，比较各方法分别插补了理想完整数据估计量的哪些不同组件。

**主要结果**：通过仿真说明**缺失机制、效应异质性与模型设定**对各方法性能起关键作用。讨论实际实现问题，包括**是否应当用结局信息来插补暴露**，还是用它来预测暴露的缺失机制。结论给出帮助研究者选择分析策略的建议，并指出建模取向上的注意点。摘要未给出具体数值。

**与 Reliable Agent·统计推断的关系**：属于经典统计推断（缺失数据 + 因果），可作为可信 agent 的因果分析组件参考，但它给出的可迁移原则其实很硬：**双重稳健不是免罪符**——存在缺失机制时，双重稳健性本身不保证无偏，必须把缺失机制显式写进估计量并做敏感性分析。这与"评测装置自身可信度"是同一个道理：装置的鲁棒性属性必须在缺失 / 非随机条件下**单独检验**，不能由常规情形下的表现外推。

## CondUQ: Calibrated Conditional Uncertainty Quantification Using Distribution Matching（2611.33939）｜cs.LG stat.ML｜Shizhuang Wang, Tianhao Wang, Xingqun Zhan

**分类**：cs.LG stat.ML　|　**作者**：Shizhuang Wang, Tianhao Wang, Xingqun Zhan　|　**链接**：https://arxiv.org/abs/2611.33939

**问题背景**：可靠性与安全关键的应用需要准确的输出不确定性量化。系统的误差常随输入质量与运行条件变化，**单一 Gaussian 模型无法刻画**；Gaussian mixture 与校准分位数虽能近似误差分布，但其**无条件形式捕捉不到误差对这些因素的依赖**。

**方法**：提出 condUQ，把误差模型**条件化在可观测因素**上。它叠加在已有系统之上、不修改该系统，因而**对黑箱同样适用**。第一步把可观测因素映射到一个潜在**质量指数（QI）**，使共享同一 QI 的误差服从一个共同的、近似 Gaussian 的条件分布；QI 预测器用**分布匹配目标端到端训练，且不需要质量标签**。第二步对每个 QI 在大规模留出集上拟合并校准一个 Gaussian 误差模型。

**主要结果**：三个例子——(a) GPS 多径误差，按卫星仰角与信号强度条件化；(b) transformer 视觉相对位姿回归模型的相对姿态误差，按图像对内部特征条件化；(c) 世界模型的预测误差，按输入观测与动作条件化。三例中 condUQ 都**显著减小了建模误差分布与经验误差分布之间的差距**，优于单一全局模型；学到的 QI 还以符合物理原理的方式揭示了各因素如何影响误差特性。摘要未给出具体分布距离数值。

**与 Reliable Agent·统计推断的关系**：条件化 UQ 是"校准"从**全局**走向**局部**的范式。对 agent 而言，等价于"按任务难度 / 上下文分层报告不确定性"，而不是甩给用户一个全局置信度——而全局置信度恰恰是"agent 在熟悉场景很准、生僻场景崩掉"这类问题最常见的误诊来源。两个值得直接借用的工程性质：**黑箱友好**（不改被测系统，适合给现成 agent 加不确定度估计）与**不需要质量标签**（分布匹配端到端训练 QI，落地门槛低）。

## Agent-as-a-Verifier: From Scores to Evidence for General Verification（2611.34132）｜cs.LG｜Yuxuan Sun, Hao (Mark) Chen, Nagarajan Natarajan, Sushrut Karmalkar, Niranjani Prasad, Amit Sharma, Hongxiang Fan

**分类**：cs.LG　|　**作者**：Yuxuan Sun, Hao (Mark) Chen, Nagarajan Natarajan, Sushrut Karmalkar, Niranjani Prasad, Amit Sharma, Hongxiang Fan　|　**链接**：https://arxiv.org/abs/2611.34132　|　**代码**：https://github.com/sunyxedu/General-Verifier

**问题背景**：验证在测试时扩展、递归智能与自动化研究里越来越关键。常见的**基于分数的验证器**（判别式奖励模型）只输出一个标量奖励，适合过滤、奖励与排序，但**不提供明确、可审计的证据基础**。另一方面，已有生成式过程奖励模型虽给出文本反馈，却大多未充分利用 agentic 能力（工具使用、迭代推理），而这对事实核查与细粒度声明验证恰恰是必需的。

**方法**：引入 Agent-as-a-Verifier，一个 agentic 的、**产出证书（certificate）**的验证系统，把**角色分离（role-separated）**的 LLM agent 放进一个受形式化方法启发的「声明-义务-证书」协议。给定一个生成候选，它会：抽取一个 **verdict-blind 的声明依赖图**（不知道结论地抽依赖）、**独立编译**该任务的验收契约（acceptance contract）、再推导出一组**可检查的义务（obligations）**。

**主要结果**：在 Terminal-Bench 2.1 上准确率**高于当时最好的方法**；在不同下游应用中，装配该 agent 的增强系统在 FrontierMath 与 CyberGym 上均优于普通 agent。更重要的是，它能**识别出欺骗 benchmark 评估器的 reward-hacking 解**，显示其在迭代 / 递归 agent 优化上的潜力。代码已开源。摘要未给出具体准确率数值。

**与 Reliable Agent·统计推断的关系**：对"评测装置自身可信度"这条主线最直接的推进——把"评分"升级为"**可审计的证据 + 义务**"，评分只是证据链的副产品。两个设计特别值得借鉴：**verdict-blind 依赖图**（避免确认偏误式地先给结论再找理由）与**独立编译验收契约**（把"什么算通过"从被测系统里剥离出来，避免自己给自己出题）。"能识别 reward hacking"这一点则与用户关心的评测可信度正面相关：当裁判会被骗时，结论的置信度必须相应下调。

## Evaluating More with Less: Black-Box Test Selection for AI Agents（2611.34617）｜cs.SE｜Ali Asgari, Mitchell Olsthoorn, Arie van Deursen, Annibale Panichella

**分类**：cs.SE　|　**作者**：Ali Asgari, Mitchell Olsthoorn, Arie van Deursen, Annibale Panichella　|　**链接**：https://arxiv.org/abs/2611.34617

**问题背景**：agentic 软件系统越来越多地进入开发流程，模型、prompt、脚手架、工具或执行环境的任何改动都要求反复测试。**用例选择（TCS）**可降低测试成本，同时提供 agent 表现的估计或尽早暴露失败。但既有 TCS 研究针对深度神经网络与 LLM 代码模型，**没有直接处理 agentic 系统**，且常需要专有 agent 拿不到的信息。

**方法**：给出**黑盒 TCS 用于 agentic 软件系统的首个实证研究**。把每个基准任务当作一个测试用例，改造**黑盒回归测试**技术，选择准则基于任务描述、元数据、代码片段与 embedding；还提出用启发式特征或**独立的 LLM-as-judge 评估**来估计任务难度。关键在于：所提策略在**不执行目标 agent、也不使用历史结果**的前提下完成任务选择。

**主要结果**：评估 **14 种选择策略**（含随机采样）加一个历史数据基线，覆盖 **10 个 AI agent 基准**、每个基准 12–101 个 agent，考察**成功率（Success Rate）估计**与**早期失败检测**两个目标。结论明确：**没有单一策略在两个目标上同时占优**——改造的黑盒回归测试策略更适合成功率估计（Category Partition 在 20% 任务预算下于 5 个基准上取得最低中位误差），LLM-as-judge 选择更适合早期失败检测。成本示例：在 SWE-bench Verified 上对 GPT 5.2 Codex，Category Partition 用 **100 个而非 500 个任务**，执行成本从 **$225 降到 $47**，成功率估计误差 **0.8 个百分点**；同等预算下 LLM-as-judge 选择检出的失败几乎是随机抽样的两倍（**53.0% vs 27.4%**）。

**与 Reliable Agent·统计推断的关系**：把"agent 评测该花多少钱"变成了有统计支撑的资源分配问题，也顺带回答了"评测结果该有多少可信度"——**0.8 个百分点的成功率估计误差**是一个可以引用、可以对比的精度指标，而"抽 100 题就下结论"在别的设定里误差可能是几十个百分点。更值得注意的是"**没有单一策略占优**"这个结论本身：估计表现与检出失败是两个不同的目标，评测设计必须先声明你要哪一个，否则"我抽了 100 道题"这个动作本身不构成任何保证。

## CypherMAS: Benchmarking Routing Reliability in LLM-Based Multi-Agent Systems（2611.33242）｜cs.MA cs.AI cs.CL｜Danil Kostromin, Andrey Sakhovskiy, Semen Budennyy

**分类**：cs.MA cs.AI cs.CL　|　**作者**：Danil Kostromin, Andrey Sakhovskiy, Semen Budennyy　|　**链接**：https://arxiv.org/abs/2611.33242　|　**代码**：https://github.com/Andoree/CypherMAS

**问题背景**：基于 LLM 的多智能体系统（MAS）把推理分散到专门 agent，它们必须**可靠地交换消息与调用工具**。既有评测通常把通信与开放式任务耦合在一起，因此难以判断一次失败究竟来自推理、格式错误的工具调用、消息丢失，还是请求被遗忘；既有基准也**没有隔离通信执行**，更没有对照已知最优路径来度量路由冗余。

**方法**：引入**合成基准 CypherMAS**，在固定的多 agent 图中隔离通信与路由。agent 被置于 chain / star / bipartite / ring 等图结构中，把**加密消息（cyphered）路由给持有匹配解码器的远端 peer**；由于**最优路径是已知的**，冗余的 LLM 调用可以被度量，路由失败也可被直接追踪。

**主要结果**：在 **11 个开源权重模型（4B 到 753B）**上的发现是——小模型在路由与工具使用上失败；**27B 以上的稠密模型随图直径增大而退化**；成功的运行会**超过最小 LLM 调用数**（即存在可测的路由冗余）。结论：通信可靠性是多智能体系统一个**独立的扩展性瓶颈**，并为复杂 MAS 提供了受控诊断工具。源码开源。

**与 Reliable Agent·统计推断的关系**：把笼统的"多 agent 失败"拆成了可归因的通信 / 路由维度——这是"可靠 agent"里很基础却常被忽略的一层：agent 系统的不确定性不只来自模型，也来自**拓扑与消息传递**。可借用的方法论是"**合成受控基准 + 已知最优路径**"：用这种方式，一个笼统的现象可以被拆成一组可定位的子问题。对多 agent 系统的可靠性报告来说，"路由失败率"应当和"答案错误率"并列汇报。

## Refusal Is Not Scored: A Coverage Limit in Content-Based Bias Evaluation（2611.33690）｜cs.CL cs.CY｜Afifah Kashif, Malak Sadek, Jin Huang, Hatice Gunes

**分类**：cs.CL cs.CY　|　**作者**：Afifah Kashif, Malak Sadek, Jin Huang, Hatice Gunes　|　**链接**：https://arxiv.org/abs/2611.33690

**问题背景**：对话模型的偏见审计常在打分**之前丢弃拒答**（如 "I can't assist with that request"）。这一步过滤几乎从不被当作**测量决策**来审视，尽管它恰恰决定了这份审计究竟能评估到哪些响应。

**方法**：考察这一步到底移除了什么。应用 **7 种偏见评估工具**（覆盖两种部署范式：**3 种词典法 + 4 种 LLM-as-judge**），在**两个交叉性数据集**上各 **360 条**生成响应。随后**移除过滤**，把每一条拒答都交给全部 7 个工具。

**主要结果**：两个数据集中，过滤器移除了一个在**人口统计上偏斜**的子集，且**完全由三个 responder 模型中的某一个**产生——该模型对朝鲜 prompt 的拒答率是**美国 prompt 的 2.15 倍**（陈述性内容）与 **1.76 倍**（操作性内容）。移除过滤后：**Bias-Lexicon 把拒答评为"干净"**，纳入它们反而缩小了它报告的国籍差异；**HurtLex 似乎捕捉到了差异**，但追溯发现这**完全来自词表中 "can" 匹配到 "I can't" 的单个词条**；LLM judge 要么标记大多数响应、要么把拒答评为无偏；两个有区分度的 judge 在纳入拒答后报告的国籍差异**下降**，且**没有任何工具能识别出拒答差异本身**。

**结论**：失败发生在**打分上游的覆盖限制**，而不是靠更好的词表或裁判提示就能弥合的校准差距；因此"裁判对哪个行为通道敏感"是一个**构念效度（construct validity）**问题，而不是方法选择问题。

**与 Reliable Agent·统计推断的关系**：与用户关心的"偏差"完全对口——它提醒我们：**测量装置的覆盖范围决定了哪些偏差根本不可见**。任何关于 agent 偏差的结论，都应先问一句"我把哪些样本排除了"（拒答、超时、工具失败、被安全策略过滤的输出）——排掉的样本不是"没有数据"，而是"数据里最可能有偏差的那部分"。LLM-as-judge 在拒答上的表现（要么全标、要么判无偏）尤其说明：**裁判本身对某些行为通道是失灵的**，而不只是不够准。
