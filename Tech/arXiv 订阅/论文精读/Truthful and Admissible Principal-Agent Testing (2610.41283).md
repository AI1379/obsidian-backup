# Truthful and Admissible Principal–Agent Testing with Nuisance Parameters

- **arXiv**: [2610.41283](https://arxiv.org/abs/2610.41283)（stat.ME / cs.GT / math.ST / stat.TH, 2026-10-30）
- **作者**: Aaditya Ramdas（Stanford University）
- **一句话**: 把"实验者上报的估计量能不能信"变成一个可证明的激励相容问题——用 **e-value 菜单**做契约，使得"诚实上报真实均值"是唯一最优报告，同时契约本身**可容许**（admissible，无法被逐点改进）；并且结论在**方差未知**时依然成立，无需对 nuisance 参数设先验。

## TL;DR

1. 统计契约 = 按证据付费的奖励规则。风险中性、报告在抽样前选定、参与成本与报告无关时，"在每个原假设下期望净收益 ≤ 0"**恰好就是 e-value 的定义**——同一个期望同时管住统计有效性与参与激励。
2. 新的第四条要求：**可容许性**（admissible）——不存在另一个有效的 e-value 能在逐点意义上提高赔付。它排除"证据函数给弱了"的情况，且与 truthful 要求**可能冲突**。
3. **Theorem 4.2（完全知情高斯 agent）**：契约落在 [1−η, 1+η]，对所有 µ≤0、σ>0 有效且可容许；在 µ>0 上严格诱导 (µ, σ)，每个类型都有严格正的期望净收益。
4. **Theorem 5.1（只知均值的 nuisance-uninformed agent）**：契约可容许、对每个有限原假设类型期望严格 < 1；对任意 µ>0 与**任意** σ>0，期望在 m=µ 处**唯一**最大，truthful 期望严格 > 1。**不需要对未知方差设任何先验**。
5. **Theorem 6.2 / 6.4**：任意固定样本量 n≥1 都有有界、可容许、严格 truthful 的菜单（中心化原假设亏空 O(σ^{−(n+2)})）；多样本时证据过程几乎必然增长（Prop 6.3），即"累积证据"能被奖励。
6. 超出高斯：**Theorem 7.2** 形状未知（对称单峰）仍可诱导位置；**Theorem 9.3** 单个观测下"可容许 + 严格诱导有界均值"**不可能**；**Theorem 9.4** 两个观测即可在全类 iid 分布上可容许地诱导均值；**Theorem 10.1** 对任意非负有限均值分布（哪怕无穷方差）用两个观测可做可容许的均值诱导。
7. 最后一节区分了"有用检验的存在"与"诱导诚实报告所需的识别性"：**有界性非必要**，仅有有限个原假设约束本身**不足以**保证可容许的诱导（Theorem 9.3 是反例）。

## 背景：为什么"统计有效"不等于"上报诚实"

经典主–代理检验（Tetenov 2016；Bates et al. 2022）只解决"让无效方案不可获利"：设 C>0 为实验成本、L_r(X) 为上报报告 r 后的非负奖励，报告在抽样前选定，则

    E_r(X) := L_r(X) / C ≥ 0,   sup_{P∈P} E_P E_r(X) ≤ 1

这**就是 e-value 的定义**（对每个提供的报告 r 都要满足）。大值即反原假设证据：Markov 不等式给出 P(E_r ≥ 1/α) ≤ α 在任何原假设下成立。风险中性 agent 的期望净收益是 C(E_P E_r − 1)——**同一个期望同时决定统计有效性和进入激励**。

本文要补的是：**统计上有效的契约未必诱导诚实报告**。例：已知 σ 时，以报告均值 m>0 为索引的似然比

    e_m(x) = exp( m x / σ² − m² / 2σ² )

对 H0 是合法 e-value，但其期望在 m ≠ µ 时更高，因此**不 truthful**。这正是"统计有效但结论有偏"的机制化版本。

## 框架：两种信息 regime + 四条要求

**两种 regime**
- **完全知情**：agent 知道 µ 和 σ；主方希望同时诱导出 (µ, σ)，且不让 agent 夸大效应或错报噪声。
- **nuisance-uninformed**：agent 知道 µ 但**不知道 σ**（要求只问它有的信息）；目标是"真实均值是唯一最优报告，**与方差无关**"，且不需要对方对 σ 持某种先验。

**四条要求**（本文核心）
1. **无收益也无损害**：知道自己是原假设的 agent 没有参与动机（任何报告的期望净收益 ≤ 0）；
2. **诚实最优**：非原假设 agent 的最优报告**唯一**地是真值；
3. **严格正收益**：每个备择类型都有严格正的期望净收益，因而愿意参与；
4. **可容许性**：不存在另一个有效 e-value 能逐点提高赔付（在非可忽略集合上严格提高）。

任何 e-value 菜单都满足第 1 条；四条同时满足是**非平凡**任务。

## 关键定义

**Definition 3.3（可容许 e-value）**：一个原假设有效的 e-value E 称为可容许的，若任何原假设有效的 G 都无法逐点改进其赔付（在非可忽略集合上严格改进才算改进）。注意：**上界在定义中不起作用**——可容许性与"e-value 是否有界"无关。

**Lemma 3.4（精确性与覆盖）**：若 E 有效且存在子族 P*_n ⊆ P_n 使 E 在其上精确，则 E 可容许；特别地，存在精确的原假设分布等价的常见原假设时成立。

**Lemma 3.5（弥散原假设穷尽）**：若原假设族被测度 ν 支配、极集与 ν-零集重合，则有效 E 可容许 ⟺ 其"偏离 ν 的部分"在 ν 下积分为零。

**Corollary 3.6（高斯零积分扰动）**：在弥散高斯原假设下，**零积分的可积扰动**保持可容许性。这是后续所有构造的引擎。

## 对我们课题（Agent 做统计推断时的 bias）的意义

1. **偏差的一种内生机制被形式化了**：当上报者（agent）有私有信息且按结论付费时，**激励扭曲本身就是偏差来源**。若要让 agent 报的置信度/估计量可用，必须同时处理"结论对不对"与"上报是不是诚实"两层。
2. **nuisance-uninformed 的结论非常实用**：只要保证对未知方差一致成立，就**不需要对方知道方差**。现实中 agent 常只知道部分信息——这意味着我们的统计保证可以在"信息不对称"下依然成立。
3. **可容许性是评估自己方法的一个标尺**：如果我们的"可靠性证书"还能被逐点改进的同类证书取代，那它就不是最强的；这给了我们一个类似"完备类"的分析工具（与 2610.41410 的残差证书可对照）。
4. **"多一次观测换一层保证"的代价表**：单观测不可行 → 双观测可行，这是可写进方法论的具体设计原则。
5. **与前期笔记的衔接**：同一作者 Aaditya Ramdas 在 [Recertifying decisions via e-closure (2610.35821)] 里做的是"把未用完的风险预算变成更大的 e-value"，本文做的是"把 e-value 变成可激励诚实的契约"。两者合起来构成一条清晰的技术线——**e-value 作为统计有效性与激励相容性的公共语言**。

## 可迁移的技术细节

- 构造引擎是 **Corollary 3.6（零积分扰动保持可容许）**：先造一个"近似可容许"的精确核，再用零积分扰动修正，得到既逐点可容许又保持有效性的菜单。
- 真值唯一性的证明通常靠"报告相关项的导数符号"：期望写成 1 + η(µ−c)·f(m)/g(m) 形式，f 单调 g 单调即可。
- 不需要二阶矩：Theorem 10.1 只用到每个观测的一阶矩 E_P U₁ = µ（E_P U₂ = µ² 有限），故**无穷方差形状下依然成立**。
