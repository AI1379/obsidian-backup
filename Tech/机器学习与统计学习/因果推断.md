# 因果推断

## 1. 什么是因果推断

因果推断是从数据中判断"**X 是否导致 Y**"（而非仅仅"X 与 Y 相关"）的统计方法与理论体系。

| | 相关性 | 因果性 |
|---|---|---|
| 问题 | X 变化时 Y 是否跟着变化？ | 干预 X 是否会使 Y 变化？ |
| 数学表达 | $P(Y \mid X)$ | $P(Y \mid do(X))$ |
| 可否用于决策 | 不一定 | 可以 |

**经典例子**：冰淇淋销量与溺水人数高度相关，但吃冰淇淋不会导致溺水——背后是共同原因"天气炎热"。因果推断就是要区分这种**混淆关系**与真实因果。

---

## 2. 核心框架：反事实（潜在结果）

基石是 **Rubin 潜在结果框架（Rubin Causal Model）**：

- 对每个个体，定义 $Y(1)$ = 接受处理时的结果，$Y(0)$ = 未接受处理时的结果
- 个体因果效应 = $Y(1) - Y(0)$
- **核心难题（Fundamental Problem of Causal Inference）**：每个个体只能观察到一种结果，反事实 $Y(0)$ 永远无法直接观测
- 因此关注**总体平均效应**：
  - **ATE**（平均处理效应）：$\mathrm{ATE} = \mathbb{E}[Y(1)] - \mathbb{E}[Y(0)]$，全体的因果效应
  - **ATT**（处理组平均效应）：$\mathrm{ATT} = \mathbb{E}[Y(1) \mid T=1] - \mathbb{E}[Y(0) \mid T=1]$，实际接受处理者的效应

### 观察性研究识别因果的三个关键假设

1. **无混淆 / 可忽略性（Ignorability）**：给定协变量 $X$，处理分配与潜在结果独立，即 $Y(1), Y(0) \perp\!\!\!\perp T \mid X$
2. **重叠 / 正值（Overlap）**：每个协变量取值下，接受处理的概率严格在 $(0,1)$ 内，即 $0 < P(T=1 \mid X) < 1$
3. **一致性（Consistency）**：观察到的结果等于其对应潜在结果，$Y = T \cdot Y(1) + (1-T) \cdot Y(0)$

## 3. 另一大框架：因果图（DAG / 结构因果模型）

Judea Pearl 的 **SCM（结构因果模型）** 用有向无环图（DAG）表达因果结构：

- 节点 = 变量，箭头 = 因果关系
- **混杂因子（Confounder）**：同时影响 X 和 Y 的变量，结构为 $X \leftarrow Z \rightarrow Y$，需调整
- **对撞子（Collider）**：同时被 X、Y 影响的变量，结构为 $X \rightarrow Z \leftarrow Y$，**不能**条件在其上（否则会人为制造虚假相关）
- **后门准则（Backdoor Criterion）**：若变量集 $Z$ 阻断所有从 X 到 Y 的"后门路径"（含箭头指向 X 的路径），则 $\mathrm{ATE} = \sum_z \mathbb{E}[Y \mid X, Z]\,P(Z=z)$
- **do 算子**：$P(Y \mid do(X))$ 表示人为干预 X 的分布，与条件概率 $P(Y \mid X)$（含选择偏差）本质不同
- 前门准则、工具变量识别均可由 **do-演算** 导出

### Pearl 的因果之梯（Ladder of Causation）

| 层级                     | 问题                | 数学形式                      |
| ---------------------- | ----------------- | ------------------------- |
| 1. 关联（Association）     | 看到 X，Y 会怎样？       | $P(Y \mid X)$             |
| 2. 干预（Intervention）    | **做了** X，Y 会怎样？   | $P(Y \mid do(X))$         |
| 3. 反事实（Counterfactual） | 当时**没做** X，Y 会怎样？ | $P(Y(x) \mid X=x', Y=y')$ |

普通机器学习（包括 LLM）基本停留在第一层。详见 [[因果推理与AI调研]]。

## 4. 识别与估计方法

### 4.1 金标准：随机对照试验（RCT）

随机化打破混淆，直接比较两组均值即可得 ATE。缺点是成本高、伦理限制（如不能随机让人吸烟）、外部效度差。

### 4.2 观察性研究常用方法

| 方法 | 核心思路 | 适用场景 |
|---|---|---|
| **回归调整** | 控制协变量后比较 | 维度低、关系线性 |
| **倾向得分匹配（PSM）** | 按"接受处理的概率" $e(X)=P(T=1\mid X)$ 匹配两组 | 协变量多但可测 |
| **IPW 加权** | 用倾向得分逆概率加权构造伪随机样本 | 同上，不丢弃样本，但极端权重不稳定 |
| **双重稳健（DR / TMLE）** | 结果回归 + 倾向得分，二者只要其一正确即可无偏 | 推荐，效率高 |
| **工具变量（IV）** | 找一个只通过 X 影响 Y 的变量 Z | 存在未观测混杂（如孟德尔随机化） |
| **双重差分（DID）** | 处理组与对照组的前后变化之差 | 政策评估（两期面板） |
| **断点回归（RDD）** | 在阈值附近近似随机 | 分数线、年龄门槛等规则性政策 |
| **合成控制法** | 用对照组加权构造"反事实"处理组 | 单一地区/单位的政策效应 |

### 4.3 因果机器学习

- **因果森林（Causal Forest）**、**BART（贝叶斯可加回归树）**：估计异质性因果效应 **CATE**（$\mathrm{CATE}(x) = \mathbb{E}[Y(1)-Y(0) \mid X=x]$）
- 用于个性化推荐、精准医疗等"谁受益最大"问题

## 5. 经典因果检验思路（Hill 准则等）

当无法做正式识别时，辅以以下判据：

- **时间先后**：因在前，果在后
- **剂量—反应关系**：暴露越多，效应越大
- **机制可解释性**：存在合理的生物学/机制解释
- **可复制性**：在不同人群、地区重复出现
- **特异性**：特定暴露对应特定结果

## 6. 应用场景

- **医学 / 流行病学**：药效评估、孟德尔随机化
- **经济学 / 政策评估**：最低工资、教育改革、补贴效果
- **营销 / 推荐系统**：广告增量价值（Uplift Modeling）
- **算法公平性**：区分歧视（因果）与统计相关性
- **AI / 大模型**：因果表示学习、反事实推理（见 [[因果推理与AI调研]]）
