# 常微分方程 2026 秋 — 课程内容总览（截至 2026-10-29）

- 教学班：英文授课班（智云 classroom 88145，林智）
- 已上课次：5 次（9/18、10/9、10/16、10/17 补课、10/23）
- 下次：10/30 第3-5节

## 课程主线
第一章 一阶方程 → 第二章 高阶线性方程 → 第三章 幂级数解

## 各次课内容

### 1. 2026-09-18（周五）第3-5节
- 课程介绍：1.5 学分、英文班、教材章节安排、作业与考核说明
- ODE 基本概念：阶（order）、线性/非线性、解、初始条件；为什么需要微分方程（Newton 第二定律等建模例子）
- 方向场（slope field / direction field）：用一阶方程画方向场，直观理解解曲线
- 一阶方程解法起步：可分离变量方程；换元法（y/x 型齐次方程 → u=y/x 化为可分离）
- 末尾引入一阶线性方程（1.5 节）
- 关键词：order、linear/nonlinear、solution、direction field、separable、change of variables、first-order linear

### 2. 2026-10-09（周五）第3-5节
- 第一章续：**恰当方程（exact equations）**
  - 判别：M(x,y)dx+N(x,y)dy=0，若 ∂M/∂y=∂N/∂x 则恰当
  - 解法：求势函数 F(x,y)，解 F(x,y)=C
- **积分因子（integrating factors）**
  - 非恰当方程乘以 μ(x,y) 使其恰当；积分因子不唯一
  - 特殊情形：只依赖 x 或只依赖 y 的积分因子公式
  - 注：求一般积分因子等价于解一个偏微分方程，通常很难；只讲特殊情形
- 降阶法（高阶 → 一阶）：三类可降阶方程
  1. y''=f(x)：直接积分两次
  2. y''=f(x,y')：令 p=y'，化为一阶
  3. y''=f(y,y')（自治/autonomous）：令 p=y'，用 y 作自变量
- 关键词：exact、potential function、integrating factor、reduction of order、autonomous

### 3. 2026-10-16（周五）第3-5节
- 第二章开始：**高阶线性方程**
- 2.1 线性方程理论：
  - 线性算子、叠加原理（superposition）
  - 齐次解空间是向量空间；二阶齐次方程解空间二维
  - 线性相关/线性无关；**Wronskian（朗斯基行列式）**判别
  - 基础解系（fundamental set）与通解结构：y = c1 y1 + c2 y2
- 2.2 常系数齐次线性方程：
  - 特征方程（characteristic equation）
  - 相异实根 / 重根 / 共轭复根三种情形与对应解
- 关键词：linear operator、superposition、linear independence、Wronskian、fundamental solutions、characteristic equation

### 4. 2026-10-17（周六，补课）第3-5节
- 2.3 **Euler（Cauchy-Euler）方程**：x²y''+axy'+by=0；令 x=e^t（或 t=ln x）化为常系数方程；注意 x<0 / x>0 分支与 log 的出现
- 2.5 **非齐次线性方程**：
  - 通解 = 齐次通解 y_c + 特解 y_p
  - 待定系数法（method of undetermined coefficients）：只适用于常系数 + 特殊右端项，老师只讲思路、要求自学细节
  - **参数变易法（variation of parameters）**：重点，适用于一般右端项；由 Wronskian 构造特解
- 2.8 **边值问题（boundary value problems）**：
  - 初始条件 vs 边值条件；与 PDE 分离变量法的联系
  - 弦振动方程（wave equation）作为引入；特征值问题（eigenvalue problem）
- 关键词：Euler equation、variation of parameters、undetermined coefficients、boundary value problem、eigenvalue、wave equation

### 5. 2026-10-23（周五）第3-5节
- 第三章：**幂级数解**
- 为什么用级数解：多数变系数/高阶方程无闭式解，数值解只是近似
- 复习 Taylor 级数、收敛半径、余项
- 二阶线性方程 y''+P(x)y'+Q(x)y=0 的点分类：常点 / 正则奇点 / 非正则奇点
- 常点：幂级数解 y=Σ cₙ(x−x₀)ⁿ；收敛半径 ≥ 到最近复奇点的距离；例 p.222
- 正则奇点：Frobenius 解 y=(x−x₀)^r Σ cₙ(x−x₀)ⁿ；指标方程 r(r−1)+p₀r+q₀=0
- 两根情形：差非整数 → 两解；差整数 → 一般一解；相等/例外 → 第二解含 log（3.4）
- 例题：指标根 0 与 −1（差整数，从较小根入手，得到 cos x 型与 sin x/x 型）；3.4 exceptional case
- 应用：PDE 分离变量 → Legendre / Bessel 方程
- 关键词：power series、ordinary point、regular singular point、Frobenius、indicial equation、exceptional case、Legendre、Bessel

## 复习建议（按优先级）
1. 第一章：可分离、一阶线性、恰当方程 + 积分因子（计算题高频）
2. 降阶法三类（判断 + 换元）
3. 第二章：Wronskian、特征方程三种根、Euler 方程、参数变易法（重点）
4. 第三章：点分类 + 指标方程 + Frobenius 递推（最花时间，按老师说"所有例子重做"）
