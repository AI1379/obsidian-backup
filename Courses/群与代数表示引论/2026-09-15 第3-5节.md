## 定义与记号

### 1. 代数（`R`-代数）的定义

设 `R` 是一个 **含幺交换环**（commutative unital ring）。

一个 **`R`-代数** `A` 由下述数据组成：

1. **`A` 是一个 `R`-模**（`R` 通过模结构作用于 `A`）；
2. **`A` 上有一个双线性映射** `μ: A × A → A`（称为 `A` 的乘法 / "product"），即对任意 `α, β ∈ R`，`x, y ∈ A` 满足
   $$\mu(\alpha x + \beta y,\, z) = \alpha\,\mu(x,z) + \beta\,\mu(y,z),\quad \mu(x,\, \alpha y + \beta z) = \alpha\,\mu(x,y) + \beta\,\mu(x,z);$$
3. 通常要求是 **结合的**（associative）：`μ(x, μ(y, z)) = μ(μ(x, y), z)`；
4. **含幺**（unital）：存在 `1_A ∈ A` 使得 `μ(1_A, x) = μ(x, 1_A) = x` 对所有 `x ∈ A` 成立。

> **小注**：当 `R` 是交换环时，`A` 作为左 `R`-模或右 `R`-模是等价的（"left or right module doesn't matter"）。
> 因此可以把 `End_R(M)` 中的 `R` 线性映射自然看作 `R`-模同态群。

### 2. 核心记号约定

| 符号 | 含义 |
| --- | --- |
| `R` | 含幺交换环；通常特别取 `R = F` 为域 |
| `M_n(F)` | 域 `F` 上的 `n × n` 矩阵代数 |
| `F[x_1, ..., x_n]` | 交换多项式代数 |
| `F⟨x_1, ..., x_n⟩` | 由 `x_1,...,x_n` 生成的**自由结合代数**（`x_i` 之间无关系，**不交换**）[存疑：ASR 把它简称"多项式"，需小心——这里是自由结合代数，不是 `F[x_1,...,x_n]`，见下文例 2] |
| `F[G]` | 有限群群代数 |
| `gl_n(F)` | `M_n(F)` 在李括号 `[A,B]=AB-BA` 下成为的**李代数**（**非结合**！） |
| `A^op` | 对位代数（opposite algebra），乘法反向 |
| `End_R(M)` | `R`-模 `M` 的 `R`-线性自同态环（自然是一个 `R`-代数） |
| `Alg_R` | `R`-代数的范畴：对象 = `R`-代数，态射 = `R`-代数同态 |

### 3. 对位代数（Opposite Algebra）

给定 `R`-代数 `A`，定义 `A^op`：
- 底层集合（= 加法群 = `R`-模）与 `A` 相同；
- 乘法反向：若 `a · b` 记作 `μ(a, b)`，则 `A^op` 上的乘法 `μ^op` 满足
  $$a \cdot_{op} b \;=\; b \cdot a.$$

直观上：把乘法图"翻过来"。若把 `A` 看作"作为左 `R`-模"，`A^op` 就是"作为右 `R`-模"，但更一般的代数结构层只翻转乘法。**作为交换环、`R`-模、集合都一样**——结构越松越容易相同，越紧越容易不同。

## 定理 / 命题 / 引理

### 命题 1：`End_R(M)` 是自然的 `R`-代数

设 `M` 是一个 `R`-模。`End_R(M)`（`M` 的 `R`-线性自同态全体）以映射复合为乘法，是一个 `R`-代数。
- **`R` 的作用**：`α ∈ R` 映到 `α · id_M`（标量乘以恒等映射），因此 `R → End_R(M)` 是一个环同态。
- **双线性**：复合关于加法是双线性的（自然）。
- 单位元：`id_M`。
- 结合性：映射复合的结合律（精确 = `F` 的代数结合性）。

[存疑：ASR 末段又说"如果 `R` 不交换，则嵌入不必是单的，但仍可在中心里"，大意如此。]

### 命题 2（核心等价）：幺表示 ≌ 左 `A`-模

设 `F` 是域，`A` 是一个 **幺结合 `F`-代数**（unital associative `F`-algebra）。
则下述两类对象之间存在**自然双射**（natural bijection）：

> **左边**：幺 `F`-代数表示（unital `F`-algebra representation）
> `(V, θ)`，`V` 是 `F`-向量空间，`θ: A → End_F(V)` 是幺 `F`-代数同态（即 `F`-线性、环同态，且 `θ(1_A) = id_V`）。

> **右边**：`A` 上的（左）`A`-模
> 一个阿贝尔群 `M` 配以 `A` 的幺环同态 `θ̃: A → End_Z(M)`（`A` 通过模结构作用于 `M`）。

**对应方向**：

**(V, θ) → (M, θ̃)**：
- 把 `V` 退化为阿贝尔群 `M`；
- 用 `θ̃(a) := θ(a)`（因为 `End_F(V) ⊂ End_Z(M)`，`F`-线性 ⇒ 阿贝尔群同态）；
- `V` 上自然的 `F`-向量空间结构来源于：把 `F` 通过 `α ↦ α·1_A` 嵌入 `A`（`A` 是幺结合 `F`-代数，标准嵌入 `F ↪ A`），再用 `θ̃` 把这个元素送到 `End_Z(M)`，从而定义了 `F` 在 `M` 上的标量作用；
- 即：`α · v = θ̃(α·1_A)(v)`。

**逆方向 `(M, θ̃) → (V, θ)`**：
- 集合不变，`V := M`；
- `F`-向量空间结构由上面的嵌入 `F ↪ A ↪ End_Z(M)` 给出；
- 验证 `θ̃` 的值域事实上落在 `End_F(V)` 内（因为 `θ̃` 在 `A` 的中心里 `F` 的像上是 `F`-线性的）；
- 即得 `θ: A → End_F(V)` 是幺 `F`-代数同态。

**两方向互逆**，构成**自然双射**。

> **推论**：固定幺 `F`-代数 `A`，幺 `A`-表示的范畴 ≅ 左 `A`-模范畴。

### 命题 3：幺表示同态 ≅ 左 `A`-模同态

设 `(V_1, θ_1)`、`(V_2, θ_2)` 是 `A` 的两个幺表示。
映射 `H: V_1 → V_2` 是 `A`-表示同态 当且仅当
- `H` 是 `F`-线性的；
- 对所有 `a ∈ A`，下述交换图成立：
  $$V_1 \xrightarrow{\theta_1(a)} V_1$$
  $$V_1 \xrightarrow{H} V_2$$
  $$V_2 \xrightarrow{\theta_2(a)} V_2$$
  即 `H ∘ θ_1(a) = θ_2(a) ∘ H`，∀`a ∈ A`.

这恰好就是 **左 `A`-模同态**的定义（一个 `A`-模同态 `M_1 → M_2` 同时保持 `F`-线性结构与 `A`-作用结构）。

> **结论**：左 `A`-模范畴、`A` 的幺表示范畴，是同一个范畴（自然同构）。

## 例题与证明思路

### 例 1：`A := M_n(F)` 的典范表示（canonical representation）

取 `V = F^n`（列向量空间），`θ = id: A → End_F(F^n)`：`A` 中的矩阵按通常方式作用在列向量上。
- 这个表示称为 `A` 的 **典范表示（canonical representation）**。

> 在范畴 `Rep(A)` 中，`A` 自己（通过 `id`）就是它的一个最重要的"标杆"对象。

### 例 2：自由结合代数的表示 ↔ `n` 个交换算子

设 `A = F⟨x_1, ..., x_n⟩`（`x_1, ..., x_n` 之间无代数关系，**自由**的非交换结合代数）。
给出一个幺表示 `(V, θ)` 等价于指定 `V` 上 `n` 个算子
$$T_i := \theta(x_i) \in \mathrm{End}_F(V),\quad i = 1, \ldots, n$$
使得 **`T_i T_j = T_j T_i`** 对所有 `i, j` 成立（因为 `x_i x_j = x_j x_i` 是 `F⟨x_i⟩` 上由自由性保证的）。

> 当 `n = 1` 时退化到 `A = F[x]`，任意算子 `T: V → V` 都对应一个 `F[x]` 的表示 `x ↦ T`。这就是**算子 = 表示**这句话的来源。

### 例 3：`F[x]` 表示的像 = 算子所满足的不变多项式

设 `T: V → V` 是 `F`-向量空间上的线性算子，定义 `θ: F[x] → End_F(V)` 为 `x ↦ T`。
- `F[x]` 是 PID；作为环同态，`θ` 的核是某个主理想 `(m(x))`，其中 `m(x)` 是首一多项式，称为 `T` 的**极小多项式**（minimal polynomial）。
- **线性代数联系**：
  - 与 `T` 相关的多项式有**特征多项式** `χ_T(x)` 和**极小多项式** `m_T(x)`；
  - `χ_T(T) = 0`（Cayley–Hamilton 定理），且 `m_T | χ_T`。
- 给定算子 ↔ 给定 `F[x]` 的一个幺表示；表示论把"算子理论的整章线性代数"重新组织了一遍。

[存疑：原 ASR 中"kernel 由哪个多项式生成"被作为问题抛给学生，没有给出明确答案。课堂上暗示——"整个线性代数都在里面"、"想想和 `T` 关联的多项式有哪些"。**最自然的答案是极小多项式 `m_T(x)`**，因为 kernel 作为 `F[x]` 的理想由 `m_T` 生成。]

### 例 4（非示例）：`M_n(F)` 上的李括号

考虑 `(M_n(F), [·,·])` 其中 `[A, B] := AB − BA`：
- 这是 **不结合的**（not associative）：`[A, [B, C]] ≠ [[A, B], C]`；
- 它是**李代数（Lie algebra）`gl_n(F)`**——对应李群 `GL_n(F)`，是另一门课的起点。
- "李代数在左下、代数在右上"—— 这就是为什么有两门课而不是一门课。

[存疑：ASR 提到 `M_n(F)` 李括号的具体计算，但没展开非结合性的演示，仅口头说"差一个东西"。]

## 范畴与动机（约第 60–75 分钟处）

### 范畴 `Vect_F` 的动机

学习线性代数的 70%–80% 时间花在 **两个向量空间之间的关系** 上（而不是单个向量空间）。一个向量空间孤立地没什么"好说的"；要看清楚它的"宇宙"，必须知道：
- 两个向量空间是否同构？
- 维数关系？
- "一样"的精确定义 ⇒ 一个保持线性结构的映射（`F`-线性映射）。

这就是范畴论语言：`Vect_F` = 对象（向量空间）+ 态射（`F`-线性映射）。

### `Alg_R` 与标杆

`Alg_R` 是 `R`-代数的范畴：
- 对象：`R`-代数；
- 态射：`R`-代数同态（必须同时是 `R`-线性映射、保持乘法、保持幺 [如果要求幺的话]）。

**标杆**（"能在里面一直找到的具体例子"）：
- 当 `R = F` 是域时，`M_n(F)` 是 `Alg_F` 中最具体、最常驻的标杆对象。
- 一般 `R` 时，`R` 本身、`R[x]`、`R[x_1,...,x_n]` 也是标杆。

### 三个圈圈（图示思路）

整门课围绕**三个相互关联的范畴**展开：
1. **`Vect_F`**（你熟悉的）；
2. **`Alg_F`**（你将要熟悉的）；
3. **`Rep_F(A)`**（对固定 `A` 的表示范畴，对 `A = 群代数` 即群表示范畴）—— 这是从 `Alg_F` 派生的子范畴，并且当 `A = M_n(F)` 时回到 `Vect_F` 本身。

## 存疑与不确定（ASR 噪声）

1. **"自由结合代数 vs 多项式代数"**：老师三次提到"多项式"或"由 `x_1,...,x_n` 生成"，但同时强调 `x_i x_j = x_j x_i` 是自由代数上的关系（这正好是**非交换**的）。最一致的解读是 `A = F⟨x_1,...,x_n⟩`（自由结合代数），`n=1` 时退化为 `F[x]`。
2. **PID 上的 kernel**：`F[x] → End_F(V)` 的 kernel 由哪一个多项式生成？老师以问题形式抛出，未在 ASR 中显式给出答案。最规范答案是 **极小多项式 `m_T(x)`**。
3. **`F[x]` → `End_F(V)`**：是否要求 `T` 必须是有限秩算子？若是有限维 `V`，则核 = `(m_T)`；若是无限维，ASR 未澄清。
4. **`R` 不交换时**"嵌入不必是单射但仍可拉到中心"——具体技术细节 ASR 不够清晰，可能涉及 **圆环分式化** / **中心化子** 的相关讨论。
5. **非交换情形下 `End_R(M)` 的代数结构**：标准结论是 `End_R(M)` 自然是 `R`-代数（即使 `R` 不交换）——ASR 仅一笔带过。
6. ASR 中夹杂大量课堂闲聊、点名、设备调试（黑板擦不掉、自带混响、`es` 工具报错等），已忽略。
