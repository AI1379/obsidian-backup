# 数值分析 2026-09-24 第9-10节

> 讲义第二章续：稳定性与条件数。本节完成「条件数」的量化定义，并分别处理**多项式求根**与**线性方程组求解**两个核心例子；引出**矩阵范数 / 矩阵条件数**及一个**相对扰动定理**。

## 本讲脉络

1. 回顾上午：**算法的向后稳定性** (backward stability) 与**问题模型的条件数** $\kappa(F)$：$\kappa(F) \approx |F'(x)| \cdot |x|/|F(x)|$。
2. **例子 A — 多项式求根**：用隐函数定理推导条件数；说明重根时条件数 $\to \infty$。Wilkinson 多项式作为经典坏例子。
3. **例子 B — 线性方程组 $AU = B$**：第一个「输入输出都是向量」的例子，自然引出**矩阵范数**与**矩阵条件数** $\kappa(A) = \|A\|\cdot\|A^{-1}\|$。
4. **算子范数 (operator norm)** 的引出：通过 $\sup_{U\ne 0}\|AU\|/\|U\|$ 定义矩阵范数；特例：$1$-范数、$\infty$-范数、$2$-范数 (谱范数)。
5. **扰动定理**：在 $A$、$B$ 同时有相对扰动时，$U$ 的相对误差上界。

## 定义与记号

### 条件数 $\kappa(F)$ (回顾 + 矩阵版)

**问题模型** $Y = F(X)$，$X \in \mathbb{R}^m$, $Y \in \mathbb{R}^n$。

- **一般形式** (上午给出，下午展开)：
  $$\kappa(F; X) = \frac{\|J_F(X)\|\,\|X\|}{\|F(X)\|},$$
  其中 $J_F$ 为 $F$ 在 $X$ 处的 Jacobian，$\|\cdot\|$ 分别为矩阵 / 向量范数 (相容)。
- **矩阵条件数** $\kappa(A)$：对 $F(B) = A^{-1}B$ 这一**线性解映射**关于 $B$ 取 sup，去掉右端向量的影响，只剩矩阵本身：
  $$\boxed{\;\kappa(A) = \|A\|\,\|A^{-1}\|\;}.$$
  其中矩阵范数采用下述**算子范数**。

> 老师原话：「条件数与右端向量无关，所以数值线性代数里用它。」
> 「well-conditioned」⇔ $\kappa$ 小；「ill-conditioned」⇔ $\kappa$ 大。无严格分界，仅定性。

### 多项式求根模型

$$P(\lambda) = \lambda^n + a_{n-1}\lambda^{n-1} + \cdots + a_0,\quad \text{输入 } X = (a_0,\dots,a_{n-1}).$$

对固定的系数向量 $a$，设 $r$ 为 $P$ 的一个根，输出 $Y = F(a) = r$。$F$ 由隐式关系 $P(r)=0$ 给出，没有显式表达式。

### 线性方程组模型

$$A U = B,\quad A \in \mathbb{R}^{n\times n},\; B \in \mathbb{R}^n.$$

**解映射**：$F: B \mapsto U = A^{-1}B$。$F$ 是线性映射，故 $J_F(B) = A^{-1}$ (系数矩阵即雅可比)。

## 定理·算法·推导

### 定理 1 (多项式求根的条件数 — 隐函数定理推导)

设 $P$ 为光滑函数，$P(r)=0$，对系数做扰动 $P \mapsto P + \varepsilon\, G$ (其中 $G$ 充分光滑)，相应地根变为 $r+\Delta r$。

**(a) 量级**：由隐函数定理，$\Delta r = O(\varepsilon)$；更精确地取到二阶 Taylor 展开：

$$0 = P(r+\Delta r) + \varepsilon\,G(r+\Delta r) \approx P(r) + P'(r)\,\Delta r + \varepsilon\,G(r).$$

利用 $P(r)=0$，并扔掉 $O(\varepsilon^2)$、$O(\Delta r^2)$、$O(\varepsilon \Delta r)$ 项，得到
$$\boxed{\;\Delta r \approx -\,\frac{\varepsilon\,G(r)}{P'(r)}\;}, \quad \text{前提 } P'(r) \ne 0 \;\text{(即 } r \text{ 为单根)}.$$

**(b) 重根情形**：若 $r$ 是 $P$ 的重根，则 $P'(r)=0$，条件数按定义趋于**无穷大**，问题极度病态。

**(c) 相对形式**：把 $\varepsilon\,G$ 与 $\Delta P$ 等同 (即把对系数的扰动 $\Delta a$ 通过 Cauchy 不等式 / 范数上界提出来)：

$$\frac{|\Delta r|}{|r|} \;\lesssim\; \underbrace{\frac{|P(r)|\,\|a\|}{|r|\,|P'(r)|}}_{\text{条件数上界 } \kappa} \cdot \frac{\|\Delta a\|}{\|a\|}.$$

> 注：条件数与「$P'(r)$ 是否接近 $0$」及「多项式次数 $n$」均有关。

### 例：Wilkinson 多项式

$$P(\lambda) = (\lambda - 1)(\lambda - 2)\cdots(\lambda - n) = \lambda^n - (\text{初等对称多项式}).$$

对**最高次项系数**做扰动：$1 \mapsto 1 + \varepsilon\, \lambda^n$。取关心的根 $r = n$，则 $G(\lambda) = \lambda^n$, $G(r) = n^n$。

$$|\Delta r| \approx \frac{\varepsilon\, n^n}{P'(n)}.$$

**计算 $P'(n)$**：由于 $P(\lambda) = \prod_{k=1}^{n}(\lambda-k)$，对 $\lambda$ 在 $n$ 处求导：

$$P'(n) = \prod_{k=1}^{n-1}(n-k) = (n-1)!.$$

故
$$|\Delta r| \approx \frac{\varepsilon\, n^n}{(n-1)!}.$$

由 Stirling 公式 $n! \sim \sqrt{2\pi n}\,(n/e)^n$，有

$$\frac{n^n}{(n-1)!} \approx \frac{n^n}{n!/n} = \frac{n^{n+1}}{n!} \sim \sqrt{\frac{n}{2\pi}}\cdot e^n.$$

> **数值**：$n=20$ 时条件数 (老师口述) 大约 $\sim 10^9$，$n=40$ 时 $\sim 10^{17}$，已无任何精度。
> 「10 次以下的多项式求根还能算，10 次以上根本没法算。」

### 定义：算子范数 (Operator / Induced Norm)

对任意向量范数 $\|\cdot\|$，**矩阵范数**通过「拉长倍数」的上确界定义：
$$\boxed{\;\|A\| = \sup_{U \ne 0}\frac{\|AU\|}{\|U\|}\;}.$$
等价地 (用 $U$ 在单位球面上归一)：$\|A\| = \max_{\|U\|=1}\|AU\|$。

- 当向量范数取 $\|\cdot\|_2$ 时，得到的矩阵范数叫 **谱范数 / spectral norm**，记为 $\|A\|_2$。
- 当向量范数取 $\|\cdot\|_1$ 时，叫 **矩阵 $1$-范数**；取 $\|\cdot\|_\infty$ 时叫 **矩阵 $\infty$-范数**。

> 老师说：「这种方式定义矩阵范数跟直接对矩阵元素做 Frobenius 范数是不一样的，我们这里不用 Frobenius 范数。」

### 命题：$1$-范数与 $\infty$-范数的闭式

- **$1$-范数** = **每列元素绝对值之和取最大**：
  $$\|A\|_1 = \max_{1\le j\le n}\sum_{i=1}^{n}|a_{ij}|.$$
- **$\infty$-范数** = **每行元素绝对值之和取最大**：
  $$\|A\|_\infty = \max_{1\le i\le n}\sum_{j=1}^{n}|a_{ij}|.$$

> 「二范数没有这种闭式，一范数和无穷范数有非常简单的表达式，所以用得多。」
> 「二范数（谱范数）需要算最大奇异值，不便手算。」

### 范数的合理性

老师用一个简短的存在性 / 一致性 (well-definedness) 论证：

- **有限性**：$U$ 取遍单位球面 $S = \{U : \|U\|=1\}$。$S$ 是有限维欧氏空间中的紧集 (连续像、闭有界)；$\|AU\|$ 是 $U$ 的连续函数 ⇒ 在 $S$ 上取到最大值 ⇒ $\|A\| < \infty$。
- **三角不等式** $\|A+B\|\le \|A\|+\|B\|$ 仍成立（由 sup 定义直接推出）。
- **次乘性** $\|AB\|\le \|A\|\,\|B\|$ 同样成立（重要的矩阵范数性质）。

### 定理 2 (线性方程组扰动定理)

设 $A U = B$，$A$ 非奇异；扰动后求 $(A+\Delta A)\hat{U} = \hat{B}$，其中 $\|\Delta A\|\cdot\|A^{-1}\| < 1$。则

$$\boxed{\;\frac{\|\hat{U} - U\|}{\|U\|} \;\le\; \frac{\kappa(A)}{1 - \kappa(A)\,\|\Delta A\|/\|A\|}\left(\frac{\|\Delta A\|}{\|A\|} + \frac{\|\Delta B\|}{\|B\|}\right).\;}$$

**证明梗概** (课上推导全程)：

1. **两个方程相减**：
   $$A\,\Delta U + \Delta A\,(U + \Delta U) = \Delta B,\quad \Delta U := \hat U - U.$$
2. **提 $A$ 出来**：
   $$(I + A^{-1}\Delta A)\,\Delta U = A^{-1}\bigl(\Delta B - \Delta A\,U\bigr).$$
3. **用工具引理**：若 $\|B\|<1$，则 $I - B$ 可逆，且
   $$\|(I - B)^{-1}\| \le \frac{1}{1-\|B\|}\quad \text{(Neumann 级数求和)}$$
   这里 $B = -A^{-1}\Delta A$，于是 $\|B\| = \|A^{-1}\Delta A\| \le \kappa(A)\cdot \|\Delta A\|/\|A\| < 1$。
4. **取范数 + 矩阵范数次乘性** $\|AX\|\le \|A\|\,\|X\|$、$\|A+B\|\le \|A\|+\|B\|$，反复应用得：

$$\|\Delta U\| \;\le\; \frac{\|A^{-1}\|}{1-\kappa(A)\,\|\Delta A\|/\|A\|}\bigl(\|\Delta B\| + \|\Delta A\|\,\|U\|\bigr).$$

5. **两端除以 $\|U\|$，右端再乘除 $\|A\|/\|A\|$**，注意到 $\|B\| = \|AU\| \le \|A\|\,\|U\|$ ⇒ $\|U\| \ge \|B\|/\|A\|$，从而

$$\frac{\|\Delta U\|}{\|U\|} \;\le\; \frac{\kappa(A)}{1-\kappa(A)\,\|\Delta A\|/\|A\|}\left(\frac{\|\Delta A\|}{\|A\|} + \frac{\|\Delta B\|}{\|B\|}\right).$$

> 老师原话：「如果 $\kappa(A)$ 不离谱，那么分母中 $1 - \kappa(A)\cdot(\Delta A/A)$ 是个 $O(1)$ 的数；主导项就是 $\kappa(A)$ 乘上 $A$ 和 $B$ 的相对扰动之和。」

### 例子：Hilbert 矩阵

$$H_n = \left[\frac{1}{i+j-1}\right]_{i,j=1}^{n}.$$

老师口述**二范数**下的条件数 (引用讲义)：
$$\boxed{\;\kappa_2(H_n) \approx \frac{(1+\sqrt 2)^{4n}}{}\; \sim \text{关于 } n \text{ 指数增长}.\;}$$

> $n=3$ 的 $H_3 = \begin{pmatrix}1&1/2&1/3\\1/2&1/3&1/4\\1/3&1/4&1/5\end{pmatrix}$，「条件数已经比较差了」。
> $n=10$ 时条件数 $\sim 10^{16}$ 量级 (老师口述)，浮点机器精度 $\sim 10^{-16}$，二者相乘毫无精度。
